# まなびのにわ（manabi-no-niwa）

2歳から小学生までの子供が日本語で使える、オフラインのブラウザ学習アプリです。

- 対象（2.0。258単元）:
  - 幼児: 2〜3歳（中で2歳段階・3歳段階に分かれる）、4歳、5歳
  - 小学1〜6年: 算数・国語（漢字の読み書きを含む）、生活（1・2年）、理科・社会・英語（3〜6年）、プログラミング（1〜6年）
  - 単元の一覧と学年の割り当ては docs/expansion/curriculum-matrix.md、作業の記録は docs/expansion/progress.md。優先度の低い単元（P2）は入っていません。
- プロフィールごとに「年齢の目安」「在籍学年」「習熟」「支援の設定（ふりがな・読み上げ など）」を別々に持ちます。学年で教材を閉じ込めません（先取り・さかのぼりができます）。
- 幼児は絵の札から遊びます。4歳のホームには初期版（1.0）の9つのあそびがそのまま入っています。小学生は教科 → 単元 → 問題の順に選びます。どのホームからも「ほかの がくねん」で、ほかの年齢・学年の遊びや教科を開けます。
- 全年齢で「おえかき」（ペン・消しゴム・塗り・はんこ63種・図形・やり直し・自動保存・PNG 書き出し）が使えます。
- ひらがなが読めなくても、絵と日本語の音声で遊べます。手書きや声を自動で採点することはありません。
- 広告・外部への通信・アカウント登録はありません。記録はこの端末のブラウザの中にだけ保存します。
- 罰・点数・ランキング・連続日数・ガチャはありません。1回は3〜5問の短い区切りです。

> この アプリの 記録は、遊んだ内容の記録です。能力の測定では ありません。
> 学習効果は検証していません（子供での観察もまだです）。教材は自動検査と独立レビューを通していますが、学校の教科書・テストの代わりではありません。

## はじめての方へ: パソコンに入れる手順（Zorin OS）

パソコンにくわしくなくても進められるように書いています。上から順に進めてください。全部で **30分〜1時間** ほどかかります（ほとんどはダウンロードと準備の待ち時間です）。

> この手順のコマンドは、開発用のパソコン（Windows の Git Bash）で、4つの zip を開いて確認の質問が出るところまでと、zip が1つ足りないときに止まって知らせることを確かめました。**Zorin OS の実機ではまだ確かめていません**。うまくいかないときは、下の「[困ったとき](#困ったとき)」を見てください。

### 用意するもの
| もの | 説明 |
|---|---|
| Zorin OS のパソコン | Lenovo Yoga 720 などで動かす想定です。ほかの Ubuntu 系でも同じ手順です |
| インターネット | **ダウンロードのときだけ**使います。入れたあとは、つながなくても使えます |
| 空き容量 **10GB 以上** | ダウンロードしたファイル（約2.6GB）と、入れたアプリ（約5GB）のためです。入れ終わったら、ダウンロードしたファイルは消してかまいません |
| ブラウザ | Zorin に最初から入っている Firefox で使えます（Chromium や Google Chrome があれば、そちらで開きます） |

### 手順1: ファイルを4つダウンロードする
1. パソコンのブラウザで次のページを開きます。
   **https://github.com/das0427/manabi-no-niwa/releases/latest**
2. ページの下のほうにある「**Assets**」の一覧から、次の **4つ** をクリックして保存します（`.sha256` で終わるものと「Source code」は要りません）。一覧の一部が隠れていて「**Show all 10 assets**」と出ているときは、それを押すと全部表示されます。

   | ファイル名 | 大きさ | 中身 |
   |---|---|---|
   | `manabi-no-niwa-2.0.2.zip` | 約170MB | アプリの本体（幼児の教材を含む） |
   | `manabi-no-niwa-2.0.2-audio-g1-g2.zip` | 約330MB | 小学1・2年の教材の音声 |
   | `manabi-no-niwa-2.0.2-audio-g3-g4.zip` | 約790MB | 小学3・4年の教材の音声 |
   | `manabi-no-niwa-2.0.2-audio-g5-g6.zip` | 約1.3GB | 小学5・6年の教材の音声 |

3. 保存先は、ふつうは「**ダウンロード**」フォルダです。4つとも保存し終わるまで待ちます。
   - 小学生が使わない場合でも、**4つともダウンロードしてください**（入れるときに、全部そろっているかを確かめます）。
   - zip を自分で開いて（展開して）おく必要はありません。次の手順でまとめて行います。

### 手順2: 「端末」を開く
「端末」は、文字で指示を出す画面です。ここで使うのは、次の手順の **1回だけ** です。

- キーボードで **Ctrl + Alt + T** を同時に押します。黒っぽい窓が開けば成功です。
- 開かないときは、画面左下のメニュー（Zorin のマーク）を開き、検索欄に「**端末**」（または「Terminal」）と入力して選びます。

### 手順3: 次の1行を貼り付けて Enter を押す
1. 下の枠の中の文字を**全部**コピーします（枠の右上にコピーのボタンがあれば、それを押します。無ければ、文字を最初から最後までなぞって選び、右クリック →「コピー」）。

   ```bash
   cd ~ && rm -rf ~/manabi-no-niwa && for f in ~/ダウンロード/manabi-no-niwa-2.0.2*.zip ~/Downloads/manabi-no-niwa-2.0.2*.zip; do if [ -f "$f" ]; then echo "ひらいています: $f"; python3 -m zipfile -e "$f" ~; fi; done; bash ~/manabi-no-niwa/deploy/zorin/install.sh
   ```

2. 端末の窓の中で**右クリック →「貼り付け」**を選びます（キーボードなら **Ctrl + Shift + V**。Ctrl + V だけでは貼り付けられません）。
3. **Enter** キーを押します。
   - 「ひらいています: …」と4回表示され、zip を順に開きます。大きいファイルは数分かかります。そのまま待ってください。
   - このコマンドは、ホームフォルダに `manabi-no-niwa` というフォルダを作り直してから、そこへ4つの zip の中身をまとめます。ほかのファイルには触りません。

### 手順4: 確認の質問に「y」と答える
しばらくすると、次のような表示が出て止まります。

```
=== まなびのにわ 導入 ===
これから次のことを行います（sudo・管理者権限は使いません）。
  1. アプリ本体をコピー: …
  2. アプリ一覧に登録: …
  3. デスクトップにアイコン: …
実行しますか？ [y/N]
```

- キーボードで **y** を押してから **Enter** を押します。
- 「**完了しました。**」と出たら、入れ終わりです。端末の窓は閉じてかまいません。
- パスワードは聞かれません（管理者の権限は使いません）。もし赤い字で「エラー」と出たら、「[困ったとき](#困ったとき)」を見てください。

### 手順5: アプリを開く
1. デスクトップにできた「**まなびのにわ**」のアイコンをダブルクリックします（デスクトップに無いときは、画面左下のメニューで「まなびのにわ」と検索します）。
2. 初めて開くときに「**起動を許可**」「信頼して起動」などと聞かれたら、許可します。
3. ブラウザが開き、「まなびの にわ」の画面が出ます。
4. **初回だけ、アプリの準備に数分かかります。** 画面の下に「**オフラインの準備中 ○%**」と出ている間は待ってください。「**オフラインで つかえます**」と出たら準備完了です。
5. 準備ができたら、いちどブラウザの窓を閉じて、もう一度アイコンから開いてください（これで、インターネットにつながっていなくても開けるようになります）。

### 手順6: 子供のプロフィールを作る（保護者の方が行います）
最初は、4歳向けのプロフィールが1つだけ用意されています。子供の名前と、年齢・学年を設定します。

1. 「はじめる」を押してホームを開きます。
2. ホームの**右上にある小さな鍵のボタンを2秒長押し**します。足し算の問題が出るので、答えを入れると「保護者画面」が開きます（子供が誤って開かないための仕組みです）。
3. 上のタブから「**プロフィール**」を選びます。
4. 名前を直し、「**区分**」で子供に合うもの（2〜3歳／4歳／5歳／小学1年〜6年）を選びます。小学生なら「在籍学年」も選びます。
   - きょうだいがいる場合は、ここで人数分のプロフィールを作れます。記録は人ごとに分かれます。
5. 画面上の「**こどもの画面へ**」を押すと、子供の画面に戻ります。

### 手順7: 小学生の教材を準備する（小学生が使う場合だけ）
小学生の教材は、学年・教科ごとの「教材パック」に分かれていて、使う分だけ準備します（2〜5歳の教材は準備不要です）。

1. 保護者画面（手順6の2と同じ開き方）の「**きょうざい**」タブを開きます。
2. 使う学年の教材の行で「**取得する**」を押します。大きい教材は数分かかります。「取得済み」になったら使えます。
   - 準備はこのパソコンの中だけで行い、インターネットは使いません。
   - 使わなくなった教材は「削除する」で消せます（学習の記録は消えません）。

これで準備は終わりです。

## 毎日の使い方
- デスクトップの「**まなびのにわ**」を開くだけです。端末やコマンドは使いません。
- やめるときは、ブラウザの窓を閉じます。
- **ほかの学年・年齢の遊びをしたいとき**: ホームの「**ほかの がくねん**」（道しるべの絵）を押します。左の「2〜3さい」〜「6ねん」から選ぶと、その年齢・学年の遊びや教科が出ます。幼児のホームからも小学生の教科を開けますし、その逆もできます。プロフィールの区分は変わりません（戻るとふだんのホームです）。
  - 小学生の教科の中では、上の「1ねん」〜「6ねん」のタブで学年を行き来できます。
  - ふだんのホーム自体を別の学年にしたいとき（進級したときなど）は、保護者画面「プロフィール」で区分・在籍学年を変えます。記録は消えません。
- **きょうだいで使うとき**: 保護者画面「プロフィール」→「プロフィールを追加」で、人数分作れます。2人以上いると、起動画面で「だれが あそぶ？」と出て、子供が自分を選びます。記録・作品・区分は人ごとに分かれます。
- 使う時間の目安（初期は10分）になると、区切りのよいところで「きょうは ここまで」と出ます。目安は保護者画面「せってい」で変えられます。
- **記録のバックアップ**: ときどき、保護者画面「データ」→「書き出し」で、記録をファイルに保存してください（詳しくは下の「記録のバックアップ」）。

## 新しい版に更新するとき
1. 手順1と同じページから、新しい版の zip を4つダウンロードします。
2. 手順2〜4と同じように、端末で1行を貼り付けて Enter を押し、「y」で進めます。
   - **貼り付ける1行の中の版の番号（いまは `2.0.2`）を、新しい版の番号に書きかえてください**（例: 新しい版が 2.1.0 なら `2.1.0`。2か所あります）。
3. 学習の記録・作品・設定は**消えません**。
4. 次にアプリを開くと、新しい版を裏で準備します。保護者画面「このアプリについて」に「あたらしい ばーじょんが あります」と出たら「**更新する**」を押します（押さなくても、窓を全部閉じて開き直せば切り替わります）。
5. 小学生の教材は、保護者画面「きょうざい」で「版が古い」と出たら「まとめて取得し直す」を押します。

## 困ったとき
| こんなとき | どうする |
|---|---|
| 端末に貼り付けられない | 端末では **Ctrl + Shift + V**（または右クリック →「貼り付け」）を使います |
| 「そのようなファイルやディレクトリはありません」「No such file or directory」と出る | zip がダウンロードフォルダに無いか、ファイル名が違います。手順1で4つとも保存できたか、ファイルの名前が `manabi-no-niwa-` と版の番号で始まっているかを確かめてから、手順3をもう一度行います |
| 「教材の音声が足りません」または「教材パックのファイルが足りません」と出る | 4つの zip のどれかが足りないか、ダウンロードが途中で止まっています。表示された名前の zip（例 `…-audio-g5-g6.zip`）をダウンロードし直して「ダウンロード」フォルダに置き、手順3をもう一度行います。zip の名前が出ないとき（2.0.0）は、「g5」「g6」を含む名前が出ていれば `-audio-g5-g6.zip`、「g3」「g4」なら `-audio-g3-g4.zip`、「g1」「g2」なら `-audio-g1-g2.zip` です |
| 「python3 が見つかりません」と出る | ふつうの Zorin OS では起きません。出た場合は、端末で `sudo apt install python3` を実行してから（パソコンのパスワードを聞かれます）、手順3をもう一度行います |
| 「空き容量が足りません」「No space left on device」と出る | 不要なファイルを消して 10GB 以上空けてから、手順3をもう一度行います |
| デスクトップのアイコンが開かない | アイコンを右クリック →「起動を許可する」を選びます。または、画面左下のメニューで「まなびのにわ」を検索して開きます |
| 画面が出ない・真っ白のまま | 1分ほど待ってから、ブラウザの窓を閉じて、もう一度アイコンから開きます |
| 音が出ない | パソコンの音量と、保護者画面「せってい」の音量を確かめます。保護者画面「このアプリについて」に「おとが でない」と出ていないか見ます |
| 小学生の教材が開けない（「おうちの ひとに ダウンロードを たのんでね」「あたらしい きょうざいを とってきてね」と出る） | 手順7で、その学年の教材を「取得する」（版が古いときは「取得し直す」）を押して準備します |
| 記録が消えたように見える | ブラウザを変えた（Firefox ↔ Chromium）か、ブラウザの「閲覧データの削除」をした可能性があります。保護者画面「データ」で書き出したファイルがあれば、「読み込み」で戻せます |

## 入れたアプリを消すとき
端末（Ctrl + Alt + T）で次の1行を貼り付けて Enter を押します。

```bash
bash ~/.local/share/manabi-no-niwa/app/deploy/zorin/uninstall.sh
```

- アプリとアイコンが消えます。学習の記録はブラウザの中にあるため、これでは消えません。記録も消すときは、先に保護者画面「データ」で必要なら書き出してから、ブラウザの設定でこのアプリ（`127.0.0.1:8765`）のサイトデータを削除します。
- ダウンロードした zip と、ホームフォルダの `manabi-no-niwa` フォルダは、ファイルの画面で削除してかまいません。

## 詳しい情報（技術的な説明）

### アドレスとブラウザ
- アプリのアドレスは必ず **`http://127.0.0.1:8765/`** です。ポートやアドレスを変えると、学習データが別のものとして扱われ、見えなくなります。ブラウザのプロファイルも変えないでください。
- `index.html` を `file://` で直接開いても、オフライン機能（PWA）は動きません。デスクトップのアイコンから開いてください。
- デスクトップのアイコンは、裏で小さな配信プログラム（`127.0.0.1` だけで待ち受け。外からは接続できません）を起動し、Chromium があればアプリ窓で、無ければ Firefox で開きます。使うブラウザは環境変数 `MANABI_BROWSER` で指定できます。
- 配信は窓を閉じても裏で動き続けますが、とても軽いです。止める場合: `pkill -f deploy/zorin/serve.py`。
- 全画面表示は強制しません。保護者画面の「せってい」から切り替えられます（ブラウザの F11 でも解除できます）。

### 自動起動（任意）
ログインしたときに配信を自動で始めたい場合は、手順3の1行の最後の `install.sh` を `install.sh --autostart` にして実行します（systemd のユーザー単位のサービス。ログイン中だけ動きます）。やめる場合: `systemctl --user disable --now manabi-no-niwa.service`。

### 配布物の構成
- 本体 `manabi-no-niwa-<版>.zip` と、小学生の教材の音声 `-audio-g1-g2.zip`・`-audio-g3-g4.zip`・`-audio-g5-g6.zip` に分かれています（ZIP のファイル数と GitHub の添付の大きさの上限のため）。どれも中の最上位が `manabi-no-niwa/` で、同じ場所に展開すれば1つにそろいます。
- `install.sh` は、教材パックのファイル（packs.json）がそろっているかを確かめ、足りなければ止まります。アプリ本体は `~/.local/share/manabi-no-niwa/app/` に配置し、アプリ一覧とデスクトップに「まなびのにわ」を作ります。`--yes` で確認を省けます。

### 通信が必要な場面
| 場面 | インターネット | 説明 |
|---|---|---|
| 導入時 | 必要 | 配布 zip を入手するときだけ。`install.sh` は通信しません |
| 初回の準備 | 不要 | `127.0.0.1` の配信から本体のファイルをブラウザに保存します。画面に準備の割合が出ます |
| 小学生の教材の準備 | 不要 | `127.0.0.1` の配信から取得します |
| 日常の利用 | 不要 | 外部への通信は一切行いません（広告・解析・音声合成サービスなし） |
| 更新時 | 必要 | 新しい配布 zip を入手するときだけ。その後の新版の準備は `127.0.0.1` だけです |

### ブラウザごとの違い
- **Chromium 系**: アプリ窓（`--app`）で開きます。PWA としてインストールもできます（実機では未確認）。
- **Firefox**: 通常のタブで使います。デスクトップ版の Firefox は通常 PWA のインストールができませんが、オフライン利用（Service Worker）は動きます（開発環境の Playwright で、準備後に配信を止めても開けることを確認）。
  - Zorin でタッチがマウスとして扱われる場合は、Firefox を `MOZ_USE_XINPUT2=1` を付けて起動すると改善することがあります（実機未確認）。
- ブラウザを変えると記録は別々になります。

## 保護者画面

ホーム右上の小さな鍵のボタンを **2秒長押し** → 表示された足し算に答えると開きます（任意で暗証番号に変更できます）。

- **これは子供の誤操作を防ぐためのもので、強固な保護ではありません**（ブラウザの開発者ツールなどで回避できます）。
- できること: 記録（自分でできた問題・ヒントを使った問題・まだ取り組んでいない内容・操作にとまどったかもしれない記録）、設定（音量・効果音・動きを減らす・利用時間の目安・1回の問題数・ホームの表示・なぞりの判定幅・難易度の固定）、作品、観察メモ、プロフィール（きょうだいで分けられます）、データの書き出し・読み込み、オフラインの準備状況と更新。
- 利用時間の目安（初期10分）は医学的な推奨ではありません。目安に達すると、遊びの区切りで「きょうは ここまで」と出ます。

## 記録のバックアップ（大切）

記録・設定・作品は、このブラウザの保存領域（IndexedDB）にあります。

- **ブラウザの「閲覧データの削除」「サイトデータの削除」をすると、記録も消えます。**
- **アドレス（`http://127.0.0.1:8765/`）が変わると、別のアプリとして扱われ、記録が見えなくなります。** ポート番号やホスト名（`localhost` と `127.0.0.1` は別扱い）を変えないでください。
- ブラウザを変えた場合（Chromium ↔ Firefox）も、記録は別々です。
- 定期的に、保護者画面 →「データ」→「書き出し」でファイルに保存してください。
- 読み込みは「プロフィールとして追加」が基本です。「すべて置き換え」は確認のうえ、直前の状態を自動で書き出してから行います。
- 保護者画面の「データを守る」を押すと、ブラウザに保存の継続を求めます（ブラウザが許可しない場合もあります）。

### 音声の作り直し・差し替え
- 台本は `src/voice/catalog/common.ts` と各モードの `src/modes/<mode>/voice.ts` にあり、`npm run voice:script` で `voice/script.json`（全文の一覧）を出力します。
- `npm run voice:build`（Windows）／`npm run voice:build:sh`（Linux）で Open JTalk により `public/audio/*.mp3` を作り直します（手順: docs/assets-pipeline.md）。実行時は音声合成を使いません。
- 家庭で録音した声に差し替える場合は、`voice/script.json` の各キーと同じ名前の mp3 を `public/audio/` に置き、`public/audio/manifest.json` を更新してからビルドします（録音した声は公開リポジトリに含めないでください）。
- **教材パックの音声**（`public/audio/<パック名>/`、数万本）は git に入れず、配布 zip にだけ同梱しています。リポジトリから自分でビルドするときは、`npm run voice:packs` で台本（`voice/packs/*.json`）を書き出し、パックごとに `python scripts/voice/generate.py --script voice/packs/<パック名>.json --out public/audio/<パック名>` で作ります（docs/assets-pipeline.md）。
- 音声ファイルが無い場合だけ、ブラウザの日本語読み上げで代わりに読みます。どちらも無い場合は無音になり、保護者画面に「おとが でない」と表示します。

## 保護者が子供と試すときの観察チェックリスト

数分そばで見て、気づいたことを保護者画面の「メモ」に残してください。
1. 自分で「はじめる」を押して、遊びを選べたか（どの絵を選んだか）
2. 問題の声を聞いて、何をすればよいか分かっていたか（「もういちど きく」を使ったか）
3. 間違えたとき、ヒントの後にもう一度試せたか。いやになってやめなかったか
4. どこで手が止まったか（操作が分からない／内容が難しい、のどちらに見えたか）
5. 「おうち」を自分で押して終われたか。「きょうは ここまで」で納得して終われたか
6. 次の日、自分から「やりたい」と言ったか
7. 遊んだ内容（数える・形・字）が、生活の会話や遊びに出てきたか

アプリでの指の練習は、鉛筆の持ち方や筆圧の練習とは別のものです。
