# まなびのにわ（manabi-no-niwa）

2歳から小学生までの子供が日本語で使える、オフラインのブラウザ学習アプリです。

- 対象（2.0。258単元）:
  - 幼児: 2〜3歳（中で2歳段階・3歳段階に分かれる）、4歳、5歳
  - 小学1〜6年: 算数・国語（漢字の読み書きを含む）、生活（1・2年）、理科・社会・英語（3〜6年）、プログラミング（1〜6年）
  - 単元の一覧と学年の割り当ては docs/expansion/curriculum-matrix.md、作業の記録は docs/expansion/progress.md。優先度の低い単元（P2）は入っていません。
- プロフィールごとに「年齢の目安」「在籍学年」「習熟」「支援の設定（ふりがな・読み上げ など）」を別々に持ちます。学年で教材を閉じ込めません（先取り・さかのぼりができます）。
- 幼児は絵の札から遊びます。4歳のホームには初期版（1.0）の9つのあそびがそのまま入っています。小学生は教科 → 単元 → 問題の順に選びます。どのホームからも「ほかの がくねん」で、ほかの年齢・学年の遊びや教科を開けます。
- 全年齢で「おえかき」（ペン・消しゴム・塗り・はんこ63種・図形・やり直し・自動保存・PNG 書き出し）が使えます。
- ひらがなが読めなくても、絵と日本語の音声で遊べます。手書きや声を自動で採点することはありません。
- 広告・アカウント登録はありません。記録はこのパソコンのブラウザの中にだけ保存します。
- インターネットに接続するのは、**新しいバージョンがあるかを確かめるときと、新しいバージョンをダウンロードするときだけ**です（2.1.0 から）。接続先は GitHub だけで、送るのはアプリの名前だけです。自動の確認は保護者画面で止められます。
- 罰・点数・ランキング・連続日数・ガチャはありません。1回は3〜5問の短い区切りです。

> この アプリの 記録は、遊んだ内容の記録です。能力の測定では ありません。
> 学習効果は検証していません（子供での観察もまだです）。教材は自動検査と独立レビューを通していますが、学校の教科書・テストの代わりではありません。

## はじめての方へ: パソコンに入れる手順（Zorin OS）

パソコンにくわしくなくても進められるように書いています。上から順に進めてください。全部で **30分〜1時間** ほどかかります（ほとんどはダウンロードと準備の待ち時間です）。

> この手順のコマンドは、開発用のパソコン（Windows の Git Bash）で、4つの zip を開いて確認の質問が出るところまでと、zip が1つ足りないときに止まって知らせることを確かめました。**Zorin OS の実機ではまだ確かめていません**。うまくいかないときは、下の「[困ったとき](#困ったとき)」を見てください。

### 用意するもの
| もの | 説明 |
|---|---|
| Zorin OS のパソコン | Lenovo Yoga 720 などで動かす想定です。ほかの Ubuntu 系でも同じ手順です |
| インターネット | **ダウンロードのときと、新しいバージョンの確認・更新のときだけ**使います。入れたあとは、つながなくても使えます。つながっていなければ、確認もしません |
| 空き容量 **10GB 以上** | ダウンロードしたファイル（約2.6GB）と、入れたアプリ（約5GB）のためです。入れ終わったら、ダウンロードしたファイルは消してかまいません |
| ブラウザ | Zorin OS 17.3 以降を新しく入れたパソコンには、Brave が最初から入っています。それで使えます。17.2 以前から更新したパソコンには、Firefox が入っています。Chromium や Google Chrome も入れてあるときは、そちらで開きます |

### 手順1: ファイルを4つダウンロードする
1. パソコンのブラウザで次のページを開きます。
   **https://github.com/das0427/manabi-no-niwa/releases/latest**
2. ページの下のほうにある「Assets」の一覧から、次の **4つ** をクリックして保存します。`.sha256` で終わるもの・`manabi-no-niwa-update.json`・「Source code」は要りません。一覧の一部が隠れていて「Show all … assets」と出ているときは、それを押すと全部表示されます。

   | ファイル名 | 大きさ | 中身 |
   |---|---|---|
   | `manabi-no-niwa-2.0.2.zip` | 約170MB | アプリの本体（幼児の教材を含む） |
   | `manabi-no-niwa-2.0.2-audio-g1-g2.zip` | 約330MB | 小学1・2年の教材の音声 |
   | `manabi-no-niwa-2.0.2-audio-g3-g4.zip` | 約790MB | 小学3・4年の教材の音声 |
   | `manabi-no-niwa-2.0.2-audio-g5-g6.zip` | 約1.3GB | 小学5・6年の教材の音声 |

3. 保存先は、ふつうは「ダウンロード」フォルダです。4つとも保存し終わるまで待ちます。
   - 小学生が使わない場合でも、**4つともダウンロードしてください**。入れるときに、全部そろっているかを確かめます。
   - zip を自分で開いて（展開して）おく必要はありません。次の手順でまとめて行います。

### 手順2: 「端末」を開く
「端末」は、文字で指示を出す画面です。ここで使うのは、次の手順の **1回だけ** です。

- キーボードで **Ctrl + Alt + T** を同時に押します。黒っぽい窓が開けば成功です。
- 開かないときは、画面左下のメニュー（Zorin のマーク）を開き、検索欄に「端末」（または「Terminal」）と入力して選びます。

### 手順3: 次の1行を貼り付けて Enter を押す
1. 下の枠の中の文字を**全部**コピーします。枠の右上にコピーのボタンがあれば、それを押します。無ければ、文字を最初から最後までなぞって選んでから、右クリック →「コピー」を選びます。

   ```bash
   cd ~ && rm -rf ~/manabi-no-niwa && for f in ~/ダウンロード/manabi-no-niwa-2.0.2*.zip ~/Downloads/manabi-no-niwa-2.0.2*.zip; do if [ -f "$f" ]; then echo "ひらいています: $f"; python3 -m zipfile -e "$f" ~; fi; done; bash ~/manabi-no-niwa/deploy/zorin/install.sh
   ```

2. 端末の窓の中で右クリック →「貼り付け」を選びます。キーボードなら **Ctrl + Shift + V** を押します。Ctrl + V だけでは貼り付けられません。
3. **Enter** キーを押します。
   - 「ひらいています: …」と4回表示され、zip を順に開きます。大きいファイルは数分かかります。そのまま待ってください。
   - このコマンドは、ホームフォルダに `manabi-no-niwa` というフォルダを作り直してから、そこへ4つの zip の中身をまとめます。ほかのファイルには触りません。

### 手順4: 確認の質問に「y」と答える
しばらくすると、次のような表示が出て止まります。

```
=== まなびのにわ 導入 ===
これから次のことを行います（sudo・管理者権限は使いません）。
  1. アプリ本体をコピー: …
  2. アプリ一覧に登録: …
  3. デスクトップにアイコン: …
実行しますか？ [y/N]
```

- キーボードで **y** を押してから **Enter** を押します。
- 「完了しました。」と出たら、入れ終わりです。端末の窓は閉じてかまいません。
- パスワードは聞かれません（管理者の権限は使いません）。もし赤い字で「エラー」と出たら、「[困ったとき](#困ったとき)」を見てください。

### 手順5: アプリを開く
1. デスクトップにできた「まなびのにわ」のアイコンをダブルクリックします。デスクトップに無いときは、画面左下のメニューで「まなびのにわ」と検索します。
2. 初めて開くときに「起動を許可」「信頼して起動」などと聞かれたら、許可します。
3. ブラウザが開き、「まなびの にわ」の画面が出ます。
4. **初回だけ、アプリの準備に数分かかります。** 画面の下に「オフラインの準備中 ○%」と出ている間は待ってください。「オフラインの準備ができました。いちど開き直すと使えます。」と出たら準備完了です。
5. 「いちど開き直すと使えます」と出たら、いちどブラウザの窓を閉じて、もう一度アイコンから開いてください。これで、インターネットにつながっていなくても開けるようになります。開き直すと、画面の下に「オフラインで使えます」と出ます。

### 手順6: 子供のプロフィールを作る（保護者の方が行います）
最初は、4歳向けのプロフィールが1つだけ用意されています。子供の名前と、年齢・学年を設定します。

1. 「はじめる」を押してホームを開きます。
2. ホームの**右上にある小さな鍵のボタンを2秒長押し**します。足し算の問題が出るので、答えを入れると「保護者画面」が開きます（子供が誤って開かないための仕組みです）。
3. 上のタブから「プロフィール」を選びます。
4. 「名前・絵・区分を変える」を押し、名前を直して、「区分」で子供に合うもの（2〜3歳／4歳／5歳／小学1年〜6年）を選びます。小学生なら「在籍学年」も選びます。最後に「保存」を押します。
   - きょうだいがいる場合は、ここで人数分のプロフィールを作れます。記録は人ごとに分かれます。
5. 画面上の「こどもの画面へ」を押すと、子供の画面に戻ります。プロフィールが2人以上のときは、「こどもの画面へ」のあとに「だれが あそぶ？」と出ます。遊ぶ子を選ぶと、ホームが開きます。

### 手順7: 小学生の教材を準備する（小学生が使う場合だけ）
小学生の教材は、学年・教科ごとの「教材パック」に分かれていて、使う分だけ準備します（2〜5歳の教材は準備不要です）。

1. 保護者画面（手順6の2と同じ開き方）の「きょうざい」タブを開きます。
2. 使う学年の教材の行で「取得する」を押します。大きい教材は数分かかります。「取得済み」になったら使えます。
   - 準備はこのパソコンの中だけで行い、インターネットは使いません。
   - 使わなくなった教材は「削除する」で消せます（学習の記録は消えません）。

これで準備は終わりです。

## 毎日の使い方
- デスクトップの「まなびのにわ」を開くだけです。端末やコマンドは使いません。
- すでに開いているときにアイコンをもう一度押すと、開いている窓が前に出て、画面いっぱい（全画面）になります。窓は1つのままで、遊んでいた画面が続きます。最初に開いたときは、全画面にはなりません。
- 全画面をやめるには、**F11 キー**を押します。ノートパソコンでは、Fn キーを押しながら F11 キーを押すことがあります。
- やめるときは、ブラウザの窓を閉じます。全画面のときは、F11 キーで元に戻してから閉じます。Alt キーを押しながら F4 キーを押しても閉じられます。
- **ほかの学年・年齢の遊びをしたいとき**: ホームの「ほかの がくねん」（道しるべの絵）を押します。左の「2〜3さい」〜「6ねん」から選ぶと、その年齢・学年の遊びや教科が出ます。幼児のホームからも小学生の教科を開けますし、その逆もできます。プロフィールの区分は変わりません（戻るとふだんのホームです）。
  - 小学生の教科の中では、上の「1ねん」〜「6ねん」のタブで学年を行き来できます。
  - ふだんのホーム自体を別の学年にしたいとき（進級したときなど）は、保護者画面「プロフィール」で区分・在籍学年を変えます。記録は消えません。
- **きょうだいで使うとき**: 保護者画面「プロフィール」→「プロフィールを追加」で、人数分作れます。2人以上いると、「はじめる」を押したあとに「だれが あそぶ？」と出て、子供が自分を選びます。記録・作品・区分は人ごとに分かれます。
- 使う時間の目安に達すると、区切りのよいところで「きょうは ここまでに しよう」と出ます。遊びでも単元でも同じです。目安の初期値は、プロフィールの区分ごとに違います（2歳段階5分・3歳段階8分・4〜5歳10分・小学1〜2年15分・小学3〜6年20分）。2.0 までに作ったプロフィールの目安は、それまでの値（10分など）のままです。目安は保護者画面「せってい」で変えられます。
- **記録のバックアップ**: ときどき、保護者画面「データ」→「書き出し」で、記録をファイルに保存してください（詳しくは下の「記録のバックアップ」）。

## 新しいバージョンに更新するとき

### 2.1.0 から先: 保護者画面で「更新する」を1回押すだけ
1. インターネットにつながった状態でアプリを開くと、新しいバージョンがあるかを GitHub に接続して自動で確かめます。新しいバージョンが無ければ何も出ません。
2. 新しいバージョンがあると、保護者画面の上に「新しいバージョン ○○ があります」と出ます。「くわしく」を押すか、「このアプリについて」タブを開きます。
3. 変わった点とダウンロードする大きさを見て、「更新する」を1回押します。**お子さんが遊んでいないときに**押してください。
   - あとは自動です: ダウンロード → 中身の確認 → 切り替え → アプリの読み込み直し → 取得済みの小学生の教材の取得し直し。途中でもう一度押したり、端末を使ったりする必要はありません。
   - 画面に進み具合が出ます。保護者画面のほかのタブへ移っても続きます。ダウンロード中・展開中は「中止する」で止められます。
   - 終わるとアプリが1回読み込み直され、最初の画面に戻ります。保護者画面「このアプリについて」を開くと「○○ に更新しました」と出ています。
4. 学習の記録・作品・設定は**消えません**。
5. うまくいかなかったときは、理由と次にすることが出ます。ほとんどの場合、いまのバージョンのまま使えます。例えば、インターネットが切れたときは、つながってから「もう一度ためす」を押すと、ダウンロードした分の続きから始めます。空き容量が足りなくなったときは、ダウンロードした分を消して、空き容量を元に戻します。空きを作ってから「もう一度ためす」を押すと、最初からダウンロードし直します。

- 自動の確認を止めたいときは、「このアプリについて」の「起動したときに、新しいバージョンがあるかを自動で確かめる」のチェックを外します。止めていても、「今すぐ確かめる」を押したときは確かめます。
- 「このバージョンからは自動で更新できません」と出たときは、下の「2.0.x から 2.1.0 へ」と同じ手順（zip を4つダウンロードして1行を貼る）で、新しいバージョンを入れ直します。

### 2.0.x から 2.1.0 へ: この1回だけ、今までの手順で
2.0.x には自動で更新する仕組みが入っていないので、2.1.0 へは1回だけ、今までと同じ手順で入れ直します。2.1.0 を入れたあとは、上の方法で更新できます。

1. 手順1と同じページから、2.1.0 の zip を4つダウンロードします。
2. 手順2〜4と同じように、端末で1行を貼り付けて Enter を押し、「y」で進めます。
   - **貼り付ける1行の中のバージョンの番号（いまは `2.0.2`）を、新しいバージョンの番号（例: `2.1.0`）に書きかえてください。** 番号は1行の中に2か所あります。
3. 次にアプリを開くと、新しいバージョンを裏で準備します。保護者画面「このアプリについて」に「新しいバージョンがあります」と出たら「更新する」を押します（この1回だけ）。押さなくても、窓を全部閉じて開き直せば切り替わります。
4. 取得済みの小学生の教材は、2.1.0 のアプリが自動で取得し直します（「まとめて取得し直す」を押さなくてかまいません）。
5. 学習の記録・作品・設定は**消えません**。

## 困ったとき
| こんなとき | どうする |
|---|---|
| 端末に貼り付けられない | 端末では **Ctrl + Shift + V**（または右クリック →「貼り付け」）を使います |
| 「そのようなファイルやディレクトリはありません」「No such file or directory」と出る | zip がダウンロードフォルダに無いか、ファイル名が違います。手順1で4つとも保存できたか、ファイルの名前が `manabi-no-niwa-` とバージョンの番号で始まっているかを確かめてから、手順3をもう一度行います |
| 「教材の音声が足りません」と出る | 4つの zip のどれかが足りないか、ダウンロードが途中で止まっています。表示された名前の zip（例 `…-audio-g5-g6.zip`）をダウンロードし直して「ダウンロード」フォルダに置き、手順3をもう一度行います |
| 「python3 が見つかりません」と出る | ふつうの Zorin OS では起きません。出た場合は、端末で `sudo apt install python3` を実行してから（パソコンのパスワードを聞かれます）、手順3をもう一度行います |
| 「空き容量が足りません」「No space left on device」と出る | 不要なファイルを消して 10GB 以上空けてから、手順3をもう一度行います |
| 「途中で止まりました」と出て、「アプリ本体（…）は、まだ入っていません」とも出る | 手順3をもう一度行います（学習の記録は消えません）。「前のバージョンは…に残っています。消さないでください」と出たときも同じです |
| デスクトップのアイコンが開かない | アイコンを右クリック →「起動を許可する」を選びます。または、画面左下のメニューで「まなびのにわ」を検索して開きます |
| 画面が出ない・真っ白のまま | 1分ほど待ってから、ブラウザの窓を閉じて、もう一度アイコンから開きます |
| 音が出ない | パソコンの音量と、保護者画面「せってい」の音量を確かめます |
| 小学生の教材が開けない（「おうちの ひとに ダウンロードを たのんでね」「あたらしい きょうざいを とってきてね」と出る） | 手順7で、その学年の教材を「取得する」（バージョンが古いときは「取得し直す」）を押して準備します |
| 記録が消えたように見える | ブラウザを変えた（Firefox ↔ Chromium）か、ブラウザの「閲覧データの削除」をした可能性があります。保護者画面「データ」で書き出したファイルがあれば、「読み込み」で戻せます |
| 保護者画面に「更新できませんでした」と出る | 表示された理由に従います。インターネットが切れた・空き容量が足りないときは、直してから「もう一度ためす」を押します。「いまのバージョンはそのまま使えます」と出ていれば、そのまま使えます |
| 「アプリのファイルの切り替えで問題が起き、元に戻せませんでした」と出る | **パソコンを再起動する前に**「もう一度ためす」を押します（前のバージョンに戻してから入れ直します）。直らないときは、「新しいバージョンに更新するとき」の「2.0.x から 2.1.0 へ」と同じ手順で、新しいバージョンを入れ直します（学習の記録は消えません） |
| 更新のあと、アプリが開かない | 「新しいバージョンに更新するとき」の「2.0.x から 2.1.0 へ」と同じ手順で、新しいバージョンを入れ直します（学習の記録は消えません） |
| アイコンを押したら、前の画面が消えて「はじめる」の画面になった | ブラウザをふだんの使い方で先に開いていたときなど、開いている窓を前に出せないときの動きです。新しい窓で開き直しています。学習の記録は消えません。ブラウザの窓をすべて閉じてから、アイコンで開き直してください。次からは、開いている窓を前に出せる場合があります（実機では確かめていません） |
| 全画面から戻れない | F11 キーを押します（ノートパソコンでは Fn キーを押しながら F11 キー）。保護者画面のボタンで全画面にしたときは、Esc キーでも戻ります。キーボードが無いときは、3本の指で画面を上になでて窓の一覧を出し、窓の × を押します（実機では確かめていません） |
| 「べつの まどで ひらいています」と出る | まなびのにわが、ほかの窓で開いています。この窓は閉じてかまいません。ほかの窓を閉じると、数秒後に、この窓が「はじめる」の画面に戻ります。この窓で続けたいときは、「この まどで ひらく」を押します |
| 窓が2つ開く | Firefox と Brave など、2種類のブラウザで開いていないか確かめます。2種類のブラウザは、お互いの窓が見えません。記録も別々になります。1つのブラウザだけで使ってください |
| 教材を取得している途中でアイコンをもう一度押したら、取得が止まった | 前の窓が消えて新しい窓で開き直したときは、前の窓で取得していた教材が途中で止まります。保護者画面の「きょうざい」で、もう一度「取得する」を押します |

## 入れたアプリを消すとき
端末（Ctrl + Alt + T）で次の1行を貼り付けて Enter を押します。

```bash
bash ~/.local/share/manabi-no-niwa/app/deploy/zorin/uninstall.sh
```

- アプリとアイコンが消えます。更新の設定（`~/.config/manabi-no-niwa/`）と、更新の作業用のフォルダ（前のバージョンの控え・ダウンロードの途中のファイル）も消えます。学習の記録はブラウザの中にあるため、これでは消えません。記録も消すときは、先に保護者画面「データ」で必要なら書き出してから、ブラウザの設定でこのアプリ（`127.0.0.1:8765`）のサイトデータを削除します。
- ダウンロードした zip と、ホームフォルダの `manabi-no-niwa` フォルダは、ファイルの画面で削除してかまいません。

## 詳しい情報（技術的な説明）

### アドレスとブラウザ
- アプリのアドレスは必ず **`http://127.0.0.1:8765/`** です。ポートやアドレスを変えると、学習データが別のものとして扱われ、見えなくなります。ブラウザのプロファイルも変えないでください。
- `index.html` を `file://` で直接開いても、オフライン機能（PWA）は動きません。デスクトップのアイコンから開いてください。
- デスクトップのアイコンは、裏で小さな配信プログラムを起動します。この配信プログラムは `127.0.0.1` だけで待ち受けます。外からは接続できません。そのあと、Chromium 系（Chromium・Google Chrome・Brave）があればアプリ窓で、無ければ Firefox で開きます。使うブラウザは環境変数 `MANABI_BROWSER` で指定できます。
- 配信は窓を閉じても裏で動き続けますが、とても軽いです。止める場合: `pkill -f deploy/zorin/serve.py`。
- 最初に開いたときは、全画面にしません。全画面になるのは、保護者画面の「せってい」のボタンを押したときと、開いているときにもう一度アイコンから開いたときです。F11 キーで、いつでも元に戻ります。保護者画面のボタンで全画面にしたときは、Esc キーでも戻ります。

### 二重起動の防止（アイコンを2回押したとき）
同じブラウザの中では、まなびのにわの画面は、いつも1つです。アイコンをもう一度押したときは、次の順で動きます。

1. アイコンを続けて押しても、起動の処理は1つずつ順に進めます（`flock`）。
2. すでに開いている窓があれば、新しい窓は開きません。その窓を前に出して、全画面にします（`deploy/zorin/mnwwindow.py`）。見つけられるのは X11 の窓です（Xorg のセッションのすべての窓と Wayland のセッションの XWayland の窓）。題名が「まなびのにわ」で、アプリ用の窓であるものを探します。ブラウザが Chromium 系（Chromium・Google Chrome・Brave）で開くパソコンでは、Firefox の窓は前に出しません。
3. 窓が見つからないとき、または前に出せなかったときは、今までどおり新しい窓で開きます。そのときは、アプリの中で新しい画面だけが残り、前の画面は保存を済ませてから閉じます。前の画面が自分を閉じられないときは、「べつの まどで ひらいています」とだけ出します。新しい画面は「はじめる」の画面から始まり、「はじめる」を押したときに全画面になります。学習の記録は消えません。

Wayland のセッションで Chromium 系のブラウザを新しく起動するときは、`--ozone-platform=x11` を付けて起動します。ブラウザの窓が XWayland の窓になり、上の2で探せるようになるためです。次の場合は付けません: ブラウザが Firefox のとき、画面の分数スケーリングが有効なとき（窓がぼやけるため）。
- 付けるのは、ブラウザのプロセスが新しく立ち上がるときだけです。すでに開いているブラウザには効きません（そのときは上の3のとおりになります）。
- そのブラウザのプロセスが動いているあいだは、保護者がふだん開く窓も XWayland の窓になります。記録（`127.0.0.1:8765` のデータ）とプロファイルは変わりません。ブラウザの窓をすべて閉じると、元に戻ります。
- X11 には、同じ画面で動くほかのアプリが、キー入力や画面の内容を読み取れる仕組みがあります。気になるときは、環境変数 `MANABI_OZONE=native` を設定してください（下の表）。

注意点が1つあります。お子さんが使っているあいだに、同じブラウザで開いたほかのサイトのページが `127.0.0.1:8765` を開くと、お子さんの窓が「べつの まどで ひらいています」に替わることがあります。学習の記録は消えません。「この まどで ひらく」を押すか、アイコンをもう一度押すと戻ります。遊んでいた途中の場面は引き継がれず、「はじめる」の画面から始まります。このとき、ほかのサイトが得るものはありません（窓が入れ替わるだけです）。この動きを防ぐ仕組みは、次のバージョンの候補にしています。

環境変数（困ったとき・開発者向け）:

| 変数 | 意味 |
|---|---|
| `MANABI_SINGLE_INSTANCE=0` | 窓を前に出す処理と、`--ozone-platform` の指定をやめます（アプリの中の「画面は1つ」は止まりません） |
| `MANABI_OZONE=x11` または `native` | `--ozone-platform=x11` を、必ず付ける／付けない |
| `MANABI_BROWSER` | 使うブラウザ。そのコマンドに `--ozone-platform=…` が書いてあれば、それを優先します |

結果は `~/.local/state/manabi-no-niwa/launch.log` に1行ずつ書きます（最大 200 行）。書くのは、結果、見つけた窓の種類、全画面になったかどうかだけです。ほかの窓の題名は書きません。

**実機では確かめていません。** Zorin OS の実機で、窓が前に出て全画面になるかは、`docs/device-checklist.md` の「二重起動」の項目で確かめます。

### 自動起動（任意）
ログインしたときに配信を自動で始めたい場合は、手順3の1行の最後の `install.sh` を `install.sh --autostart` にして実行します。配信は systemd のユーザー単位のサービスとして、ログイン中だけ動きます。やめる場合: `systemctl --user disable --now manabi-no-niwa.service`。

### 配布物の構成
- 本体 `manabi-no-niwa-<バージョン>.zip` と、小学生の教材の音声 `-audio-g1-g2.zip`・`-audio-g3-g4.zip`・`-audio-g5-g6.zip` に分かれています（ZIP のファイル数と GitHub の添付の大きさの上限のため）。どれも中の最上位が `manabi-no-niwa/` で、同じ場所に展開すれば1つにそろいます。
- `install.sh` は、教材パックのファイル（packs.json）がそろっているかを確かめ、足りなければ止まります。アプリ本体は `~/.local/share/manabi-no-niwa/app/` に配置し、アプリ一覧とデスクトップに「まなびのにわ」を作ります。`--yes` で確認を省けます。

### 通信が必要な場面
| 場面 | インターネット | 説明 |
|---|---|---|
| 導入時 | 必要 | 配布 zip を入手するときだけ。`install.sh` は通信しません |
| 初回の準備 | 不要 | `127.0.0.1` の配信から本体のファイルをブラウザに保存します。画面に準備の割合が出ます |
| 小学生の教材の準備 | 不要 | `127.0.0.1` の配信から取得します |
| 日常の利用 | 不要 | アプリ（ブラウザ）は外部へ通信しません（広告・解析・音声合成サービスなし）。配信が起動して15秒後と、その後12時間ごとに、新しいバージョンがあるかを GitHub に確かめます。つながっていなければ何もしません。保護者画面で止められます |
| 更新時 | 必要 | 2.1.0 から: 保護者画面の「更新する」で、GitHub から変わった部分の zip だけをダウンロードします。2.0.x からは配布 zip を手で入手します。その後の新しいバージョンの準備は `127.0.0.1` だけです |

### 更新の仕組み（2.1.0 から）
- 外へ通信するのは配信（`serve.py`）だけで、新しいバージョンの確認とダウンロードのときだけです。行き先は `https://github.com/das0427/manabi-no-niwa/releases/…` と GitHub の配布用のホスト（`release-assets.githubusercontent.com`・`objects.githubusercontent.com`）だけで、プログラムに固定しています。転送のたびに、ホストとパスを確かめます。パスは、github.com ではこのリポジトリのリリースのものか、配布用のホストではリポジトリの番号が合うかを見ます。https の確認は、オフにできません。
- 送るのは HTTPS の GET と、アプリの名前（User-Agent: `manabi-no-niwa-updater`）だけです。バージョン・記録・個人の情報・Cookie は送りません。GitHub にはこのパソコンの IP アドレスが届きます（ふつうのウェブの閲覧と同じ）。
- アプリ（ブラウザ）は同じ `127.0.0.1:8765` の窓口（`/__manabi/update/…`）とだけ通信します（CSP の `connect-src 'self'`）。窓口はほかのサイトから呼べません。Host・Origin・Sec-Fetch-Site・JSON の Content-Type・起動ごとの合言葉を確かめます。ほかのサイトの枠（iframe）にも入れさせません。配信する画面・音声などのファイルも、ほかのサイトのページからは読み込めません（`Cross-Origin-Resource-Policy: same-origin`）。
- 入れる前に、大きさと sha256・zip の中のパス・中身・新しい配信の自己検査を確かめます。どれかが合わなければ入れずに、いまのバージョンのままにします。
- 組み立ては `~/.local/share/manabi-no-niwa/app.next` で行い、`app` と入れ替えます。前のバージョンは、新しいバージョンの配信が起動してバージョンを確かめるまで `app.prev` に残ります。作業用は `~/.local/share/manabi-no-niwa/update/`、設定は `~/.config/manabi-no-niwa/updater.json` です。sudo・システムの設定・サービスの登録・アイコンには触りません。待ち受けは `127.0.0.1:8765` のままで、学習の記録にも触りません。
- 保守用: `python3 ~/.local/share/manabi-no-niwa/app/deploy/zorin/serve.py --check-update` で、最新のバージョンの情報を1回取得して表示します。
- 環境変数 `MANABI_UPDATE_TEST_ORIGIN` は開発の試験用です（`http://127.0.0.1:<ポート>` だけを受け付けます）。本番のポート 8765 で動く配信にこれが設定されていると、更新の仕組みを止めます。
- 同じパソコンのほかの利用者のアカウント（OS のユーザー）のプログラムからも、窓口は呼べます。できるのは「公式の最新バージョンへの更新」「中止」「自動の確認のオン・オフ」「確認」だけです。
- 保護者画面を開くときの確認（長押しと足し算）は誤操作の防止で、認証ではありません。この確認を通れる年齢のお子さんがいるときは、保護者画面「せってい」で暗証番号を設定してください（更新や自動の確認の設定を勝手に変えられないように）。

### ブラウザごとの違い
- **Chromium 系**（Chromium・Google Chrome・Brave）: アプリ窓（`--app`）で開きます。PWA としてインストールもできます（実機では未確認）。
- **Firefox**: 通常のタブで使います。デスクトップ版の Firefox は通常 PWA のインストールができませんが、オフライン利用（Service Worker）は動きます。開発環境の Playwright で、準備後に配信を止めても開けることを確認しました。
  - Zorin でタッチがマウスとして扱われる場合は、Firefox を `MOZ_USE_XINPUT2=1` を付けて起動すると改善することがあります（実機未確認）。
  - Firefox はタブで開くので、アプリのタブが裏にあると、外から見つけられません。そのときは新しいタブで開き直し、前のタブは閉じます。Firefox で開くパソコンでは、題名が「まなびのにわ」と同じ別のサイトのタブが、前に出ることもあります。Chromium 系（Chromium・Google Chrome・Brave）で開くパソコンでは、Firefox の窓は前に出しません。
- ブラウザを変えると記録は別々になります。

## 保護者画面

ホーム右上の小さな鍵のボタンを **2秒長押し** → 表示された足し算に答えると開きます（任意で暗証番号に変更できます）。

- **これは子供の誤操作を防ぐためのもので、強固な保護ではありません**（ブラウザの開発者ツールなどで回避できます）。
- できること: 記録（自分でできた問題・ヒントを使った問題・まだ取り組んでいない内容・操作にとまどったかもしれない記録）、設定（音量・効果音・動きを減らす・利用時間の目安・1回の問題数・ホームの表示・なぞりの判定幅・難易度の固定）、作品、観察メモ、プロフィール（きょうだいで分けられます）、データの書き出し・読み込み、オフラインの準備状況、アプリの更新（新しいバージョンの確認・「更新する」・自動の確認のオン・オフ）。アプリの更新は 2.1.0 から使えます。
- 利用時間の目安（初期値は区分ごとに5〜20分）は医学的な推奨ではありません。目安に達すると、遊びでも単元でも、区切りで「きょうは ここまでに しよう」と出ます。

## 記録のバックアップ（大切）

記録・設定・作品は、このブラウザの保存領域（IndexedDB）にあります。

- **ブラウザの「閲覧データの削除」「サイトデータの削除」をすると、記録も消えます。**
- **アドレス（`http://127.0.0.1:8765/`）が変わると、別のアプリとして扱われ、記録が見えなくなります。** ポート番号やホスト名（`localhost` と `127.0.0.1` は別扱い）を変えないでください。
- ブラウザを変えた場合（Chromium ↔ Firefox）も、記録は別々です。
- 定期的に、保護者画面 →「データ」→「書き出し」でファイルに保存してください。
- 読み込みは「プロフィールとして追加する」が基本です。「すべて置き換える」は、いまのデータをすべて消して入れ替えます。確認のうえ、直前の状態を自動で書き出してから行います。
- 保護者画面の「データを守る」を押すと、ブラウザに保存の継続を求めます（ブラウザが許可しない場合もあります）。

### 音声の作り直し・差し替え
- 台本は `src/voice/catalog/common.ts` と各モードの `src/modes/<mode>/voice.ts` にあり、`npm run voice:script` で `voice/script.json`（全文の一覧）を出力します。
- `npm run voice:build`（Windows）／`npm run voice:build:sh`（Linux）で Open JTalk により `public/audio/*.mp3` を作り直します（手順: docs/assets-pipeline.md）。実行時は音声合成を使いません。
- 家庭で録音した声に差し替える場合は、`voice/script.json` の各キーと同じ名前の mp3 を `public/audio/` に置き、`public/audio/manifest.json` を更新してからビルドします。録音した声は公開リポジトリに含めないでください。
- **教材パックの音声**（`public/audio/<パック名>/`、数万本）は git に入れず、配布 zip にだけ同梱しています。リポジトリから自分でビルドするときは、`npm run voice:packs` で台本（`voice/packs/*.json`）を書き出し、パックごとに `python scripts/voice/generate.py --script voice/packs/<パック名>.json --out public/audio/<パック名>` で作ります（docs/assets-pipeline.md）。
- 音声ファイルが無い場合だけ、ブラウザの日本語読み上げで代わりに読みます。どちらも無い場合は無音になります。ひらがなの遊びでは、画面に「おとが でません。おとなの ひとが よんで あげてください」と出ます。

## 開発

```bash
npm install
npm run dev          # http://127.0.0.1:5173
npm run check        # 型・lint・format
npm test             # 単体テスト（Vitest）
npm run e2e          # E2E（Playwright: Chromium・Firefox）
npm run check:design # DESINGN.md の自動検査
npm run check:audio  # 台本と音声ファイルの突き合わせ
npm run build        # dist/ に本番ビルド
npm run package      # release/ に配布用 zip（元に git の外・変更・無視されたものがあると止まる）
```

- `npm run package` は、配布に入る元に、git の外のファイル・変更したファイル・無視されたファイルがあると、一覧を出して止まります。わざとのときは `npm run package -- --allow-dirty` を使います（公開する版では使いません）。git のタグ（これまでの版）を読めないときも止まります（`git fetch --tags`。わざと比べないなら `-- --no-tag-check`）。
- 教材パックの音声（`public/audio/<パック名>/`）は git に入れていないので、作りかけがあっても止まりません。公開の前に `git status --ignored public/audio` で作りかけが無いかを見てください。
- `release/` には、zip ごとに入れたファイルの一覧（`<zip の名前>.files.txt`）もできます。GitHub には上げません。詳しくは docs/expansion/updater-design.md の 3.6 節です。

## 保護者が子供と試すときの観察チェックリスト

数分そばで見て、気づいたことを保護者画面の「メモ」に残してください。
1. 自分で「はじめる」を押して、遊びを選べたか（どの絵を選んだか）
2. 問題の声を聞いて、何をすればよいか分かっていたか（「もういちど きく」を使ったか）
3. 間違えたとき、ヒントの後にもう一度試せたか。いやになってやめなかったか
4. どこで手が止まったか（操作が分からない／内容が難しい、のどちらに見えたか）
5. 「おうち」を自分で押して終われたか。「きょうは ここまでに しよう」で納得して終われたか
6. 次の日、自分から「やりたい」と言ったか
7. 遊んだ内容（数える・形・字）が、生活の会話や遊びに出てきたか

アプリでの指の練習は、鉛筆の持ち方や筆圧の練習とは別のものです。
