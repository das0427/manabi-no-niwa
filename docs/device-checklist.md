# 実機確認チェックリスト（device-checklist.md）

対象: Lenovo Yoga 720-12IKB（81B5000AJP）/ 12.5インチ 1920×1080 タッチ / Zorin OS Core
状態: **未確認**（開発は Windows 11 上で行い、実機を操作できなかった）。保護者または開発者が実機で確認し、結果を記入する。
自動テスト（Playwright）のタッチ模擬は、実機の指操作の確認ではない。

記入例: `[x] 確認日 2026-11-01 / Chromium 141 / OK` 、問題があれば GitHub Issues に登録。

## 1. 環境の記録
- [ ] Zorin OS の版（`cat /etc/os-release`）
- [ ] Python の版（`python3 --version`。3.8 以上なら配信スクリプトが動く想定）
- [ ] Chromium 系ブラウザの名前と版（Chromium / Google Chrome / Brave）
- [ ] Firefox の版
- [ ] 表示倍率（設定 → ディスプレイ → 拡大縮小。100% / 125% / 150% / 200%）
- [ ] タッチの方式（Wayland / X11。`echo $XDG_SESSION_TYPE`）

## 2. 導入と起動（README の手順どおりに）
- [ ] 配布 zip を展開し `bash install.sh` が確認つきで動く
- [ ] デスクトップとアプリ一覧に「まなびのにわ」が出る
- [ ] アイコンから起動して、ブラウザ（Chromium なら アプリ窓）で開く
- [ ] 2回目以降の起動で、配信が二重に起動しない（ポート 8765 が1つだけ）
- [ ] `--autostart` を付けた場合、再起動後も配信が動く（任意）
- [ ] Chromium で「インストール」（PWA）ができるか（可否を記録）
- [ ] Firefox で開いて使えるか（Firefox はインストール不可の想定）

## 3. オフライン
- [ ] 初回起動後、保護者画面「このアプリについて」で「オフラインで つかえます」になる
- [ ] Wi-Fi を切って再起動（PC ごと）→ アイコンから起動 → 全9モードを開始できる
- [ ] Firefox でも同じ
- [ ] 新しい版の zip で install.sh を再実行 → 次の起動で新版、記録が残っている

## 4. 表示（各表示倍率で）
- [ ] ホームの9つの札が全部見え、文字が切れない
- [ ] 横スクロールが出ない、要素が重ならない
- [ ] 主操作の札を定規で測る: ____ mm（目標 12〜15mm 以上）
- [ ] 隣の札との間: ____ mm（目標 4mm 以上）
- [ ] 問題文の文字が約40cm離れて読める（保護者の目で）
- [ ] グレースケール（アクセシビリティ設定）で、正解・誤答・ヒント・選択中が区別できる

## 5. 指タッチ（全9モード）
- [ ] 各モードを指だけで最後まで遊べる（なぞり以外はタップだけ）
- [ ] 隣のものを誤って押すことが多くない
- [ ] 長押しで文字選択・メニュー・拡大が出ない（子供画面）
- [ ] なぞり: 指の動きに線が遅れずについてくる。ページがスクロールしたり、戻るジェスチャーにならない
- [ ] なぞり: 指を離して続きから書ける
- [ ] みち: 盤面を触ってもページが動かない
- [ ] Firefox でタッチがマウスとして扱われていないか（なぞりの判定幅の表示や反応で確認。必要なら README の `MOZ_USE_XINPUT2=1`）
- [ ] タッチパッド・マウスでも全モードを操作できる
- [ ] ペン（電池交換後）: なぞりで使える。判定幅「ペン」の設定が効く

## 6. 音
- [ ] 「はじめる」の後に声が出る。内蔵スピーカーで聞き取れる
- [ ] 「もういちど きく」がいつでも効く。連打しても声が重ならない
- [ ] 画面を移ると前の声が止まる。別のアプリに切り替えると止まる
- [ ] 効果音が大きすぎない（保護者設定で調整できる）
- [ ] 数字（いっこ・にこ・さんこ…）とひらがな1字の読みが正しく聞こえる
