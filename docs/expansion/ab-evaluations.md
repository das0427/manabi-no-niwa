# A/B 的な比べ方の記録（ab-evaluations.md）

使いやすさの直し（FX）と比べ（AB）の結果をまとめる。リポジトリに入れるのは要約だけで、判定の答えの全文・伏せた資料・画面は作業の置き場に残す。子供の情報は書かない。

## 比べ方
- 子供では比べていません。アプリは利用者ごとに出し分けず、どちらを見たかも記録しません。本番のビルドに入るのは、いつも1つの作りだけです。
- 候補は3つに分けました。**直し（FX）**は、不具合か、DESINGN.md・ux-by-age.md・要件と明らかに食い違い、直し方が1つに決まるものです。判定を省き、直す前（基準のコミット）と後の数値と、規約との照合で入れました。**比べ（AB）**は、案の良し悪しが判断しだいのものです。**保留（HD）**は、設計の大きな変更や外部の調査が先に要るものです。
- 判定（AB）: 立場を決めた Opus の判定役が、新旧を X/Y で伏せた画面と声の記録を見て選びます（1候補に3人以上）。
- 数値: Playwright で新旧に同じ台本を流して測りました（操作の回数、押す的の大きさ、字数、声の手がかり、文字の配置など）。直し（FX）は、組の担当とレビュー担当が、それぞれ自分の台本で直す前と後を測りました。
- 採用の条件（AB）: 判定の過半数、数値が悪くならない、DESINGN.md などの規約に反しない、既存の検査が通る。満たさないものは今の作りのままです。
- 罰・点数・ランキング・連続日数・利用を延ばす導線を足す案は入れません。外部のトラッキング・アカウント・広告なし、学習記録は端末の中だけ、という方針は、判定の結果でも変えません。
- これは学習の効果を確かめたものではありません。子供の立場の判定は、大人が子供を思い描いたものです。人の聞き比べ・見比べ・家庭での試しはしていません（依頼者の方針）。
