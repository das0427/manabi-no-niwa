## 2. 単元の「実装済み」の条件（教材充足）

curriculum-matrix.md 2章の定義を正本とする（単元の種類ごとの問題数 N・M）。共通して次をすべて満たすこと:

1. 導入（おてほん）がある
2. 自力練習の**異なる**問題が種類別の数以上ある（生成問題は seed を変えて検査し、数字や位置だけの違いを別問題と数えない規則に従う）
3. 別例での確認（表現を変えた問題）がある
4. 誤答時の説明（典型的な誤りごと）、ヒント2段階、解説がある
5. 音声（台本と生成済み音声。英語は英語音声。未収録なら状態を partial にする）
6. 問題データが X-QA-01 の項目を持ち、X-QA-02 の自動検査に通る
7. 単元の状態が `ready`（`partial` は子供画面に出してよいが「実装済み」に数えない）

問題数と目標の網羅性は分けて報告する（単元が目標のどこまでを扱うか、扱わない内容）。

## 3. おえかきの受入条件（E2E・単体）

- 指（タッチ模擬）とマウスで: 細い／太い／速い線、キャンバスの端、消しゴム、塗りつぶし（閉じた形の中・すき間なし）
- はんこ: カテゴリから選ぶ→見本と大きさの確認→タップで配置→同じ絵柄を連続配置→押す前の左右反転・回転・大きさ→配置後の選択・移動・大きさ・回転・削除
- 図形: 7種、輪郭／塗り、輪郭の太さ、色、タップで配置、ボタンで大きさ・回転、選択・移動・削除
- 重なり: てまえへ／おくへ、重なった対象の選択（続けてタップで奥へ）、透明部分を通り抜ける
- undo／redo（線・塗り・消し・はんこ・図形・移動・変形・削除）
- 保存→アプリを閉じる→開く→再編集（はんこ・図形が動かせる）
- 中断（ページを閉じる）→再開で復元
- 画面サイズ変更で作品が消えない
- PNG 書き出しに選択枠が入らない
- 作品50件・はんこ200個の作品で、一覧と編集が操作できる（開発PCでの計測を記録。実機は未確認）

## 4. 旧版データの受入条件

- v1.0.0 で作った IndexedDB（プロフィール2つ、各モードの記録、なぞり・みちの作品、メモ、設定）を v2 で開いて: プロフィール・設定・作品・メモが残る／4歳の単元に確実に対応する記録は新しい進度として表示／不確かなものは「旧記録」として閲覧のみ／習得済みに変換されていない
- v1 の書き出しファイルを v2 で読み込める
- 移行の途中失敗で元データが残る
