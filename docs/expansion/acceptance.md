## 2. 単元の「実装済み」の条件（教材充足）

### 2.1 単元ごとの条件
curriculum-matrix.md 2章の定義を正本とする（単元の種類ごとの問題数 N・M）。共通して次をすべて満たすこと:

1. 導入（おてほん）がある
2. 自力練習の**異なる**問題が種類別の数以上ある（生成問題は seed を変えて検査し、数字や位置だけの違いを別問題と数えない規則に従う）。下限: 手作りは N≥8、生成は seed 20 本で異なる問題 ≥N（R#6。N の値は curriculum-matrix.md 完成時に確定）
3. 別例での確認（表現を変えた問題）がある。復習用に「別の表現の問題」が **2 種以上**ある（R#14）
4. 誤答時の説明（典型的な誤りごと）、ヒント2段階、解説がある
5. 音声（台本と生成済み音声。英語は Kokoro-82M で生成した英語音声で、試聴して問題が無いこと（R#17）。未収録・未試聴なら状態を partial にする）
6. 問題データが X-QA-01 の項目を持ち、X-QA-02 の自動検査に通る
7. 単元の状態が `ready`（`partial` は子供画面に出してよいが「実装済み」に数えない）

問題数と目標の網羅性は分けて報告する（単元が目標のどこまでを扱うか、扱わない内容）。

### 2.2 網羅の下限（機械検査。R#6）
`npm run curriculum:report` が次を検査し、満たさなければ失敗する。**数値は curriculum-matrix.md 完成時に確定**し、確定した値と日付をこの節に書く。

| 検査 | 条件 | 数値 |
|---|---|---|
| 領域の網羅 | 各学年の国語・算数で、学習指導要領の各領域に ready 単元が 1 つ以上 | — |
| 単元数の下限 | 各学年×教科（国語・算数）の ready 単元数 ≥ 下限 | matrix 完成時に確定 |
| 異なる問題の下限 | 2.1 の 2（手作り N≥8、生成は seed 20 本で異なる問題 ≥N） | N は matrix 完成時に確定 |

- `curriculum:report` の出力形式は**学年×領域の表**に固定する（行＝学年、列＝領域。各セルに ready／P1 総数）。

### 2.3 P1 一覧の凍結と変更の手順（R#6）
1. curriculum-matrix.md の完成時に、P1 単元の一覧を凍結する。凍結した matrix の版と日付を下の表の1行目に記録する。
2. 凍結後に P1 の単元を P2（または対象外）へ移すときは、変更の前に、単元ID・理由・日付をこの表に記録する。
3. 記録した変更は独立レビューを通す（レビュー記録を docs/expansion/reviews/ に置き、表に参照を書く）。
