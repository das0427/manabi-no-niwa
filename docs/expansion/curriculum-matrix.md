### 0.2 現行と次期

- 基準は**現行の小学校学習指導要領（平成29年告示）**。2026年10月時点で現行（EJM 2）。
- 次期学習指導要領は**未施行**として扱う（審議まとめ 2026-10-05、パブリック・コメント 10-06〜11-05、小学校の全面実施は令和12年度の想定: EJM 6、EOS 8）。次期の内容（算数の領域再編、情報の領域、AIへの指示など）は学年配当にも単元にも使わない。学年タグは教材データの設定値で持ち、告示後に本表を改訂する。
- 漢字は**2020年度以降の配当表**（都道府県名の20字追加、計32字の配当学年の移行）。旧配当の教材と学年がずれる字があることを保護者画面に注記する（EJM 3-1）。
- ローマ字は**令和7年内閣告示第4号**（ヘボン式に準ずる）を現行とする（EJM 3-3）。

### 0.3 学年配当の確定度

| 教科 | 学年の決まり方 | 本表での扱い |
|---|---|---|
| 算数・理科・社会 | 指導要領が学年別に示す | 学年は確定 |
| 国語（漢字以外） | 第1・2学年、第3・4学年、第5・6学年のまとまり | 学年の割当は**本アプリの案**（※印）。教科書で前後する（EJM 2） |
| 漢字 | 学年別の配当表 | 確定 |
| 生活 | 第1・2学年のまとまり | ※ |
| 外国語活動・外国語 | 3・4年、5・6年のまとまり。語・表現の学年配当はない | ※ |
| 幼児 | 公的資料は3〜5歳を分けない（EC 2.0） | 年齢は**目安**。保護者が段階を選ぶ |

### 0.4 対象外の扱い

- **教科として対象外**: 音楽、図画工作、家庭、体育、特別の教科 道徳、総合的な学習の時間、特別活動。理由: 依頼範囲外、かつ実技・体験・対話が本体。全年齢共通の「おえかき」は教材ではないので、本表では**学習連携**（3.10）だけを扱う。
- **単元の中で対象外**にするもの（2.5 に扱いを定める）: 自由作文の評価、話す・発表・話し合い・音読の評価、英語の話す・書く（自由に書く文）の自動評価、手書きの字形（ひらがな・カタカナ・漢字・英字）の正誤、毛筆、タイピング（ローマ字入力は情報・総合の内容）。
- **実体験が本体のもの**（観察・実験・飼育・栽培・町探検・ものづくり）は代替しない。事前の予想と事後の記録・整理の補助に限る。火・薬品・発熱を伴う実験の手順は示さない（結果の読み取りのみ）。
- **地域依存**（身近な地域・市区町村・県内の地域）は、正解を固定しない。一般的な例か、保護者・子が入力する形。
- **時事・統計**は「れいの データ」と表示し出典年を付けた例示データで、読み取りの練習に使う（EOS 5.2）。

## 1. 教材充足の受入条件（実装前に決める）

### 1.1 状態の定義

| 状態 | 条件 |
|---|---|
| 未実装 | — |
| 試作 | 遊べるが、1.2 の必須要素または 1.3 の量のどれかが未達 |
| **実装済み** | 1.2 の必須要素すべて、1.3 の量（Q≥1.0）、1.5 の網羅（C=全部）、1.8 の自動検査に合格 |
| 確認済み | 実装済み＋内容の点検（学年配当・ふりがな・正答の幅・誤概念の説明）＋実機での試用記録（子供または保護者） |
| 旧記録 | 統合・廃止で新しく出題しない。記録は閲覧のみ |

### 1.2 必須要素（全単元。採点しない「記」は 4・6・10 を除く）

| # | 要素 | 条件 |
|---|---|---|
| 1 | 導入 | 単元の最初の回に、お手本（解き方を見せる）を自動で出し、以後は「おてほん」でいつでも見られる。算数は**具体物 → 絵・図（ブロック、テープ図、数直線）→ 記号**の3段を持つ。国語・知識は「提示 → 例 → 確かめ」。導入は練習の問題数に数えない |
| 2 | 自力練習 | 1.3 の N・M 以上の異なる有効問題（同一性は 1.4） |
| 3 | 別例での確認 | 練習と**表現を変えた**問題（式↔文章題↔図、横書き↔縦書き、語の中↔文の中、別の道具・別の目盛り、別の文種）を到達項目ごとに3問以上。練習の数とは別に数える |
| 4 | 誤答時の説明 | 単元ごとに典型的な誤り（誤概念）を列挙する（計・概は3つ以上、他は2つ以上）。誤りの選択肢・入力に誤概念IDを付け、IDごとに説明文と図を持つ。誤概念IDのない汎用の誤答応答は、誤答候補全体の20%以下 |
| 5 | ヒント | 段階式。幼児は2段階（LD 0.2 の規則をそのまま使う）。小学生は3段階（①何を見るか ②図・途中式の一部 ③最後の一手を残した途中まで）。どの段階でも答えそのものは示さない。最後は「つぎへ」で出られる |
| 6 | 解説 | 問題ごと（生成ならテンプレートごと）。正解後・「つぎへ」の後に見られる。図つきが原則。小1・小2は音声つき |
| 7 | 後日の復習 | 復習の単位を決め、間隔反復の対象に登録する（1.6） |
| 8 | 音声 | 1.7 の規則 |
| 9 | 表記 | ふりがな規則（2.1）、字体（配当表の字体）、数字・単位の表記の自動検査に合格 |
| 10 | 正答の定義 | 等価表現・許容誤差・複数解・順不同を問題データに持つ（2.4） |
| 11 | 根拠 | 本表の根拠と学年タグを単元データに持つ |

### 1.3 量の基準（単元の種別ごとの N・M）

| 種別 | 生成のとき N | 手作りのとき M | 類型・到達項目ごとの最低 | 補足 |
|---|---|---|---|---|
| 計 計算 | 異なる有効問題 **100以上**（定義域が100未満なら**全件**） | — | 類型ごとに **10**（定義域が小さければ全件） | 文章題は場面テンプレート**8以上**、意味の型（合併・増加・求残・求差、等分除・包含除 など）を**2種以上**。数値だけ違う文章題は同じ場面 |
| 概 概念 | **60以上** | **30以上** | 到達項目ごとに **6** | 表現（具体物の絵・図・数直線・言葉）を**3種以上** |
| 読 読解 | — | 本文 **8本以上**、設問 **30以上** | 観点（順序・人物・中心文・要旨など）ごとに **5問** | 文種を**2以上**（物語・説明・図表つき など）。本文は本アプリのオリジナル（昔話・古典の再話は著作権の切れた原典から自作） |
| 知 知識 | 項目リスト**全件** | 1項目に**2問以上**（形式か文脈が違う） | — | リストが15項目未満なら合計**30問以上** |
| 運 運筆 | 対象の線・字の**全件** | — | 1題ごとに お手本アニメ・なぞり・お手本比較 | 字形の正誤は採点しない |
| 探 探究 | — | 場面 **6以上**、設問 **24以上** | 1場面に「予想・条件・結果・考察」のうち**3段以上** | データは例示データと明示。実験の代替と書かない |
| 記 記録 | — | 問いかけ **6以上** | — | 採点しない。保護者画面に表示 |
| 遊 幼児 | 段階ごとに **12以上**（L2 は **8以上**。定義域が小さければ全件） | 同左 | — | 同一性は LD 0.6 |

### 1.4 水増しを数えない基準（同一性キー）

- **異なる問題** = 正規化した「同一性キー」が異なる問題。キーは単元仕様で定義し、問題データに持つ。
- **同じとみなす差**: 正解の位置、選択肢の並び、背景・色、登場人物の名前、品物の絵柄（絵柄が学習内容でないとき）、図形の平行移動と拡大縮小（大きさが学習内容でないとき）、表示サイズ、ふりがなの有無、単位記号の字形（cm と ㎝）。
- 図形の**回転・裏返し**は、向きが学習内容でない単元では同じ。合同・対称・展開図・方位・位置の単元では別。
- **計算**: 式が違えば別。ただし交換法則が学習内容でない単元では、交換しただけの式（3＋5 と 5＋3）は同じ。
- **文章題**: 「場面テンプレート × 意味の型」を1件とする。数値だけ違うものは**場面数に数えない**（N は式の側で数える）。
- **知識**: 同じ項目で誤りの選択肢だけ違うものは同じ。同じ漢字の同じ読みでも、語例が違えば別（「やま」: 山道／高い山）。
- **読解**: 同じ本文の同じ設問の言い換えは同じ。
- **生成器の検査**: seed 0〜999 で生成し、自動検査（1.8）に通った問題の同一性キーを数えて N 以上。1つのキーが全体の3%を超えない（偏りの検査）。類型ごとの最低数も同じ方法で数える。

### 1.5 問題数と網羅性を分けて評価する

- **到達項目**: 各単元の目標を2〜8の到達項目に分ける（例 g1.math.add-carry: ①10のまとまりをつくる ②加数を分解する ③被加数を分解する ④増加の文章題 ⑤合併の文章題 ⑥式から場面を選ぶ）。実装担当が単元仕様に書き、本表の目標を超えない。
- **量 Q** = 異なる有効問題数 ÷ 基準（N または M）。**網羅 C** = 必須要素（導入・練習6問以上・別例確認・誤答説明・解説）がそろった到達項目の数 ÷ 到達項目の数。
- 報告の書き方: 「Q 1.3 / C 6/6」。**実装済み = Q≥1.0 かつ C が全部**。Q が大きくても C が欠ければ実装済みにしない（同じ類型だけ大量にある状態を防ぐ）。
- 進度の判定（LD 0.3・architecture 4.4 の「10件中8件の independent」）は到達項目ごとの窓で行う。単元の習熟 = 全到達項目の習熟。

### 1.6 後日の復習（間隔反復）

- 対象: 小1以上の P1・P2 単元すべて。幼児は間隔反復をしない（ホームのおすすめに再提示するだけ）。L2（2歳段階）は記録に基づく提案もしない（EC 4.3）。
- 単位: 知識=項目（字・語・記号）、計算=類型（復習のたびに新しい数値で生成）、概念・探究=到達項目、読解=観点（初見の本文を使う。同じ本文は30日以上空ける）、運筆=字。
- 間隔（独、効果未検証、保護者設定で変更可）: 習熟した日から 1・3・7・14・30・60 日。復習で independent なら次の間隔へ、誤答なら1日に戻す。1日の復習は最大5問で、その日の最初に「ふりかえり」として出す（飛ばせる）。
- 復習の誤答は単元の習熟を取り消さない。保護者画面に「ふくしゅうで まちがえた」を別に示し、誤概念IDから前提単元を提案する（5.3）。

### 1.7 音声

| 対象 | 規則 |
|---|---|
| 幼児 | 指示・選択肢の名前をすべて音声で。音声が手がかりの問題は最初の再生中は選択肢を無効（LD 0.1） |
| 小1・小2 | 問題文・選択肢・ヒント・解説を全文読み上げ（自動再生。設定で切替） |
| 小3〜小6 | 読み上げボタン（既定は手動）。国語の読解本文の読み上げは任意。漢字の読み問題は、答えになる部分を読み上げない |
| 英語 | listen は音声が本体（必須）。人の録音か品質確認済みの合成音声。発音の正誤判定はしない |
| 音が出ない環境 | 幼児と英語 listen はモードの最初に保護者向けの案内を出す（LD 2 の方式） |

### 1.8 自動検査（全単元共通。CI で実行）

1. 正答が一意（または定義した集合）。誤りの選択肢が正答の等価表現になっていない。
2. ふりがな規則（2.1）、配当外漢字・表外字の検出。
3. 数の範囲（単元の定義域）、単位の一致、読み上げキーの存在。
4. 図・式・読み上げを同じ問題データから導いていること（LD の M9-08 の方式）。図の個数と数値の一致。
5. 同一性キーの数と偏り（1.4）、誤概念IDの付与率（1.2-4）。

## 2. 横断の規則

### 2.1 ふりがなと使う漢字の規則

- **基準学年 B** = min（単元の学年, 子のプロフィールの学年）。幼児・学年未設定は B=0。
- 表示する文（問題文・選択肢・ヒント・解説・読解本文）の漢字:

| 漢字の配当学年 | 扱い |
|---|---|
| B より前の学年 | ふりがななし（保護者設定で「すべてに ふりがな」も可） |
| B の学年 | ふりがなを付ける（当該学年の字は学習途中で、教科書ごとに学習時期が違うため） |
| B より後の学年、小学校配当外の常用漢字 | 原則ひらがなで書く。教科の用語・固有名詞で必要なものだけ、ふりがな必須 |

- 漢字の**読み**の答えは小学校で学ぶ音訓に限る。音訓の段階別の割り振りの資料は**要確認**（調査メモに未記載。実装前に確認）。
- 自動検査: 学年タグ付き漢字表（2020年度配当、1026字）と照合（1.8-2）。

### 2.4 正答の定義（共通）

- 数: 全角半角・桁区切り・先頭ゼロ・末尾ゼロ（0.50＝0.5）を正規化する。
- 小数と分数: 問題ごとに「形式指定（小数で／分数で）」か「等価なら正」を持つ。4年以前は形式指定を既定にする。
- 分数: 「既約のみ正」「等価も正」「仮分数・帯分数のどちらも正」を問題ごとに指定。解説は既約で示す（答えの形の慣習は教科書で差があり**要確認**）。
- 単位: 問題が単位を表示するか、子が選ぶかを指定。「□m□cm」は複数欄。
- あまり: 「商」と「あまり」の欄を分ける。
- 許容誤差: 角度±1〜2度、目盛りは最小目盛りへ吸着、およその面積は範囲で判定。円周率は3.14。
- 複数解・順不同: 集合一致（約数の列挙、場合の数）。
- かけ算の式の順序: 既定は答えだけを判定（EJM 5-1）。式を問う問題は「場面に合う式」を選択肢で問い、判定の基準を解説に書く。
- ローマ字: 長音は ō・ou・oo を許容（問題の指定がない限り）。訓令式は誤りにせず「あたらしい かきかたでは shi」と案内（EJM 3-3）。

### 5.3 先取り・さかのぼりの入口

- **学年と位置を分けて持つ**: プロフィールの学年（ふりがな・既定の表示に使う）と、単元ごとの進度は別に持つ（design-benchmark-notes の採用候補の原則と同じ考え）。記録は単元IDで持つので、学年をまたいでも消えない。
- **さかのぼり**: 単元の最初に「じゅんび チェック」（前提単元の到達項目から3〜5問。生成問題）。2問以上誤ったら、前提単元のその到達項目を「さきに これを やってみよう」と提案する（強制しない、飛ばせる）。復習や練習の誤答の誤概念IDからも前提を引く（例: 繰り下がりの誤り → g1.math.sub-borrow の到達項目③）。
- **先取り**: 単元が習熟したら、5.2 の鎖で次の単元を「つぎの がくねんの ないよう」の印つきで提案する。保護者設定「先取りを許可」の既定は1学年先まで。幼児から小1への先取りは保護者が開いたときだけ（4.4）。
- 先取りした単元の文は、2.1 の基準学年 B（子の学年）でふりがなを増やす。
- 学年の途中の目安（「何月ごろ」）は教科書に依存するため本表では決めない（要確認）。
