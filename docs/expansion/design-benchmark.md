# 他社教材・アプリのデザインベンチマーク（design-benchmark.md）

- 対象: まなびのにわ 拡張（2〜3歳〜小6、全年齢のおえかき）で、画面・体験の要件を決めるための参考
- 確認日: **2026-10-24**（全対象）。元の調査ノート: `docs/expansion/research/design-benchmark-notes.md`、おえかきは `drawing.md`
- 資料の根拠の種別・研究の扱いは `research.md` を参照（B1〜B14、E1〜E2）

## 0. 方法と限界

- 公開ページ・公開動画・公式ヘルプ・公開記事だけを見た。登録・購入・資料請求・アプリの起動はしていない。画像・動画は保存していない。
- ページ本文は取得ツールの要約を通して読んだ。有料画面と実機での操作感（ヒントの出方、誤答後の流れ、音声の長さ）はほぼ未確認。
- 「観察事実」は公開情報に書かれていた仕様・見えた画面で、**その設計が子供に効く根拠ではない**。宣伝（満足度、No.1、効果の主張）は観察と分けて「宣伝」と書く。いずれも独立した検証は確認できていない。

## 1. 複製しない・誤認させない方針

1. 他社のキャラクター、世界観、レッスン名・機能名、文言（ほめ言葉・促しの決まり文句を含む）、画面構成、イラスト、音声、効果音、コード、素材を複製しない。本書の固有名は参照のためだけに使い、アプリの文言・名称・画面に持ち込まない。
2. 提携・監修・公式・準拠と誤認させる表示をしない。画面・README・説明文に他社名や「○○式」「○○と同じ」を書かない。
3. 他社が採用していることを、正しさの根拠にしない。採るのは一般化した原則だけで、採用の理由は各対象の「理由」欄に書く。
4. おえかきは Tux Paint（GPL、素材の許諾が混在）のコード・素材・アイコン・効果音を流用しない。公開ドキュメントの仕様の観察だけに使う。

| 制約 | ホバー前提のプレビューはタッチで再現できない。素材の許諾が混在。 |
| 採用判断 | **一部採用** |
| 理由 | 簡易化と名前を聞かない保存は、文字が読めない年齢でも使える形として採る。図形の二段階回転は幼児に向かないため、ボタン操作に置き換える。はんこの扱いは統括の決定（再編集できるオブジェクト）を優先し、消しゴム・塗りとの規則を別に決める（research.md §10-5）。 |

## 3. 採らないパターン

ガチャ・くじ・ランダム報酬を完了に結びつける／ポイント・物品交換、ランキング、連続日数の維持／残念そうな表情や音で続行・課金を迫る／子供画面の広告・外部リンク・課金・共有誘導／時間切れ・「あと少しで消える」などの焦らせる表示、通知の乱発／大きな不正解音、赤い×の連続／装飾が操作領域や問題文に重なる／保護者がいないと進めない構造、または「保護者なしでも大丈夫」と断定する表現／個人情報の過剰な収集／未確認の効果・数値を画面や文言に書くこと／他社のキャラクター・世界観・固有の名称の模倣。

## 4. このアプリで一貫させる体験の原則（統合方針）

他社から部分を寄せ集めると体験が不揃いになる。そこで、**骨格は全年齢で同じにし、年齢差は決められたパラメータ（量・文字・操作・音声・保護者の関与）でだけ変える**。下の原則に合わない他社の工夫は、どれだけ一般的でも採らない。

| ID | 原則 | 主な由来 |
|---|---|---|
| UX-01 | 始める前に1回の量（問題数か作品1つ）と終わりを見せる。終わったら続けるよう促さない | B1、B3、B5、B8、CX-01、CX-04 |
| UX-02 | 画面が「みる（お手本）」「やってみる」「たしかめる」のどれかを、形と言葉で区別する。幼児は「みる→やってみる」の2つまで | B1 |
| UX-03 | 1画面に主な課題は1つ、主ボタンは1つ。「つぎへ」「もういちど」「おうち」は形と位置で区別する | B7、FB-06 |
| UX-04 | 教材（問題・図・線）と装飾を分け、操作領域に装飾を重ねない。慣れたら装飾を減らせる | B7、Y2 |
| UX-05 | ヒントは段階的に出し、考える機会を残してから答えに近づける。ヒント後の正解は区別して記録 | B4、FB-02、FB-03 |
| UX-06 | 誤答は「間違い」と言わず、見直す場所と次の一手を示す。赤い×・ブザーを使わない | B1、FB-01、COL |
| UX-07 | 報酬は静かな記録（作品、できたこと、日付）だけ。ガチャ・ポイント・連続日数・ランキングを置かない | B8、B12、CX-06 |
| UX-08 | 学年（目安）と段階（実力）を別に持ち、開始段階を選べる。戻る・進むは提案として示す | B2、B6、AD-02 |
| UX-09 | 復習は「おすすめ」と「自分で選ぶ」の両方。間隔をおいて自然に挟む | B2、B8 |
| UX-10 | 操作の種類を年齢で段階化（タップ→なぞり→手書き→入力）。ジェスチャには必ず同じ働きのボタンを用意し、反応領域を広げ、縁と下端中央を避ける | B3、B10、E1、Y6、Y8 |
| UX-11 | 音声はいつでも止められ、聞き直せる。音量の急変を避ける。幼児は音声が主、小学生は文字が主で音声は任意 | B3、B4、B14 |
| UX-12 | 保護者の画面は子供の画面と入口を分け、記録・設定・ほめる観点・声かけ例を置く | B1、B4、B7、B10 |
| UX-13 | 親子で使う場面を前提に作る（2〜3歳は大人が隣）。「ひとりでできる」と断定しない | B3、B5、B10、Y9 |
| UX-14 | 子供画面に広告・外部リンク・課金を置かない。名前はニックネーム、録音・写真は既定で保存しない | B10、B13、BC-03、RP-02 |
| UX-15 | 画面の骨格（ホーム→あそび→おわり→きろく）と共通部品（おうち・もういちど きく・ヒント）の位置と見た目を全年齢で同じにする | 統合方針（本書） |

## 5. 年齢差の扱い

数値や区分は他社の観察（観察）、研究（研究、research.md Y8〜Y12）、本書の推論（推論、効果未検証）を区別する。

| 観点 | 2〜3歳 | 4歳 | 5歳 | 小1〜2 | 小3〜4 | 小5〜6 |
|---|---|---|---|---|---|---|
| 文字 | 読ませない。絵と声だけ（研究） | 文字なしで進める。読める子は文字も見られる（研究） | 短いひらがなを併記。カタカナは読みまで（推論） | ひらがな中心、配当漢字はふりがな付き（research.md §10-3） | 漢字を増やし、上の学年の漢字にふりがな | 通常の文。ふりがなは保護者設定 |
| 操作 | タップだけ。判定ありのなぞりなし（研究） | タップ中心、なぞりは線・形（研究） | なぞりで字。ドラッグは任意（研究・観察） | なぞり・手書き（判定は広め）（観察） | 入力（数字・ローマ字）を追加（観察） | 入力と図の操作（目盛り合わせ等） |
| 選択肢の数 | 2つまで（推論） | 3〜4（推論） | 4まで（推論） | 4前後（推論） | 内容に応じる | 内容に応じる |
| 音声 | すべて自動で読み上げ | 同左 | 同左 | 自動読み上げ、止められる | 「きく」ボタンで任意（推論、§10-6） | 同左 |
| 保護者の関与 | 隣で一緒に。開始と声かけは大人（研究） | 始めは一緒、慣れたらひとりでも（観察） | ひとりで始められる。振り返りは親子で | 記録を親子で見る | 保護者は設定と見守り | 子供が自分の記録を見て計画（観察） |
| 画面の落ち着き | 入口は大きく少数、装飾最小、動きは押したときだけ（観察・研究） | 同左に近い | 装飾を少し許す | 教科のアイコンは少数（観察） | 教科と記録を増やす（観察） | 情報量は増えてよいが1画面1課題は維持 |
| 1回の量 | 2〜3問か作品1つ。目安5分（推論、§10-1） | 3〜5問（CX-01） | 3〜5問 | 10〜15分の目安（観察） | 15〜20分の目安（観察） | 同左 |

**年齢差について観察されたこと**: 他社の年齢差は、文字の大きさよりも「操作の種類（タップ→なぞり→手書き→入力）」と「保護者の関与の度合い」に表れていた。どの社も、文字サイズ・行間・ふりがなの具体値は公開ページで確認できなかったため、本アプリが独自に決め、実機で確かめる。

## 6. 実機・追加調査で確かめること

- 他社の実画面（ヒントの出方、誤答後の流れ、復習、ふりがな）は未確認。必要なら公開の無料体験の範囲で再確認する（登録・購入はしない）。
- UX-10 の反応領域・縁の扱い、UX-11 の音声の主従、§5 の選択肢数と1回の量は、実機（Yoga 720・Zorin）と子供の観察で確かめる（Issue #12、#13）。
- 独立研究（Hirsh-Pasek、Deci ほか、Meyer、Mayer）は原典未読。原則の根拠として使う範囲は research.md の判断欄に従う。
