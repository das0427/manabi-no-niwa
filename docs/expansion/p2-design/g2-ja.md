# g2-ja P2 単元の設計書（g2.ja.listen-notes・g2.ja.culture）

設計: 統括の依頼による設計担当（Opus）。実装担当はこの文書だけを見て書けるようにした。
内容（本文・設問・選択肢・ヒント・解説）はすべてこの文書に全文を書いてある。実装担当は**文を足したり言い換えたりしない**（直すときは理由を報告に書く）。

- 正本: `docs/expansion/curriculum-matrix.md` 3.5 の該当行、`docs/expansion/pack-brief.md`、`docs/expansion/engines.md`。
- 手本: 同じエンジンの P1 単元 `src/packs/g1-ja/listen.ts`（listen の問題の書き方・ヒント①の文・解説の型・誤概念の調子）、同じパックの `src/packs/g2-ja/polite.ts`・`util.ts`・`g2-ja.test.ts`。
- 置き場所: `src/packs/g2-ja/listen-notes.ts`（export `listenNotes`）、`src/packs/g2-ja/culture.ts`（export `culture`）。`src/packs/g2-ja/index.ts` の `units` の末尾（`writeStructure` の後）に `listenNotes, culture` の順で足す。
- `revised: '2026-10-30'`（util の `REVISED` は 2026-10-24 のまま。新しい2単元だけこの日付を直接書く）。
- 新しい絵は**描かない**（下の絵はすべて登録済みの ID。`src/illust/content/g2-ja.tsx` は作らない）。
- 音声ファイルは作らない（統括が `audio.text` から作る）。`audio` に `key` は付けない（英字を含む文は無い）。

## 共通の書き方

- **漢字**: 本文・選択肢・ヒント・解説の漢字はこの文書に書いたとおり `漢字《よみ》`。1年・2年の字だけを使っている（3年以上の字はひらがなにした: はっぴょう・しつもん・もの・もつ・むかし・あそぶ・つぎ・たいいくかん・みやこ・おに 等）。この文書の《よみ》付きの字は全部 `kanjiGrade ≤ 2` を確かめてある。
- **分かち書き**: 問題文・音声の文・選択肢・ヒント・解説はすべて文節で空白（この文書の文のとおり）。
- **問題文の型**: listen の問題は g1 と同じく `prompt = 'よく きいてね。' + 問い`。choice の問題（なぞなぞ・かるたの別例）は問い（なぞ）そのまま。
- **ヒント**: どの問題も3段。①は到達項目ごとに共通の文（各単元の表）、②③は問題ごとの文（各問題に書いた）。どの段も答えの語そのものを書かない。
- **選択肢**: 小2の上限 4 以内（multi は上限の外だが 4 にした）。正解を先頭に書いてよい（画面で並べ替える）。`fixed: true` と書いた問題だけ `fixedOrder: true`（数の順）。絵のある選択肢がある問題は `layout: 'row'`、文だけは `'column'`（g1 listen と同じ規則）。
- **選択肢の長さ**: 文の選択肢は、ふりがなを除いて **16字以内**（空白を含む）。語の途中で折れないよう短くしてある。
- **同一性キー**: `listen-notes:<問題id>`、`culture:<問題id>`（1つの本文・1つの問いが1件。手作りなので全部別）。
- **誤概念**: 誤りの選択肢には全部 誤概念ID を付けた（汎用の誤答 0%）。

### 1.1 到達項目・段階

| id | title | level | levels の label / chance |
|---|---|---|---|
| `point` | `はっぴょうの だいじな ことを ききとる` | 0 | `だいじな ことを ききとる` / 0.1 |
| `topic` | `なにに ついての はなしかを つかむ` | 1 | `はなしの 中心《ちゅうしん》` / 0.1 |
| `ask` | `はなしに あう しつもんを えらぶ` | 2 | `しつもんを えらぶ` / 0.1 |

各到達項目: 練習 8問 ＋ 別例（`alt: true`）3問 ＝ 11問。合計 33問 → Q = 33 / 30 = 1.10、C 3/3。

別例の表し方:
- point: 選択肢が**絵**（文ではなく絵で選ぶ）。
- topic: ①はっぴょうに**だいめいを つける**（2問）、②**2つの はなしを きいて** どちらが その はなしかを選ぶ（音声2つ、1問）。
- ask: 「〜を しりたい」という**目的を先に示し**、それに合う きき方を選ぶ（はなしに合うかではなく、目的に合う問いのことばを選ぶ）。

| id | explain |

### 1.3 導入（intro, 3場面）

1. `はっぴょうを きく ときは、「いつ」「どこで」「なにを」「いくつ」に みみを すまそう。`
2. `なんども 出《で》て くる ことばが、はなしの 中心《ちゅうしん》だよ。「ねこの なまえ」「ねこの すきな こと」と つづけば、ねこの はなしだね。`
3. `しつもんは、はなしに つながって いて、まだ きいて いない ことを たずねよう。「ねこを かって います。」なら「なんさいですか。」と きけるね。`

## 5. テストで確かめること（`src/packs/g2-ja/g2-ja.test.ts` に足す）

既存の「g2-ja の教材検査」は `pack.units` を全部回すので、index に足せば `checkUnit` の誤り 0・`isReady`・学年より上の漢字なし・選択肢 4 以下・id 重複なし は自動で確かめられる。加えて次を `describe('P2 単元（listen-notes・culture）')` に書く。

1. **量と網羅**: 両単元とも `checkUnit` の `distinct ≥ 33`、各到達項目 `distinct ≥ 8`・`alt ≥ 3`、`genericWrongShare === 0`。
2. **誤りの選択肢にすべて誤概念**: 両単元の全問題（listen・choice）で、`correct` でない選択肢に `misconception` がある。
3. **正解の数**: multi でない問題は正解がちょうど1つ。pt-bring2 だけ multi で正解2つ。
4. **選択肢の長さ**: すべての選択肢の `plainText(label)` が 16字以内。問題文の `plainText(prompt)`（「よく きいてね。」を含む）が 32字以内（この文書の問題文は全部 32字以内に数えてある）。
5. **かるた**: karuta- の練習（listen）で、正解の札の label が よみふだ（`audio.text`）の はじめの1字（カタカナはひらがなに直して比べる）と一致。誤りの札の label は はじめの1字と違う。`dakuten` を付けた札は、はじめの字と濁点の有無だけが違う（か↔が、ふ↔ぶ、と↔ど）。`middle-word` を付けた札の字は、よみふだを《》の読みに直した文（`海《うみ》` → うみ）で、空白の後ろの語の はじめに出てくる。
6. **かるたの別例**: karuta-alt- の正解の label は、同じ札の よみふだ（2.5 の表）の はじめの語と一致（実装では よみふだの表を1か所に置き、練習・別例の両方から引くとよい）。
7. **ask**: ask- の練習で、正解の選択肢と already-said・off-topic・wrong-qword の選択肢は「か。」で終わり、not-question の選択肢は「か。」で終わらない。
8. **絵の id が登録済み**: 両単元の選択肢・図の `illust` の id がすべて `getIllust(id)` で見つかる（`src/illust/registry` をテストから import してよい）。
9. **音声に英字なし・key なし**: すべての `audio` の `key` が無く、文に英字が無い。
10. **ねずみの よめいり を使わない**（g1 read-story との重複防止）: culture の問題の JSON に「よめいり」が無い。
