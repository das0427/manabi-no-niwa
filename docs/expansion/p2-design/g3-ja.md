### 0.3 選択肢の数・並び
- 選択肢は 3つ（季節を答える問題だけ 4つ: 春・夏・秋・冬）。小3の上限 4 以内。

内容の確認（設計で確かめたこと）:
- 古典の句の本文は広く知られた形と照らした（作者: 松尾芭蕉・与謝蕪村・小林一茶・正岡子規。いずれも没後70年以上。**作者名は画面・データに出さない**。上のコメントの原句もソースのコメントに残さなくてよい）。表記の直し: 歴史的仮名づかい「とつて」「くねつて」→「とって」「くねって」、送り仮名「打な」「来り」→「打つな」「来たり」、4年以上・表外の字（蛙・飛・閑・蝉・蝿・終日・尋・暮・涼・障子・穴）はひらがな。
- 季節の言葉は歳時記の一般的な分類に合わせた: かわず（蛙）＝春、せみ＝夏、春の海＝春、雪とけて（雪解）＝春、はえ（蠅）＝夏、名月＝秋、雪＝冬、すみれ＝春、秋のくれ＝秋、すず風（涼風）＝夏、天の川＝秋、つくし＝春、かき氷＝夏、赤とんぼ＝秋、せんぷうき＝夏、どんぐり＝秋、こがらし＝冬、お月見＝秋、しもばしら＝冬。子供がまちがえやすい「天の川（秋）」「すいか（秋）」「朝顔（秋）」は季節を問う問題に使わない。
- 音の数（全句 5・7・5）はテストでも確かめる（4.1）。

### 1.6 問題の作り方（手作り 43 問）
同一性キー: `haiku:<到達項目>:<種類>:<句の id か語>`。id は同一性キーから `haiku:` を除いたもの。

#### 1.6.1 oto 音の数（listen 8問 ＋ 別例 choice 3問）
練習（listen）の形:
```ts
{
  engine: 'listen', id: `oto:${w.id}`, objective: 'oto', level: 0,
  prompt: '手《て》をたたきながら聞《き》こう。いくつの音《おん》かな。',
  audio: { text: w.word },
  figure: { kind: 'text', text: w.word, size: 'l' },
  options: opts(`${n}音《おん》`, [[`${x}音《おん》`, mis], ...]),
  hints: ['手《て》をたたきながら、ゆっくり言《い》ってみよう。', w.h2, w.h3],
  explain: w.e,
  identity: `haiku:oto:${w.id}`,
}
```
`H2` は下の3種から選ぶ（表の「h2」の列）:
- `Y` = `'小《ちい》さい「ゃ・ゅ・ょ」は、前《まえ》の字《じ》といっしょに1回《かい》たたくよ。'`
- `S` = `'小《ちい》さい「っ」や「ん」、のばす音《おん》も、それぞれ1回《かい》たたくよ。'`
- `K` = `'漢字《かんじ》は、読《よ》みがなで数《かぞ》えよう。'`
