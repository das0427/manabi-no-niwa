### 1.5 内容の確かさ（設計で確かめた方針）

- **方言**は、辞書・方言集で意味がはっきりしていて、広く知られたものだけ（おおきに・めんこい・なんぼ・ほかす・しばれる・ちゃう・なおす・えらい・なげる・なまら・ばってん・だんだん・こわい・はよ・めんそーれ）。**どの地方の言葉かは問わない**（問題の答えにしない）。解説では「〜などで」とぼかして書く。方言をからかう・低く見る書き方をしない。
- **世代の言葉**は、物の名前の言いかえ（えもんかけ・帳面・写真機・チョッキ・ズック・えりまき）だけ。もとが商品名の語（チャック・ホッチキス・セロテープ等）は使わない。若者言葉・ら抜き言葉など評価が分かれるものは使わない。
- **古語**は、古語辞典で意味が定まったもの（うつくし・ののしる・おどろく・やがて・をかし・あやし）。古文の引用は著作権の切れた原典から短く（枕草子「うつくしきもの。瓜にかきたるちごの顔。」・いろは歌）。作品名・作者名は出さない（枕・随 が配当外のため。classics-read と重ねない）。
- **語源**は、辞書で通説とされるものだけ（たそがれ＝たそかれ「誰そ彼」、さようなら＝「左様ならば」、すし＝「酸し」、ありがとう＝「有り難し」、いただく＝頭上にささげる、小春日和＝陰暦十月（今の十一月ごろ）、油を売る＝油売りの長話〔「といわれる」と書く〕）。
- **外来語**の出どころ: パン・カルタ・ボタン＝ポルトガル語、ランドセル・ガラス・コップ＝オランダ語、アルバイト・カルテ・エネルギー＝ドイツ語（いずれも国語辞典の語源欄どおり）。ノート・ハンガー・カメラ等は英語。
- **仮名の字源**は通説だけ（ひらがな: 安あ 以い 加か 計け 太た 知ち 止と 奈な 波は 末ま 美み 女め 留る 礼れ 和わ、カタカナ: 加カ 多タ 千チ 宇ウ 己コ 八ハ 保ホ 比ヒ 流ル）。字源に説が分かれるもの（ツ・ニ・マ など）と、もとの字が配当外のもの（於・之・奴・祢・阿・伊・江 など）は使わない。
- **漢字の成り立ち**: 象形（山・川・日）、指事（上・本・末）、会意（林・休・森）、形声（晴＝日＋青、銅＝金＋同、清＝氵＋青）。**国字**: 畑（火＋田）、働（人＋動）。
- 万葉仮名の例「波流（はる）」は万葉集の表記に実際にある書き方（例: 「波流佐礼婆」）。本文では「たとえば」として出す。

## 4. 問題

### 4.0 共通の書き方

- **match**: `left` は上の段、`right` は下の段（正しい相手＋まぎらわしいもの1つ）。`pairs` は `[i, i]`（left の i 番目と right の i 番目。kanji-usage／info-relations と同じく、書いた順で組にし、画面で混ぜる）。`wrongPairs` は表に書いたものだけ。`level` は到達項目の段階。
- **choice**: `options: opts(正解, [[誤り, 誤概念], …])`（util.ts）。選択肢は4つまで。`layout` は文の選択肢なら `'column'`、1〜2字の札なら書かない。文・会話を見せるときは `figure: { kind: 'text', text, size: 'm' }`（1字だけ大きく見せるときは `size: 'xl'`）。
- **reading**: classics-read の `readItems` と同じ形（`aspect`・`hintFocus: [段落, 根拠, 根拠]`・`evidence`）。h1 は `「①の段落《だんらく》を読《よ》み返《かえ》そう。」` の形（番号は CIRCLED。classics-read と同じ部品をこのファイルの中に書く）。`passage.numbered: true`、`genre: 'explain'`。本文の ID は `lc-` で始め、他の単元と重ならない。全部 `alt: true`。
- 表の「誤り」の列は `文 → 誤概念ID`。誤概念の無い誤り（汎用）は「—」。汎用は choice の誤り 65 のうち 9（dl-alt-erai・ch-gen・ch-alt-utsukushi・or-itadaku・or-koharu・or-alt-randoseru・kn-alt-an 各1、kj-alt-hatake 2）≒ 14%（20%以下）。

## 9. 実装の注意（設計で気付いた落とし穴）

- 部首は字で書かず、かなで書く（`さんずい`、`にんべん（人《ひと》）`）。`人《にんべん》` のような、字と合わないよみは付けない。
- 「選択肢」「随筆」「枕草子」「於」などの配当外・表外の字は、子供に見せる文に使わない（この設計の文には入っていない）。
- 「々」は kanjiGrade で 7（配当外）になるので使わない（`人《ひと》びと`・`家《いえ》いえ`）。
- `今日《きょう》`・`大人`などの熟字訓は1語でよみを付ける（この設計では `今日《きょう》` だけ）。
- reading の誤りの選択肢にも誤概念を付ける（`—` の2つ以外）。qa の汎用誤答の割合は choice だけを数えるが、そろえておく。
- `dl-letter`・`kj-alt-kun` 以外の choice は選択肢3〜4つ。`kj-alt-kun` は2つ（音・訓の2つの読みを比べる問題なので2択でよい）。
- match の `id` は `<種類>:<id>`（`dl-match:a`、`ch-match:gen-a`、`ch-match:kogo-a`、`ch-match:kanazukai`、`or-match:moto`、`or-match:loan-a`、`kn-match:h-a`、`kn-match:k-a`、`kj-match:sei-a` など）。choice は表の id のまま（`dl-what` など）、reading は `lc-hougen:naosu` など。
