### 0.1 置き場所・形

- 前提 `prereq: []`（本表の前提欄は3単元とも「−」）。
- `gradeIsAppProposal: true`（生活は第1・2学年のまとまり。本表の ※）。

### 0.2 選択肢の形と画面の収まり（`choiceItem` の自動の選び方）

- 文の選択肢は `layout: 'column'` を渡す（school-safety と同じ）。`choiceItem` は、ラベルが 8字以上なら問題文の下に「1：…」の一覧を出し、ボタンを「1・2・3」にする。
- 一覧で3つ全部を出せるのは「問題文が2行（ふりがなを除いて 60字）以内」かつ「作業領域の図が無い」とき。**この設計の文の選択肢の問題には図を付けない**（付けると選択肢が2つに減る）。問題文は全部 60字以内、選択肢は全部 20字以内にしてある。
- 絵の選択肢（`rightFigure`・`wrongFigures`）の問題は、ラベルを 7字以内にしてある（3つが1行に並ぶ）。`layout` は渡さない（row）。
- `budget.test.ts` はパックの全単元に効くので、新しい単元もそのまま検査される。

### 0.3 文の規則（この設計で確かめたこと）

- 小1（public・home）: ひらがな・カタカナだけ。漢字は使わない。
- 小2（tell）: 使う漢字は 手・紙・絵・話・電・名・前・友・先・生・年・方・合 だけで、すべて1・2年の配当（手・名・先・生・年は1年、紙・絵・電・話・前・友・方・合は2年。`kanji-grades.ts` で確認）。漢字は必ず `漢字《よみ》`。
- 分かち書き: 文節ごとに空白。かなが 13字以上つづく所は無い。
- どのヒント③も、正解の選択肢の文をそのまま含まない（テスト「ヒント③が 正解の選択肢の文を そのまま いわない」に合う）。
- 実在の人物・団体・商品名・地名は無い。「おうちの ひと」と書き、家族の形を決めつけない（home）。子供の名前・写真を求める問いは無い。
- 文の重複: g2.life.town の use-rules（図書館で静かに読む・期限までに返す・ブランコの順番・電車やバス・公園のごみ・荷物を持つ）、g1.life.school-safety の rules（廊下・あいさつ・挙手・階段・並ぶ・かして・片付け）と**同じ場面は使っていない**。

### 0.5 テストに足すこと（`life-g12.test.ts`）

既存のテストはパックの全単元に回るので、`checkUnit` の誤り0・`isReady`・`extraChecks`（学年より上の漢字・選択肢の数・絵の有無・分かち書き）・段階ごとに5問以上・ヒント③・explain に正誤の言い方が無い、はそのまま効く。次を足す（「内容の再発防止」のテストに追記してよい）:

1. 3単元とも `priority === 'P2'`、`status === 'ready'`。
2. `isReady(checkUnit(unit))` が true、Q と C が下の「量の見込み」と一致（public: 異なる問題 30・Q 1.25・C 3/3、home: 18・Q 3.00・C 2/2、tell: 30・Q 1.25・C 3/3）。

### 1.3 問題（手作り 30 問）

school-safety.ts の `Q`（`id, level, prompt, right, wrongs, hints, explain`）と同じ形。`wrongs` の要素は `[文, 誤概念ID]`。絵の選択肢の問題だけ `rightFigure`・`wrongFigures` を持つ。

作り方:
- 練習（`OURS`・`USE`・`SUPPORT`）: `choiceItem({ id: \`${q.id}\`, obj, level, prompt, right, wrongs, layout: 'column', hints, explain })`。id はここに書いた値をそのまま使う（接頭辞を足さない）。
- 別例（`OURS_ALT`・`USE_ALT`・`SUPPORT_ALT`）: 同じく `choiceItem` に `alt: true`。絵の選択肢の問題（`own-alt-*`）は `layout` を渡さず、`rightFigure: illust(q.rightFig)`、`wrongFigures: q.wrongFigs.map((f) => illust(f))`。
