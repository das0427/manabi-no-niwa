**approx-area のエンジンの注（matrix と違う判断。報告に書く）**: geometry の pick は問題の図（`figure`）を出せない（算数の図のエンジンに figure を付けない規則。g6 のテストが止める）。池・葉などの本体の図を見せて式や面積を問うには、`circle-area.ts`・`prism-volume.ts` の前例どおり choice・number に SVG の図を付ける。geometry は「どの形と みるか」（選択肢そのものが図）にだけ使う。

**コードを書くときの共通の注意**
- 文はふつうに漢字で書き、`finishUnit` の辞書で《よみ》を付ける（g5 は `finishUnit(u, '追加の語 …')`、g6 は `ruby.ts` に足す）。
- **fill の `blanks[].wrong[].value` には辞書のよみが付かない**（g5 の ruby.ts の SKIP に `value` がある）。漢字を含む値は《よみ》を手で書く（例 `'箱《はこ》の ねだん'`）か、`R()`（`makeRuby(extra).R`）を通してから入れる。fill の照合は ふりがなを無視するので、選択肢側と同じ字であれば一致する。
- SVG の `<text>` には **数字・英字・記号だけ**（かな・漢字・カタカナ不可。g6 のテストが止める。A・B は英字なので可）。
- 色は `var(--ink)`・`var(--sky)`・`var(--sun)`・`var(--white)` だけ。区別は線の種類（実線・破線・点線）と文字（A・B）でつける（色だけで区別しない）。
- 選択肢は 4つまで（小5・小6。fill の選択肢も 4つまでにそろえる）。
- 学年より上の漢字を使わない（g5 は 5年まで、g6 は 6年まで）。5年: 「枚」(6年) は使わず「まい」、「値段」は「ねだん」、「縦」(6年) は「たて」、「割」(6年) は使わない。6年: 「概」「床」「壇」は使わない（「およその 形」「花だん」）。

### 1.7 問題の型

共通: すべて `engine: 'fill'`。`prompt` は文、`text` は空欄 `{{}}` を含む式の行（1行 24字以内。必要なら `\n` で2行）、`options` は 2〜4。式の図は `expr(…)`（util.ts）。表の図は `{ kind:'table', header:['□', …xs], rows:[['○', …ys]] }`。

**数の選択肢の作り方（helper を1つ作る）**: `numOpts(correct, cands: [value, misconception][])` → 正答を先頭に、候補のうち「正の整数（または 小数でない値）・正答と違う・ほかの候補と違う」ものだけを残し、合計 4つまで。戻り値は `{ options: string[], wrong: { value, misconception }[] }`。候補が1つも残らない組は作らない（下の定義域ではかならず1つ以上残る。テストで確かめる）。

#### (1) make — 場面を式に（非 alt）

- prompt: `${text(p)}\n□と ○の 関係を 式に 表そう。`
- figure: なし
- text と blanks（kind ごと）:

| kind | text | 空欄と選択肢 | 誤り → 誤概念 |
|---|---|---|---|
| lin | `○ ＝ {{}} × □ ＋ {{}}` | options = `[a, b, a+b]`（文字列）。空欄1 answers `[a]`、空欄2 answers `[b]` | 空欄1: b→swap-const、a+b→add-all。空欄2: a→swap-const、a+b→add-all |
| tri | `○ ＝ ${a} {{}} □ {{}} 2` | options = `['×','＋','÷']`。空欄1 options `['×','＋']` answers `['×']`、空欄2 options `['÷','×']` answers `['÷']` | 空欄1: ＋→add-mult。空欄2: ×→tri-half |
| vol | `○ ＝ ${a} {{}} ${b} {{}} □` | options = `['×','＋']`。空欄1・2 とも answers `['×']` | ＋→add-mult（両方） |
| mul | `○ ＝ ${a} {{}} □` | options = `['×','＋','÷']`、answers `['×']` | ＋→add-mult、÷→reverse-op |
| sum | `□ {{}} ○ ＝ {{}}` | options = `[c, c/2]`（空欄2用）。空欄1 options `['＋','×','−']` answers `['＋']`、空欄2 answers `[c]` | 空欄1: ×→add-mult、−→sum-diff。空欄2: c/2→equal-split |
| sub | `○ ＝ ${c} {{}} □` | options = `['−','＋','×']`、answers `['−']` | ＋→sum-diff、×→add-mult |
| add | `○ ＝ □ {{}} ${d}` | options = `['＋','−','×']`、answers `['＋']` | −→sum-diff、×→add-mult |

- hints:
  1. `'□と ○が 何を 表して いるかを 確かめよう。'`
  2. `` `言葉の 式に すると「${word}」だね。` ``
  3. kind ごと（最後の一手を残す）: lin `` `○ ＝ ${a} × □ ＋ …　あとから たすのは 何かな。` ``／tri `` `${a} と □ を かけて、それを …` ``（÷ を言わない）／vol `` `たて、横、高さを どう 計算すると 体積に なるかな。` ``／mul `` `たて と 横を どう 計算すると 面積に なるかな。` ``／sum `` `姉と 妹を 合わせると いつも 同じ 数に なるね。` ``／sub `` `切り取ると 残りは ふえるかな、へるかな。` ``／add `` `もらうと 全部の まい数は ふえるかな、へるかな。` ``
- explain: `` `「${word}」なので、式は ${formula(p)} です。` ``
- identity / id: `` `make:${scene}:${params}` ``（params は使う数を `:` でつなぐ。例 `make:cookie:60:100`）。式が違えば別の問題（curriculum-matrix 1.4「式が違えば別」）。

#### (2) make-alt — 表から式に（alt: true）

- 場面の文を出さず、表だけで式を作る（表し方: 文章 → 表）。kind は lin・tri・mul・sum・sub・add（vol は表から a と b を分けられないので使わない）。場面の params の定義域をそのまま使う（場面を選んで kind と params を取り出す。vol の box が出たら make の非 alt に回す か、場面を選び直す: **場面を選ぶ前に box を除いた 7 場面から選ぶ**）。
- 表の □ の値 xs: tri は `[2,4,6,8,10]`、ほかは `[1,2,3,4,5]`。ys = f(x)。
- prompt: `'表は、□と ○の 関係を 調べた ものです。□と ○の 関係を 式に 表そう。'`
- figure: 表。text・blanks は (1) と同じ（tri・mul・sub・add の数は式に書いてある）。
- hints: 1 `'□が ふえると ○は どう 変わるかな。'`、2 `` `□が ${xs[0]}の とき ○は ${ys[0]}、□が ${xs[1]}の とき ○は ${ys[1]}。` ``、3 kind ごと: lin `` `□が 1 ふえると ○は ${a} ふえるね。□が 1の とき、${a} × 1 ＝ ${a}。${ys[0]}との ちがいは …` ``／tri `` `${a} × ${xs[0]} ＝ ${a*xs[0]}。○は その 何分の いくつかな。` ``／mul `` `○ ÷ □ は いつも 同じ 数だね。` ``／sum `` `□と ○を たすと、いつも 同じ 数に なるね。` ``／sub `` `□が ふえると ○は へって いるね。` ``／add `` `○ − □ は いつも 同じ 数だね。` ``
- explain: `` `表から、${formula(p)} の 関係に なって います。` ``
- identity: `` `make-alt:${kind}:${params}` ``（場面の名前を含めない。表には場面が出ないため。tank と cookie の lin は数が重ならない）。

#### (3) value — □に数を入れる（非 alt）

- t を場面の t の定義域から選ぶ。答え `y = f(t,p)`。
- prompt: `` `式 ${formula(p)} で、□が ${t}の とき ○は いくつですか。` ``
- text: kind ごとに □ に t を入れた式 ＋ ` ＝ {{}}`:
  - lin `○ ＝ ${a} × ${t} ＋ ${b} ＝ {{}}`／tri `○ ＝ ${a} × ${t} ÷ 2 ＝ {{}}`／vol `○ ＝ ${a} × ${b} × ${t} ＝ {{}}`／mul `○ ＝ ${a} × ${t} ＝ {{}}`／sub `○ ＝ ${c} − ${t} ＝ {{}}`／add `○ ＝ ${t} ＋ ${d} ＝ {{}}`
  - sum は 2行: `${t} ＋ ○ ＝ ${c}\n○ ＝ {{}}`
- options・wrong（numOpts。答えと同じ・0以下・小数になる候補は捨てる）:

### 2.7 問題の一覧（48問）

共通の書き方:
- id = identity（単元内で一意）。`alt` は表のとおり。
