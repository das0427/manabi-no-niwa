### 0.3 段階（level）の扱い
- p23 では **段階0 = 2歳段階（L2）**、段階1 = 3歳段階（L3）。2歳段階の子は常に段階0の問題を出される（`UnitRunner.roundLevel`）。
- **first-sound・peekaboo・puzzle2・road は「L3 のみ」の単元だが、段階は1つ（段階0）だけにする**。どれも L3 の仕様が「2択」なので、段階0の検査（2択・8問以上）をそのまま満たす。段階の名前は「3さいの だんかい: …」と書く。2歳段階の子に出さないのは、ホームの札（0.4）で行う。
- picture-book だけ2段階（段階0 = L2、段階1 = L3）。

### 0.5 curriculum-matrix と違う判断（統括へ報告する）
1. **peekaboo・puzzle2・road は legacy ではなく choice（と listen）で作る**。matrix は「legacy(B4 縮小)／legacy(K2 縮小)／legacy(R1)」だが、legacy は v1 のモードの段階をそのまま使う方式で縮小できない（B4 は場所3つ、K2 は2〜3ピース＋余り1とドラッグ、R1 は道具と回転）。さらに legacy は進度を v1 の同じスキル（p4.think.memory・p4.math.shapes・p4.think.road と共有）に書くので、3歳の遊びが4歳の進度を動かしてしまう。p23 の他の単元（shape-match など）も matrix の「legacy(K1), choice」を choice で作っている。
2. **peekaboo は「かくれる動き」を見せられない**（今のエンジンに「見せてから隠す」段が無い）。代わりに「すこし みえて いる からだ（みみ・しっぽ）から かくれた ばしょを みつける」にした。物が見えなくなっても在ることに気付く遊びとして同じ目標。**エンジンへの要望**: choice に「覚える画面 → 隠す → 選ぶ」の段（memory の B4 と同じ流れ）があれば、matrix どおりの「カップに かくれる」を作れる。
3. **picture-book の L2「聞くだけ」は「聞いて ゆびさし（2択・やさしい誤答）」にした**。採点しない「聞くだけ」の問題の形が無い（explain は盤か理由の選択肢が要る、listen は正解が要る）。2歳段階は `softJudgement`（正誤の音・○×なし）なので、誤答の選択肢は話に出てこない乗り物にして、ほぼ迷わない問いにする。**エンジンへの要望**: listen に「聞き終わったら『おしまい』だけ押す」形（採点しない）があれば L2 をその形にする。
4. peekaboo の量は matrix「絵20×位置2」に対し、動物8・隠れ場所2（位置は 1.4 で同じ問題）。異なる問題 24（基準 12 の 2.0倍）。

### 1.3 問題
**(a) 練習 `sound`（20問）** — 20語それぞれを正解にする。
- `id`/`identity`: `sound:<語>`（例 `sound:いぬ`）
- `prompt`: `この おとで はじまるのは どっち？`
- `audio`: `{ text: <head> }`（例 `い`）、`hideTranscript: true`
- `figure`: なし
- 正解: その語（`label` = 語、`figure` = 絵）
- 誤り1つ: 1.2 の条件の語。`misconception: 'other-sound'`
- `hints`: `['もういちど おとを きいて、まねして いって みよう。', 'えの なまえを ゆっくり いって、はじめの おとを くらべよう。']`
- `explain`: `<語>は「<head>」で はじまるね。`（例 `いぬは「い」で はじまるね。`）

**(b) 練習 `same`（20問）** — 20語それぞれを「図の語 A」にし、正解は A の相方 B。
- `id`/`identity`: `same:<A>`
- `prompt`: `この えと おなじ おとで はじまるのは？`
- `figure`: `ill(A の絵)`、`audio`: `{ text: A }`
- 正解: B。誤り1つ: A と行が違う語 C（条件は 1.2）。C が A と同じ「なかま」なら `misconception: 'same-group'`、違えば `'other-sound'`
- `hints`: `['えの なまえを ゆっくり いって みよう。', '<A>を ゆっくり いって、はじめの おとで とめて みよう。']`
- `explain`: `<A>と <B>は、どちらも「<head>」で はじまるね。`

**(c) 別例 `sound`（4問, `alt: true`）** — 音を「となえ歌」の中で聞く（word-listen の「文の中で聞く」と同じ型の別例）。
- 正解の語: いちご、くるま、ひよこ、バナナ
- `id`/`identity`: `chant:<語>`
- `prompt`: `きいてね。どれかな？`
- `audio`: `{ text: '<h>、<h>、<h>。この おとで はじまるのは、どーれだ？' }`（例 `い、い、い。この おとで はじまるのは、どーれだ？`）、`hideTranscript: true`
- 誤り・誤概念・ヒント・解説は (a) と同じ

**(d) 別例 `same`（4問, `alt: true`）** — 絵を出さず、ことばを耳だけで聞く。
- A → 正解 B: うし→うさぎ、かさ→かめ、たまご→たこ、とけい→とり
- `id`/`identity`: `ear:<A>`
- `prompt`: `おなじ おとで はじまるのは どっち？`
- `audio`: `{ text: A }`、`figure`: なし

- `hints`: `['もういちど きいて、まねして いって みよう。', 'きいた ことばを ゆっくり いって、はじめの おとで とめて みよう。']`

### 5.2 お話（8本）と練習の問題
各お話から2問: **`who`（段階0, 2択）** と **`thing`（段階1, 3択）**。
- `who`: `id`/`identity` `who:<話>`、`prompt` `きいてね。でて きたのは どっち？`、正解は主人公、誤りは**話に出てこない乗り物・物**（`not-in-story`）。
  - `hints`: `['もういちど おはなしを きいて みよう。', 'だれが でて きたか、ゆっくり おもいだそう。']`
  - `explain`: `<主人公>さんが でて きたね。`
- `thing`: `id`/`identity` `thing:<話>`、`prompt` は表の問い、正解・`other-role`（話に出てくるが問いの答えではない物）・`not-in-story`（話に出てこない物）の3択。
  - `hints`: `['もういちど おはなしを きいて みよう。', '<ヒントの人物>さんが でて くる ところを よく きいてね。']`
  - `explain`: 表の解説

## 6. 内容の確かめ（設計で確認済み）
- 漢字なし・分かち書き・カタカナは身近な語だけ。語は既存の絵の label と同じ書き方（`おはな` の絵 `flower` は使わない）。
- first-sound の語頭: スプーン＝す、バナナ・バス＝ば、とけい＝と（すべて表の head）。誤りの条件で、い/う（同じ あ行）、は/ば（点の有無）の組は出ない。
- picture-book: `not-in-story` の物の名前は各話の本文に出てこない（S1 バナナ・バス、S2 ボール・ひこうき、S3 みかん・くるま、S4 いちご・でんしゃ、S5 かさ・ふね、S6 トマト・じてんしゃ、S7 もも・かさ、S8 ボール・くるま）。`other-role` の名前は本文に出てくる。別例の正解の名前は本文に出てこない。
- 色だけで区別する問題なし。赤と緑を同時に見分けさせる問題なし（road の にんじんは `--berry` と `--leaf` だが、区別は求めない）。
- 実在の人物・団体・商品名なし（「パンやさん」は一般名）。お話は自作。
- road の8面の経路は、隣り合うマスだけでつながり、同じマスを2度通らず、4×3 に収まる（4.2 の形は経路から計算した値）。
