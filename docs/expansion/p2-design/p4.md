## 0. 共通（3単元とも）

### 0.1 置き場所・書き方
- ファイル: `src/packs/p4/story-listen.ts`、`src/packs/p4/seasons.ts`、`src/packs/p4/daily-order.ts`。`src/packs/p4/index.ts` の `units` に `storyListen`, `seasons`, `dailyOrder` を足す（`kanaTraceEarly` の前、P1 の後ろ）。
- 手作り（`source: { kind: 'items', items: build() }`）。生成器は使わない。
- 部品は `./lib` の `ill`, `mix`, `choiceItem`, `listenItem` を使う（p4 の P1 単元と同じ。`choiceItem`/`listenItem` は正解を先頭に渡すと id から決まる順に混ぜる）。
  - 正解が2つ以上の問題（`multi: true`）は `listenItem` が使えないので、`{ engine: 'listen', …, multi: true, options: mix(id, [...]) }` を直接書く。
  - order・sort の問題は型（`OrderItem`, `SortItem`。`../../curriculum/types` から import）をそのまま書く。
- **漢字を1字も使わない**（p4.test が `JSON.stringify(items)` に漢字が無いことを確かめる）。ひらがな＋身近なカタカナ（バス・ボール・トマト・タオル・コップ・テーブル・フライパン・チューリップ・バナナ・テレビ）だけ。文は文節で空白（分かち書き）。
- ヒントは2段（幼児）。どの段も正解の語・絵をそのまま言わない。
- 選択肢は3つまで（seasons の2択・multi の4つを除く）。4歳の上限4以内。
- `stage: 'p4'`, `domain: 'play'`, `priority: 'P2'`, `status: 'ready'`, `review: 'none'`（幼児は間隔反復をしない。curriculum-matrix 1.6）, `gradeIsAppProposal: true`（4歳への割当は本アプリの案。幼稚園教育要領は年齢別でない）, `revised: '2026-10-30'`。
- 音声ファイルは作らない（統括が台本から作る）。listen の `audio` は `{ text }` だけ（`key` を付けない。英字は使わない）。

### 0.3 テスト（`src/packs/p4/p4.review.test.ts` に足す。既存の検査はそのまま）
`p4.test.ts` はそのままで、新しい3単元にも `checkUnit` の誤りなし・`isReady`・選択肢4つまで・正解判定・絵の登録・漢字なし・id 一意が自動でかかる。加えて次を書く:
- **story-listen**
  - id が `who:`・`what:` で始まる listen 問題: 正解の選択肢の `label` が本文（audio の text を全部つないだもの）に含まれる。
  - 誤概念 `other-role` の選択肢の `label` は本文に含まれる／`not-in-story` の選択肢の `label` は本文に含まれない。
  - multi（`who-all:*`）: 正解の label はすべて本文に含まれ、誤りの label は含まれない。
  - ヒントの最後の段に、正解の `label` を「」付きで書かない（既存の「ヒントの最後の段に正解をそのまま書かない」の対象の配列に `'p4.ja.story-listen'` を足すだけでよい）。
  - 問題文（prompt）は 26字以内、選択肢の label は 10字以内（空白を除いて数える）。本文の1文は 32字以内。
- **seasons**
  - 季節の表（`THINGS`）が唯一の正本で、choice の正解・sort の `box`・別例の正解が、すべてその物の季節と一致する。
  - 誤りの季節の誤概念は、表から計算した「となり（差1または3）→ `season-next`／はんたい（差2）→ `season-opposite`」と一致する。
  - sort の各カードの `wrongBoxes` は正しい箱以外の3つの箱をすべて持つ。
- **daily-order**
  - 別例（choice）の正解は、その場面の手順表（`SCENES`）で決まる位置の手順（「つぎ」なら i+1、「はじめ」なら 0、「さいご」なら末尾）と一致する。
  - order の問題の `cards` の文は場面の手順表と同じ順。
- 共通: 3単元の問題の id が単元の中で一意（既存の検査で足りる）。

### 1.3 問題の形（共通の型）
**練習 who / what（listen, `listenItem`）**
- `id` = `identity` = `${kind}:${story.id}`（kind は `who` か `what`）、`objective` = kind、`level` = 本文の level。
- `prompt` = `「${story.title}」。${q.q}`
- `audio` = `story.lines.map((text) => ({ text }))`、`gapMs: 700`
- `hints` = `['もういちど おはなしを きこう。', `「${q.focus}」の ところを おもいだそう。`]`
- `explain` = q.explain（下の表）
- `correct` = `{ label: 正解の名, figure: ill(正解の絵) }`、`wrong` = 表の2つ（label・絵・誤概念）

**練習 next（listen）**: 同じ形。`objective: 'next'`, `level: 2`, `hints` = `['おはなしで なにが あったか おもいだそう。', q.cue]`（cue は表）。

**別例 who-all（listen, multi）**: `id` = `identity` = `who-all:${story.id}`, `objective: 'who'`, `level: 1`, `alt: true`, `multi: true`,
`prompt` = `「${title}」。でて きたのを ぜんぶ えらぼう。`, `audio` は本文, `gapMs: 700`,
`hints` = `['もういちど おはなしを きこう。', 'でて きた どうぶつは ふたり だよ。']`,
`explain` = `${正解1}と ${正解2}が でて きたね。`,
`options` = `mix(id, [正解2つ（correct: true）, 誤り2つ（misconception: 'not-in-story'）])`。

**別例 scene（listen）**: 選択肢の絵が「だれ＋なに」の2つの絵の並び `{ kind: 'row', items: [ill(だれ), ill(なに)] }`。`id` = `identity` = `scene:${story.id}`, `objective: 'what'`, `alt: true`, `level` は本文の level。hints = `['もういちど おはなしを きこう。', q.cue]`。

**別例 next-pic（choice, `choiceItem`）**: 音声なしの「えの おはなし」。`figure` = `{ kind: 'row', items: [ill(1こめ), ill(2こめ)] }`, `prompt` = `えの おはなし。つぎは どう なる？`, `objective: 'next'`, `level: 2`, `alt: true`, `id` = `identity` = `next-pic:${id}`, hints = `['ひだりの えから じゅんに みよう。', cue]`。
