# p5 パック P2 単元の設計書（docs/expansion/p2-design/p5.md）

版 1（2026-10-30）／設計: Opus（設計担当）／宛先: 実装担当（Sonnet）、統括（Opus）
対象: `p5.ja.small-kana`、`p5.think.why`、`p5.env.predict`、`p5.ja.letter-play`（curriculum-matrix 3.3 の該当行。すべて P2・未）

この設計書だけで書けるように、**問題の文・選択肢・正答・誤概念・ヒント・解説をすべて書いた**。実装担当は内容を足さない・言い換えない（足りないと思ったら報告に書く）。文の空白（分かち書き）もこのとおりに写す。

## 0. 共通（4単元すべて）

### 0.1 置き場所・書き方
| 単元 | ファイル | export 名 | 主なエンジン |
|---|---|---|---|
| p5.ja.small-kana | `src/packs/p5/small-kana.ts` | `smallKana` | listen, choice |

- `src/packs/p5/index.ts` の `units` の最後（`katakanaTrace` のあと）に `smallKana, thinkWhy, envPredict, letterPlay` の順で足す。
- 手作りの問題（`source: { kind: 'items', items }`）。生成器は使わない。
- 選択肢は画面で並べ替えないので、**既存の `lib.ts` の `choiceItem` / `listenItem` / `opts`（問題 id から決まる順に混ぜる）を使う**。experiment の `task.options` も `opts(id, 正解, 誤り)` で作る。explain の `reasons` は混ぜない（書いた順。「ほかの わけ」は最後）。
- 問題の `id` と `identity` は同じ文字列（下の各表の「id」）。
- 幼児なので**ヒントは2段**（`[h1, h2]`）。どの段も答えの語・答えの選択肢の文を書かない。
- **漢字を使わない**（幼児。p5.test が JSON 全体に漢字が無いことを検査する）。カタカナは物の名前（アイス・ボール・タオル・リボン・ハート・バナナ 等）だけ。
- 選択肢は 2〜3（幼児の上限4以内）。全部の誤りの選択肢に誤概念IDを付ける（汎用の誤答 0%）。
- 誤概念の説明は「〜と かんがえたのかな」で始め、正しい見方を1文で示す（責めない）。
- `revised: '2026-10-30'`、`priority: 'P2'`、`stage: 'p5'`、`domain: 'play'`（既存の p5 と同じ）。`status` は `checkUnit` が通り `isReady` が true なら `'ready'`、届かなければ `'partial'`（理由を報告）。
- 音声ファイルは作らない（listen の `audio` は `{ text }` だけ。key を書かない）。

### 0.3 本体の変更が要るもの（実装担当は変えない。統括へ）
1. **幼児ホームの札**（`src/curriculum/preschoolHome.ts` の p5）: p5.test の「ホームの札」は全単元が札にあることを検査するので、**統括が札を足すまでこのテストは落ちる**（実装担当は直さず報告に書く）。札は9枚で上限のため、新しい札は作らず、次のように足す案:
   - `hiragana`（ひらがな）に `p5.ja.small-kana`
   - `kaku`（もじを かく）に `p5.ja.letter-play`
   - `kimari`（きまり）を「かんがえる」に名前を変え、`p5.think.pattern`・`p5.think.why`・`p5.env.predict`
2. **experiment の「予想してから」**: `consider` は「やってみる」を答える前に押せるので、予想の設問に使うと先に結果を見られてしまう。このため予想（到達項目 predict）は **choice** で作り、結果は解説の図で見せる（2章）。エンジンに `predictFirst`（答えるまで「やってみる」を押せない・答えたあとに結果を出す）があれば、予想も experiment にできる（要望）。

### 1.2 問題の型（2つ）
- **練習（きいて よむ）** `listenItem`: `prompt: 'きこえた ことばは どれ？ よんで えらぼう。'`、`audio: { text: 正解の語 }`、選択肢は文字（正解＋誤り2）。id `hear:<語>`。`alt` なし。
- **別例（えを みて よむ）** `choiceItem`: `prompt: 'この えの なまえは どれ？ よんで えらぼう。'`、`figure: ill(絵)`、選択肢は文字（正解＋誤り2）。id `pic:<語>`。`alt: true`。（表し方: 音→字 を 絵→字 に変える。語の中の小さい字を、聞かずに自分で読む）
- 問題文には答えの語を書かない（読む力を見るため。問題文は自動で読み上げられる）。
- ヒント h1 は型と段階で決まる（下）。h2 は各行の「h2」列。
  - 練習 level0: `'もういちど きいて、てを たたきながら いって みよう。'`
  - 練習 level1: `'もういちど きいて、ゆっくり いって みよう。'`
  - 練習 level2: `'もういちど きいて、のばす ところを さがそう。'`
  - 別例（全段階）: `'えの なまえを ゆっくり いって みよう。'`
- 解説は各行の「解説」列（そのまま）。

## 7. 内容の確かめ（設計で確認したこと・残ること）
- 長音の表記（現代仮名遣い）: ア・イ・ウ段は「あ・い・う」を添える（おかあさん・おにいさん・くうき）。エ段は「い」が原則（とけい・せんせい）、「おねえさん」は「え」。オ段は「う」が原則（ぞう・ぼうし・こうばん・おとうさん）、「こおり」は「お」（歴史的仮名遣いで ほ・を に由来する語）。誤り「とけえ」「ぼおし」はこの原則に対する誤りとして扱う。
- 「びよういん」「ねこ」「こばん」「しゅしん」等、誤りの選択肢に実在の語が混ざるが、音を聞いて（または絵を見て）選ぶので答えは1つに決まる。
- 理科の事実: りんご・すいか・皮つきの みかん は水に浮く、生の たまご・こいし は沈む。小さい氷は大きい氷より早く溶ける。うちわの風で葉・ふうせんは動き、こいしは動かない。砂糖・塩は水に溶け、砂は溶けない。これらは一般的な家庭での観察で、結果は「この アプリの せってい」として示す。**未確認**: 品種・鮮度で浮き沈みが変わる場合がある（たまごは古いと浮く）。解説は「なまの たまご」と書かず一般的な結果にとどめた。
- 「かえるは あめの ひに げんき」は日常の観察の範囲（両生類は乾燥を嫌う）。
- 他社教材・キャラクター・実在の人物・商品名は使っていない。昔話・本文の引用なし。
