## 0. 共通（両単元）

### 0.1 置くファイルと形

| ファイル | 内容 |
|---|---|
| `src/packs/soc-g56/information.ts` | `export const information: UnitSpec` と `export const informationAllow: Allow` |
| `src/packs/soc-g56/environment.ts` | `export const environment: UnitSpec` と `export const environmentAllow: Allow` |
| `src/packs/soc-g56/index.ts` | `units` の末尾に `information, environment` を足す。`ALLOW` に `'g5.soc.information': informationAllow`, `'g5.soc.environment': environmentAllow` を足す |
| `src/packs/soc-g56/review-p2.test.ts` | 3章の検査（新規） |

- 既存の `util.ts` の部品だけを使う: `baseSoc`・`choiceItem`・`multiItem`・`sortItem`・`orderItem`・`matchItem`・`fillItem`・`readingItem`・`graphChoice`・`table`・`textFig`。util.ts は変えない（足りないものは無い）。
- `...baseSoc(id, 'g5')` のあとに **`priority: 'P2'`** を上書きする（baseSoc は P1 を返す）。`kind: 'inquiry'`、`status: 'ready'`、`review` は baseSoc のまま（'objective'）、`icon` も baseSoc のまま（'subj-shakai'）。
- 同一性キーは問題の id（util の部品が `identity: id` にする）。手作りなので生成器・domainSize は無い。
- 例示データの題の後ろに付ける文は既存と同じ定数にする: `const REI = '（れいのデータ。このアプリでつくった例《れい》だよ）';`
- グラフの年の札は food.ts と同じ書き方: `const YEARS = ['1970', '1980', '1990', '2000', '2010'].map((y) => \`${y}年《ねん》\`)`（単元ごとに必要な年をこの設計書に書く）。
- 本文（reading の passage）は `const P_XXX: ReadingItem['passage'] = { id, genre, title, paragraphs }` で書き、同じ本文を複数の設問で使い回す（history-1.ts と同じ）。
- 選択肢は1つ選ぶ問題で **4つまで**（正解1＋誤り3まで）。すべて選ぶ（multi）も4つ。layout は既定（column）。
- **すべての誤りの選択肢・誤りの札に誤概念IDを付ける**（汎用誤答 0% を目指す）。sort・order・match・fill の誤概念は書いた1つ（または空欄ごとの指定）。
- 文の書き方: この設計書の文は **そのまま** コードに写す（RichText。漢字はすべて `漢字《よみ》`）。分かち書きをしない（日本語の字のあいだに空白を入れない）。文の中の「」はそのまま。
- 実在の放送局・新聞社・企業・アプリ・商品の名前、公害の原因企業の名前を出さない。人物は架空の「ゆうきさん」「お姉《ねえ》さん」だけ。
- 「水俣病」の「俣」は常用漢字表にない字なので使わない（2.1 の規則）。**「みなまた病《びょう》」「新潟《にいがた》みなまた病《びょう》」** と書く。

### 0.2 この設計書の問題の書き方（読み方）

```
id: <問題の id> | <部品> | obj <到達項目> | L<段階> [| alt] [| aspect <観点> | 本文 <P_名前>]
問: 問題文（prompt）
図: 図（figure。table / textFig）
正: 正解の選択肢（right）           ← multi は「正:」が複数行
誤: 誤りの選択肢 [誤概念ID]         ← wrongs: [文, 誤概念ID]
ヒ1: / ヒ2: / ヒ3: ヒントの3段（hints）
囲: reading の hintFocus（ヒントの段ごと。「p2」は段落2全体、「p2s1」は段落2の1文目、「-」は null）
根: reading の evidence
解: 解説（explain）
```
- sort: `箱:`（boxes）、`札: 文 → 箱の番号(0始まり)`、`誤概念:`（mis）。
- order: `札:` を **正しい順** に書く。`誤概念:`（mis = reverseMisconception）。
- match: `組: 左 ＝ 右`（pairs）。`誤概念:`（mis）。
- fill: `文:`（text。`{{}}` が空欄）、`空欄n: 正解 ／ 誤り[誤概念ID] …`、`選択肢:`（options）、`useOnce`。
- graph: `グラフ:` に GraphData（kind・labels・values・scaleStep・max・unit・title）。
