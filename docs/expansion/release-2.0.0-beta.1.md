# 2.0.0-beta.1（段階1）リリースノート

2.0（対象年齢の拡張）の最初の段階リリースです。**ベータ版**です（実機・子供での確認は未実施）。

## 使えるもの
| 区分 | 内容 |
|---|---|
| 2〜3歳 | 幼児ホーム（札8枚。2歳段階は札4枚＋おえかき、正誤の効果音なし、利用時間の既定5分）。8単元 |
| 4歳 | 初期版（1.0）の9つのあそびを札に残し、新しい単元（数える・はじめの音・ひらがなを読む・きまり など）を足した。初期版のひらがな・さんすう・もじのなぞりも札の中から遊べる |
| 5歳 | かず・とけい・かたち・ひらがな・かたかな・おはなし・もじを かく・きまり・てじゅん（式・カタカナの書きは保護者が開く） |
| 小1〜小4 | 算数（小1 16・小2 16・小3 16・小4 18 単元）、国語（小1 12・小2 8・小3 9・小4 7 単元）、漢字（1・2年の読み・書き 4単元） |
| 全年齢 | おえかき（ペン・消しゴム・塗り・はんこ63種・図形7種・やり直し・自動保存・作品一覧・PNG）、がんばりノート、保護者画面（区分・在籍学年・支援の設定・単元を開く・教材パック・作品の書き出し） |

単元は合計 144（索引 `src/curriculum/unit-index.json`）。どの単元も自動検査（問題の量・網羅・ヒント3段階・誤概念・よみの無い漢字・選択肢の数 など、curriculum-matrix 1.8）に合格し、状態は「実装済み（ready）」です。

## 更新の注意
- 1.0 の記録はそのまま残ります（変換しません）。4歳のホームの初期版のあそびは、1.0 と同じ記録を読みます。

## 検査の結果（2026-10-24、Windows 11 の開発機）
- 単体テスト（Vitest）: 全件合格（教材の自動検査・再発防止のテストを含む）。型検査・lint 合格。DESINGN.md の自動検査・教材パックの分離検査 合格
- E2E（Playwright。Chromium・Firefox）: ホーム・全モード・レイアウト・保護者画面・おえかき・配信 165件合格（10件は対象外のブラウザでスキップ）、オフライン・更新・教材パック 31件合格
  - オフライン・教材パックの E2E は、パックの音声を外したビルドで実行した（検査は仕組みを見るもので、数百 MB の dist を検査ごとに写すと時間切れになるため）。音声入りの本番ビルドは教材パックの分離検査で確かめた
- 教材の内容: 小1〜小4の算数・国語は独立レビュー（Fable）の重大な指摘をすべて修正。幼児（2〜5歳）・小2算数・1・2年漢字は Opus のレビューで見つかった重大25件を修正（レビューした担当が修正。独立レビューではない）
- 配布 zip: 943 MB（教材の音声 約4万6千本を含む）

## 内容レビュー
- 小1〜小4の算数・国語は、独立レビュー（Fable）の重大な指摘をすべて直し、再発を防ぐテストを足しました（小3・小4: 重大8件。二等辺三角形の誤答、等分でない図、計算の順序のヒント、花だんの面積の文、誤概念の説明の付け違い、正解が2つの問題、選択肢の位置の偏り など）。
- 選択肢の正解がいつも1番目に表示される問題（絵・図形・グラフ・穴うめ）は、エンジン側で直しました。
- 残っている軽微な点: 筆算の途中の値など、手順の説明としてヒントに数が出るもの／小4の読解本文の題材の一部の重なり（docs/expansion/progress.md）。

## 既知の制約
- Zorin OS の実機・タッチ・子供での確認は未実施（docs/device-checklist.md）。
- 地図・実験のエンジンは段階1の教材では使っていません。
- 本体を更新すると、教材パックも「あたらしい ばーじょん」と判定され、取り直しになります（ビルドの補助関数が本体側のチャンクに入るため。更新は 127.0.0.1 の配信が動いている間に行うので、保護者画面「きょうざい」から取り直せます）。
