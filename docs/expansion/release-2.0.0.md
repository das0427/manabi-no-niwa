## 教材の内容の確かめ
- 自動検査（全単元）: 問題の量・網羅、ヒントの段数、誤概念、よみの無い漢字、選択肢の数、学年より上の漢字 など（curriculum-matrix 1.8）。
- 小1〜小4の算数・国語: 独立レビュー（Fable）→ 重大な指摘はすべて修正。
- それ以外（幼児・小5・小6・理科・社会・英語・生活・プログラミング・漢字・小2算数）: Opus のレビューで見つかった重大な誤りを、同じ担当がその場で修正（厳密な意味の独立レビューではない）。重大の修正は合計で約190件（正答が2つ成り立つ問題、事実・読み・安全のきまりの誤り、子供に不適切な語・文 など）。どれも再発を防ぐテストを足しています。
- 教材の文・問題はすべてオリジナル（他社の教材・教科書の問題や文を写していません）。

## 配布
- 本体 `manabi-no-niwa-2.0.0.zip` と、小学生の教材の音声 `-audio-g1-g2.zip`・`-audio-g3-g4.zip`・`-audio-g5-g6.zip` の4つ。**すべて同じ場所に展開**してから `install.sh` を実行します（足りないと install.sh が止めて知らせます）。
- 日本語の音声は Open JTalk（Mei）、英語は Kokoro-82M（af_heart）でオフライン生成。実行時に音声合成サービスを使いません。

## 既知の制約（すべての一覧は [handover.md](handover.md)）
- 実機・子供での確認は未実施。初回の準備で本体に保存するファイルが約8,500（幼児と英語の音声を含む）。準備にかかる時間は実機で確認が要る。
- 本体を更新すると、教材パックも「古い」と判定され取り直しになる（ビルドの補助関数が本体側のチャンクに入るため。更新は配信が動いている間に行うので取り直せる）。
- エンジンへの要望のうち未対応のもの（コンパスの作図、商が2けた以上のわり算の筆算、関数のグラフ、世界地図、竹島・尖閣諸島の拡大図 など）は handover.md の D 章。
- 英語の発音・Kokoro の読み、日本語の読み上げの不自然さ（助数詞の音の変化 など）は耳で確かめていない。
