# 2.0.1 リリースノート

2.0.0 からの変更です（教材の中身と音声は 2.0.0 と同じです）。

## 変わったこと
- **「ほかの がくねん」の入口**: 幼児（2〜3歳・4歳・5歳）と小学生のどのホームにも、道しるべの絵の「ほかの がくねん」を足しました。押すと「2〜3さい」〜「6ねん」から選べ、その年齢・学年の遊びや教科を開けます。幼児のホームから小学生の教科も、その逆も開けます。プロフィールの区分は変わりません。
- **導入のしかた**: README の導入手順を、パソコンにくわしくない方でも上から順に進められるように書き直しました（ダウンロードする4つのファイル、端末に貼り付ける1行、困ったとき）。
- **install.sh**: 教材の音声が足りないとき、ダウンロードし直す zip の名前で知らせるようにしました。
- 幼児のホームの右の列で、「おえかき」と「ノート」を横に並べました。

## 更新の注意
- 2.0.0 から更新すると、小学生の教材パックが「版が古い」になります（本体の更新で教材パックの版も変わる既知の制約）。保護者画面「きょうざい」で「まとめて取得し直す」を押してください。学習の記録は消えません。
