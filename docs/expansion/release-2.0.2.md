# 2.0.2 リリースノート

2.0.1 からの変更です（教材の中身・音声・画面の動きは 2.0.1 と同じです）。

## 変わったこと
- **版の表示の誤りを直しました**: 保護者画面「このアプリについて」の版と、データの書き出しファイルに記録する版が、2.0.0・2.0.1 でも「1.0.0」と出ていました（中身は入れた版のものでした）。版の番号を手で書かず、ビルドのときに自動で入れるようにしたので、この版からは「2.0.2」と正しく出ます。

## 更新の注意
- 2.0.1 から更新すると、小学生の教材パックが「版が古い」になります（本体の更新で教材パックの版も変わる既知の制約）。保護者画面「きょうざい」で「まとめて取得し直す」を押してください。学習の記録は消えません。

## 検査の結果（2026-10-24、Windows 11 の開発機）
- 型検査・lint・単体テスト（版の番号が package.json と一致することの検査を追加）・DESINGN.md の自動検査・教材パックの分離検査 合格
- E2E は 2.0.1 で実施済み（画面の動きは変えていない）
- 実機（Zorin OS / Yoga 720）と子供での確認は未実施
