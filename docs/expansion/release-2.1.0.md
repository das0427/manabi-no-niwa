## 保護者画面に出す短い説明
この節の箇条書き（5行まで。1行120字まで。文字として表示するので、太字やリンクの記号は使わない）が、保護者画面「このアプリについて」の「新しいバージョンがあります」の下に出ます（設計: docs/expansion/updater-design.md 3.1 節）。
- 新しいバージョンの確認は自動で行います。入れるときは、保護者画面の「更新する」を1回押すだけです。
- アイコンをもう一度押したときは、開いている窓を前に出して全画面にします。見つからないときは新しい窓で開きます。
- 単元を66増やして324にしました。幼児の英語（聞いて選ぶ）13単元を含みます。
- 使いやすさの直し16件、画面の文字や図の配置の直し、画面の文言の見直しを入れました。
- セキュリティの点検を3回行い、見つかった問題を直しました。直していない点は設計文書に理由を書いています。

## 変わったこと

### 自動更新（保護者画面で「更新する」を1回押す）
- アプリを開くと、新しいバージョンがあるかを GitHub に接続して自動で確かめます（配信が起動して15秒後と、その後12時間ごと。つながっていなければ何もしません）。自動の確認は、保護者画面「このアプリについて」で止められます。
- 新しいバージョンがあれば、変わった点とダウンロードする大きさが出ます。保護者が「更新する」を1回押すと、ダウンロード → 中身の確認 → 切り替え → アプリの読み込み直し → 取得済みの小学生の教材の取得し直しまでを自動で行います。変わっていない音声の zip はダウンロードしません。
- 途中で切れたときは続きから始めます。大きさ・sha256・zip の中のパス・中身・新しい配信の自己検査のどれかが合わないときは、入れずにいまのバージョンのまま使えます。学習の記録・作品・設定には触りません。
- 外へ通信するのは配信（`serve.py`）だけです。行き先は GitHub のリリースと配布用のホストだけで、送るのは HTTPS の GET とアプリの名前だけです。ブラウザは同じ `127.0.0.1:8765` とだけ通信します。
- 設計と確認の記録: docs/expansion/updater-design.md。

### 二重起動の防止（アイコンを2回押したとき）
- すでに開いている窓があれば、新しい窓は開かず、その窓を前に出して全画面にします。窓が見つからないとき、または前に出せなかったときは、今までどおり新しい窓で開き、アプリの中では新しい画面だけを残します（前の画面は保存してから閉じます）。学習の記録は消えません。
- 窓を見つけられるのは X11 の窓（Xorg のセッションのすべての窓と、Wayland のセッションの XWayland の窓）です。Wayland のセッションで Chromium 系のブラウザを新しく起動するときは、`--ozone-platform=x11` を付けます。止めたいときは環境変数 `MANABI_OZONE=native` か `MANABI_SINGLE_INSTANCE=0` を使います（README）。
- 設計と確認の記録: docs/expansion/single-instance-design.md。

- **2.0.x から 2.1.0 へは、1回だけ今までの手順（zip を4つダウンロードして、端末で1行を貼る）で入れ直します。** 2.0.x には自動で更新する仕組みが入っていないためです。2.1.0 を入れたあとは、保護者画面の「更新する」で更新できます（README）。
