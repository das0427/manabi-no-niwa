## 1. 目的（X-GL）

年齢・学年・習熟度に合う学習内容と操作環境を提供し、子供が次を体験できる。

| ID | 体験 | このアプリでの具体 |
|---|---|---|
| X-GL-01 | 自分で始められる | 文字が読めない子は絵と音声だけ、読める子は短い見出しで、ホーム→学習→終わりまで進める |
| X-GL-02 | 何をするか分かる | 各問題の上部に1つの指示（音声つき）。初回はお手本 |
| X-GL-03 | 考えて試せる | 数える・並べる・図を操作する・根拠を探す等、操作が考える過程になる |
| X-GL-04 | 分からないときに助けを得られる | 段階的なヒント、えで みる、解説、聞き直し |
| X-GL-05 | 失敗しても取り組み直せる | 罰なし。誤答の理由に応じた説明とやり直し |
| X-GL-06 | できることの増加を実感できる | 単元の地図（できた所に印）、がんばりノート、作品集。点数・順位は出さない |
| X-GL-07 | 自由に表現できる | おえかき（ロックなし・採点なし） |
| X-GL-08 | 納得して終われる | 短い区切り、終わりの振り返り |
| X-GL-09 | また自分から使いたくなる | 本人の選択と少数のおすすめ。ガチャ・連続日数で釣らない |

最大化しないもの: 利用時間、正答数、連続利用日数。

## 2. 対象と利用者の情報（X-TG）

| ID | 要件 | 受入条件 |
|---|---|---|
| X-TG-01 | 対象区分: 2〜3歳／4歳／5歳／小1〜小6 | プロフィールで選べる。2〜3歳は入口1つで、内部に「2歳段階」「3歳段階」を持ち、操作・指示・選択肢数が変わる |
| X-TG-02 | 次を**分けて**管理する: 年齢の目安、在籍学年、教科・単元ごとの習熟度、支援設定（ふりがな・読み上げ・文字の大きさ・指示の長さ）、画面表現の好み（やさしい／ふつう／おちついた） | データ上別の項目。どれか1つを変えても他は変わらない（単体テスト） |
| X-TG-03 | 学年だけで教材をロックしない | どの学年の単元も保護者が開ける。子供画面の「ほかの がくねん」から先取り・さかのぼりができる（既定は在籍学年の±1） |
| X-TG-04 | 進級（学年を上げる）しても履歴を維持 | 学年変更で記録・作品・習熟度が消えない（E2E） |
| X-TG-05 | 2歳は親子利用を基本 | 2歳段階では保護者向けの案内（いっしょに あそぶ）を表示。スコア・正誤の強調をしない |

## 3. ホームとナビゲーション（X-HM）（v1: HM-01〜06 を置き換え）

| X-HM-01 | 教科→単元→活動で整理。ホームを大量のカードで埋めない | 小学生ホームの第1階層は教科（最大7）と「きょうの おすすめ」と「おえかき」。単元は教科の中 |
| X-HM-02 | 幼児は絵中心の入口 | 2〜5歳のホームは絵のあそび札（最大9）。読めなくても選べる |
| X-HM-03 | おえかきは全対象のホームから直接開ける | すべての区分のホームに「おえかき」入口（1タップ）。ロックなし |
| X-HM-04 | きょうの おすすめは2〜3件、本人の選択を優先 | 他をロックしない。理由を保護者画面で説明 |
| X-HM-05 | 表示の大きさ・倍率に耐える | 1920×1080 と 125%・150%・ブラウザUIで高さが減った場合で、はみ出し・横スクロールなし |
| X-HM-06 | 単元の地図（進み具合） | 単元ごとに「まだ／とりくみちゅう／できた（ふくしゅう まち）」を形と文字で表示。点数・順位は出さない |

## 4. 学習の流れ（X-LP）

| ID | 要件 | 受入条件 |
|---|---|---|
| X-LP-01 | 導入（お手本） | 単元の最初に、具体物→絵→記号をつなぐ短いお手本（音声つき）。いつでも「おてほん」で見返せる |
| X-LP-02 | 自力練習 | 単元の問題は受入条件（acceptance.md 2章）の数の、**異なる**問題がある |
| X-LP-03 | 別例での確認 | 表現を変えた問題（絵→式、文→図 等）を単元に含む |
| X-LP-04 | ヒント | 2段階。答えを直接押させない（v1 learning-design 0.2 の規則を全学年に適用） |
| X-LP-05 | 解説 | 正解後・つぎへ の後に、なぜそうなるかを短く（図・式・根拠の文）。典型的な誤りには誤りに応じた説明 |
| X-LP-06 | 復習 | 自力でできた単元は、日を空けて別例で確認する（間隔反復。1日後→3日後→7日後 等）。おすすめに出す |
| X-LP-07 | 区切りと振り返り | 1回は数問（保護者が変更可）。終わりに「できたこと」を言葉と絵で。中断・再開可 |
| X-LP-08 | 操作ミスと理解不足を区別 | v1 の operationIssue を全エンジンで記録し、保護者画面で別表示 |
| X-LP-09 | 不要な正解の手掛かりを作らない | 正解位置の均等化、長さ・色・模様・強調で答えが分からない（自動検査できる範囲は検査） |
| X-LP-10 | 有効な複数解を認める | 等価表現（分数の約分前後・小数と分数・単位換算）、並べ方、図形の向き、作図の位置 |

## 5. 年齢・学年別の学習内容（X-CU）

| ID | 要件 | 受入条件 |
|---|---|---|
| X-CU-01 | 年齢・学年×教科・領域×単元の対応表を正本とする | curriculum-matrix.md。単元ID・目標・前提・段階・エンジン・教材数・根拠・優先度・状態 |
| X-CU-02 | 各学年を個別に扱う | 小1〜小6の各学年に、国語・算数の単元が個別にある（低中高の3区分で済ませない） |
| X-CU-03 | 中核は国語・算数 | 各学年の国語・算数の P1 単元が acceptance.md の充足条件を満たす |
| X-CU-04 | 生活・理科・社会・外国語活動／英語・プログラミング的活動 | 適用学年に P1 単元があり、残りは対象外・P2 を理由付きで明記。暗記クイズだけにしない |
| X-CU-05 | 4歳も再設計 | 初期版9モードの維持／変更／統合／廃止の判断と根拠・影響を記録（curriculum-matrix.md 4章） |
| X-CU-06 | 5歳は読む力と書く力を分ける | ひらがな・カタカナの読み単元と、運筆・書字準備の単元が別。就学前の先取りを強制しない |
| X-CU-07 | 2〜3歳は読字・細かな操作・多段階指示を前提にしない | 2歳段階はタップのみ、選択肢2つまで、指示は1文 |
| X-CU-08 | 漢字は読みと書きを分ける | 読み: 語の中で選ぶ・入れる。書き: 書き順のなぞり＋お手本比較（手書きの字形を自動で正誤判定しない）。未習漢字は問題文に使わずふりがな |
| X-CU-09 | 英語は評価できる範囲を明確に | 聞いて選ぶ・文字・語の範囲を自動判定。話す・書くは自動評価しない（お手本・振り返り） |
| X-CU-10 | 実装範囲を超えて「全教科完全対応」と称さない | README・アプリ内の説明に、対応範囲と対象外の一覧へのリンク |

| X-UX-08 | 連打で二重回答・二重遷移しない | v1 の仕組みを全エンジンへ |

## 8. おえかき（X-DR / X-ST / X-SH / X-SV）（新規）

### 8.1 基本（X-DR）
| ID | 要件 | 受入条件 |
|---|---|---|
| X-DR-01 | 全対象・全プロフィールで使える自由なおえかき。ロックなし。採点・正解・見本一致を強制しない | ホームから1タップ。記録（attempts）を作らない |
| X-DR-02 | なぞり・文字練習・問題書き込みとは別機能 | 別の画面・別の保存 |
| X-DR-03 | 道具: ペン（ブラシ）、色、線の太さ、消しゴム、元に戻す／やり直す、塗りつぶし、新しいキャンバス、保存・一覧・再編集、PNG書き出し、自動保存・中断後の復元、はんこ、図形 | 各道具の E2E |
| X-DR-04 | 指・マウス・タッチパッドで使える。ペン・筆圧は任意 | 筆圧なしで全機能。ペンの筆圧は「あれば線の太さに反映」（設定で無効化可） |
| X-DR-05 | 道具の表示: 「かんたん」と「くわしく」を同じ描画基盤で切り替え。年齢で初期値を提案、切り替え可 | かんたん: 大きな色8色程度・太さ3段・ペン・消しゴム・はんこ・図形・もどす・ほぞん。くわしく: 色の細分・サイズ・回転・選択編集・重なり順 |
| X-DR-06 | 状態（かく／おす／えらんで うごかす）を明確に。絵柄を選んだだけでキャンバスに置かない | 道具欄に今の道具の大きな表示。はんこは「えらぶ→キャンバスをタップ」で初めて置く |
| X-DR-07 | 操作の安定 | 描画中にページがスクロール・ズームしない／速い線が途切れない（coalesced events）／指を離して再開できる／画面回転・サイズ変更で作品が消えない／色変更・保存で表示位置や倍率が変わらない |
| X-DR-08 | 誤操作防止 | 全消去・削除・破棄は確認（絵と文字。幼児は2段階: 押す→「ほんとうに？」の大きな札） |
| X-DR-09 | 保存状態を非読字の子にも伝える | 保存中・保存済み・保存失敗を絵（くも／チェック／！）と音で |
| X-DR-10 | 手の接触対策 | ブラウザで可能な範囲（pointerType の区別、ペン使用中はタッチ描画を無視する設定）。OS・ブラウザの制約を README に記載 |

### 8.4 編集・重なり（X-ED）

## 9. 習熟と進度（X-AD）（v1: AD-01〜09 を拡張）

| ID | 要件 | 受入条件 |
|---|---|---|
| X-AD-01 | 単元（スキル）ごとの進度。1問で急変しない | v1 の規則（ラウンドの終わりに判定・窓10件・偶然の確率を考慮）を全単元へ |
| X-AD-02 | 自力・支援（ヒント）・見直し・再挑戦・中断を区別 | v1 の結果の種類を継続 |
| X-AD-03 | 時間だけで理解を判定しない。暗記・連打を考慮 | 復習は別例で出す（同じ問題を繰り返して習得扱いにしない） |
| X-AD-04 | 後日に別例で確認 | 「できた」になった単元は復習で別例を出し、復習で自力でできて初めて「しっかり できた」 |
| X-AD-05 | 難易度は原則一要因ずつ | 単元内の段階の変更要因を curriculum-matrix に記録 |
| X-AD-06 | 保護者の固定・変更、単元を開ける・閉じる | 保護者画面 |
| X-AD-07 | 進級時も履歴維持 | X-TG-04 |

## 13. データ・オフライン・更新（X-DA / X-OF）

| ID | 要件 | 受入条件 |
|---|---|---|
| X-DA-01 | 既存のプロフィール・履歴・作品を保全 | v1 のデータで新版を起動して、記録・作品・設定が残る（移行テスト・E2E） |
| X-DA-02 | 旧記録の対応付け | 4歳の単元へ確実に対応付けられるものだけ新しい単元の記録として扱い、それ以外は「旧記録」として閲覧のみ。対応付けが不確かな履歴を新単元の習得済みに変換しない |
| X-DA-03 | スキーマ移行（v1 → v2） | 段階的な移行（db.ts の UPGRADES[2]）。途中失敗で元データが残る |
| X-DA-04 | インポート形式・サイズ検証、無断上書き防止 | v1 と同じ＋v1 形式のファイルも読み込める |
| X-OF-01 | 教材パック単位の取得 | 区分（幼児・小1〜小6）×教科のパック。保護者画面で取得・削除・容量表示。取得済みはオフラインで使える |
| X-OF-02 | 未取得の説明 | 未取得の単元は「おうちの人に ダウンロードしてもらってね」（保護者画面への案内） |
| X-OF-03 | 画面と教材の版の整合 | パックに対応する画面の版を持ち、合わない版は使わない（再取得を案内） |
| X-OF-04 | 起動時に教材・画像を一括読み込みしない | 単元を開くときにパックを読み込む（遅延読み込み）。起動時の読み込みサイズの上限を設ける |
| X-OF-05 | 更新で学習を中断しない／旧データ移行 | v1 と同じ |
| X-OF-06 | Firefox も検証。PWA と通常利用を区別。file:// だけで動くと説明しない | E2E と README |
| X-OF-07 | ローカル配信は 127.0.0.1 限定。OS 設定・サービス登録を無断で行わない | v1 と同じ |
