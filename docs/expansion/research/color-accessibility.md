# 配色・可読性・アクセシビリティ調査（子供・日本語・数式・図表）

確認日: 2026-10-24。担当: 調査（Sonnet）。本文を読めた資料は「取得可」、検索結果の要約だけ・PDF が読めなかった資料は「二次」「未確認」と明記する。数値のうち「計算」はこの調査で算出したもの。

## 0. 先に結論

- 現行の子供画面は **文字の大半が `--ink` 系で十分**（--ink on --paper 9.85:1）。弱点は次の4点。
  1. 主操作ボタンの文字 `--white on --leaf` が **3.17:1**（通常文字の 4.5:1 に届かず「大きな文字」扱いの 3:1 にぎりぎり）。
  2. 正解の ○ の輪（`--leaf`）が `--paper` 上で **2.97:1**（非テキスト 3:1 に 0.03 不足）。
  3. 教材色 `--mat-red` と `--mat-green` は D型の見え方で **ΔE 5.6**（ほぼ区別不能）。
  4. 保護者画面（12〜15px の通常文字）の `--berry` 文字 3.53:1、`--ink-soft` on `--paper-2` 4.27:1、入力欄の枠 2.12:1。
- 「白背景のまぶしさ」を避ける根拠は弱い。`--paper` の輝度は純白の 0.917 倍で、差は約 8%。
- 色が学習成績を上げる、という断定はできない（§2.2）。最低基準への適合は使いやすさの保証でもない（§6）。

## 2. 基準・研究・ガイドの整理

### 2.1 基準（そのまま適用する数値と条件）

| 項目 | 内容 | 適用条件・注意 |
|---|---|---|
| 1.4.3 コントラスト（最低限）AA | 文字と背景 **4.5:1**。大きな文字は **3:1** | 計算値は丸めない（4.499 は不適合）。操作不可の部品の文字、装飾、ロゴは対象外。背景画像上の文字は通常の表示で重なる背景に対して判定 |
| 「大きな文字」 | 18pt 以上、または太字 14pt 以上。CJK フォントは「同等の文字サイズ」 | 96dpi の CSS px で 18pt=24px、14pt=18.67px（計算）。CJK の同等サイズの数値は Understanding にも明示なし。日本語は欧文より同じ pt でも字面が大きいことがあるが、**数値の換算は公式に無い**ため、この境界に頼らず 4.5:1 を目標にするのが安全 |
| 1.4.11 非テキストのコントラスト AA | UI 部品の識別に必要な視覚情報、状態（選択・フォーカス）、意味のある図形は隣接色と **3:1** | 部品が文字で識別できれば枠は不要。ただしフォーカス表示は必要。無効状態は対象外。グラデーションは最も低い所で判定。ホバーの装飾は 3:1 不要。**色相だけの変化は 1.4.1 で不適合になりうる** |
| 1.4.1 色の使用 A | 色を情報伝達・操作・応答・要素の区別の**唯一の手段にしない** | Understanding: 色相差に明度差があり 3:1 以上ならそれも手がかりと数える。別の手がかり（形・文字）には 3:1 の要求は書かれていない。「緑の枠と赤の枠」のように特定の色の知覚が必要なら追加の手がかりが必須 |
| 2.5.8 ターゲットのサイズ（最低限）AA | ポインタ操作の対象は **24×24 CSS px** 以上 | 例外: 間隔（24px の円が他の対象に重ならない）、同等の別操作、文中、UA 制御、必須。子供への言及はなし |
| 2.5.5 ターゲットのサイズ（強化）AAA | **44×44 CSS px** | 間隔の例外は無い（同等・文中・UA・必須のみ） |
| 2.4.7 フォーカスの可視 AA／2.4.11 フォーカスで隠されない（最低限）AA／2.4.13 フォーカスの外観 AAA | 2.4.13: 非フォーカス時の外周 2px 分以上の面積で、変化が **3:1** | 2.4.13 は AAA（任意） |
| 1.4.12 テキストの間隔 AA | 利用者が行間 1.5、段落後 2、字間 0.12、語間 0.16（いずれも文字サイズ比）に上書きしても内容・機能が失われない | 日本語は語間・段落後を使わないため、該当する性質だけで適合できる。「既定をその値にせよ」ではない。固定寸法の舞台で文字がはみ出さないかの確認が要る |

- **WCAG 3.0 は草案**（2026-09-10 Working Draft）。「WCAG 2 を廃止しない」と明記。コントラスト算法は「未定」と本文にある。現行の判定は WCAG 2.2 の比で行う。
- **JIS X 8341-3:2016** は WCAG 2.0（ISO/IEC 40500:2012）と内容を一致させた規格。1.4.11（2.1 で追加）、2.5.8（2.2 で追加）は JIS 2016 の適合基準には含まれない。改正審議（WCAG 2.2 = ISO/IEC 40500:2025 との一致）が 2025-10 に始まったとの記事が1件あるが、公式発表では確認できていない（未確認）。このアプリは公開 Web サイトの適合表記を求められる立場ではないが、設計上は WCAG 2.2 AA を基準にするのが妥当。

### 2.3 ガイド（推奨）

- **CUDO「3つのポイント」**: (a) できるだけ多くの人に見分けやすい配色を選ぶ、(b) 色を見分けにくい人にも情報が伝わるようにする、(c) 色の名前を使ったコミュニケーションを可能にする。
- **有病率**: CUDO は P型・D型が日本人男性の約20人に1人、女性の約500人に1人、全体で 320万人以上（後天を含め約500万人）、C型は男性約95%・女性99%以上と記す。T型は同ページに記載なし。岡部・伊藤はアジア系男性の赤緑型を5%（欧州系8%・アフリカ系4%）、T型を約 0.001% とする。女性の割合は資料により 0.2%・1%と幅がある。**P型とD型の内訳の数値は今回取得できず（未確認）**。
- **岡部・伊藤の推奨**: 色だけに頼らず形・位置・線種・ハッチを併用する。明度差・彩度差を使う。赤と緑の組を避ける。凡例でなく直接ラベルを付ける。純粋な暗い赤は P型に黒く見えるので朱色寄りに。線は太く、文字は太く。
- **CUD推奨配色セット**: アクセント9色（小面積・サイン・グラフ向け）、ベース7色（大面積向け）、無彩色4色の計20色。2009年に伊藤啓らが日本塗料工業会・DICと作成。ver2 暫定 RGB は赤 (255,51,0)、黄 (255,255,0)、緑 (51,153,102)、青 (0,65,255)、空色 (102,204,255)、ピンク (255,153,153)、橙 (255,153,0)、紫 (153,0,102)、茶 (138,59,43) など。現行版の値は未確認。
- **学校**: 平成23年度使用開始の小学校教科書から多様な色覚への配慮が必須（CUDO 資料の要約・二次）。2002年に色覚検査が健診の必須項目から外れた（二次）。
- **文部科学省 拡大教科書規格（弱視向け・紙）**: 本文は 22pt 程度（小3まで 26pt 程度）、ゴシック体の中太、ルビは本文の半分以上、ルビのある行は行間を広く、背景色が文字を邪魔するなら除去、文字の影・紛らわしいグラデーションは除去、反射の少ない紙。教科書体は初出の仮名・新出漢字に使う。
- **ルビ**: JLReq は「原則として親文字の1/2」。親文字が約7pt未満ではルビを付けず括弧書きを勧める。

## 3. 色トークン設計への示唆（役割別の条件）

数値は WCAG 2.2 の基準（基準）か、この調査からの提案（提案、研究の裏付けは弱い）かを区別する。「内部目標」は設計判断で、研究の裏付けはない。

| 役割 | 守る条件 | 色以外の手がかり | 現行の状況 |
|---|---|---|---|
| 背景（紙）・教材面（白カード） | 面どうしは色差に頼らず**輪郭線で分ける**（白カード vs paper は 1.07:1）。まぶしさ対策の根拠は弱いので、保護者設定で背景（既定／より暗い／白黒反転）を選べるようにするのが安全（反転希望は 28%、不要が 69%） | 輪郭線 | ink の輪郭 0.35u で成立 |

追加の提案:
- **押せる大きさ**: 現行の最小 5〜6u は、u が最小の 5px でも 27.5〜30px で 2.5.8 の 24px を満たす。44px（2.5.5）は主操作で u≥7.33px、補助操作で u≥8px（舞台幅約 800px 以上）が必要。実機 1920px では約 106〜115px。ただし 24px が子供の指に十分という意味ではない（§6）。
- **保護者画面**: ボタンは `padding: 5px 12px` で、DESINGN の「44px 以上」との整合を実測で確認する（今回は未測定）。
- `prefers-contrast`、`forced-colors`、ダークモードの対応は `src` に無い（grep で該当なし）。保護者設定での切替を検討する。
- **ルビ**（小学生向けに漢字を使う場合）: 親文字の 1/2 を基本とし、ルビ付きの行は行間を広げる。字体は教科書体（初出の仮名・新出漢字）かUDフォント。学年別の「最適な文字サイズ」の公的数値は今回見つからず（未確認）。Katzir の結果は学年で最適が変わることだけを示す。
- 提案する具体の色（要・実機と子供での確認）: `--leaf` を #357A38 前後に暗くすると white 文字 5.17:1、paper 上で ○ が 4.84:1。`--ink-soft` を #6B5B50 にすると paper-2 上 5.34:1。保護者画面の berry 文字は #B4432F で white 上 5.46:1。

## 4. 現行アプリの色のコントラスト比（計算）

方法: sRGB を線形化し、相対輝度 L = 0.2126R + 0.7152G + 0.0722B、比 = (L1+0.05)/(L2+0.05)。丸めずに判定し、表は小数第2位。線形化の閾値は 0.04045（WCAG 本文の 0.03928 との差は結果に影響しない）。半透明やcolor-mix は事前に合成して算出。

## 5. 色覚シミュレーションの見立て

**方法**: Viénot・Brettel・Mollon (1999) の簡易法（P型・D型の2色覚）。sRGB を線形化し、線形RGB→LMS は DaltonLens の掲載行列（Viénot 推奨、Smith-Pokorny 由来）を使用。投影は P型で L = 2.02344M − 2.52581S、D型で M = 0.494207L + 1.24827S（係数は文献値の記憶によるもので、今回の取得資料では確認できていない。白と灰色が不変であることで内部整合は確認）。逆変換後に sRGB へ戻す。Brettel 1997 の2平面法とT型は使っていない。指標は、シミュレーション後の色どうしの CIE76 ΔE*ab と輝度比。目安は私の設定で、**ΔE<15 は区別が難しい、15〜30 は注意**（規格ではない）。2色覚の近似であり、軽度の色覚特性（異常3色覚）では差はこれより小さい。

| 組み合わせ | 通常 ΔE（輝度比） | P型 ΔE（輝度比） | D型 ΔE（輝度比） | 見立て |
|---|---|---|---|---|
| **mat-red vs mat-green** | 90.1（1.42） | 32.7（2.02） | **5.6（1.20）** | D型でほぼ同じ色。仕分け教材で最重要 |
| mat-red vs mat-yellow | 68.4（2.37） | 61.3（2.96） | 44.4（2.16） | 区別可 |
| mat-green vs mat-yellow | 55.7（1.67） | 29.0（1.47） | 42.5（1.80） | P型で注意 |
| leaf vs berry | 79.6（1.11） | **16.2（1.52）** | **12.8（1.04）** | 近い明度で、両型で近づく |
| berry vs leaf-dark | 75.9（1.55） | **5.8（1.14）** | 24.4（1.79） | P型で区別不能 |
| leaf vs wood | 47.9（1.50） | **8.3（1.30）** | 20.2（1.62） | P型で区別不能（○が木のピース上） |
| leaf-dark vs wood-dark（札の段差どうし） | 47.3（1.38） | **7.9（1.18）** | 21.9（1.51） | 同上 |
| mat-green vs wood | 48.9（1.30） | **11.0（1.13）** | **10.9（1.41）** | 両型で近い |
| berry vs wood-dark | 30.5（1.12） | 11.1（1.03） | **5.0（1.19）** | 両型で近い |
| leaf vs sky／sun vs wood／sky vs paper-2 | 56.8／26.5／37.6 | 54.5／26.6／33.3 | 54.0／26.4／40.7 | 型による変化は小さい（元々の差による） |

グレースケールの L*（計算）: leaf 59.5、berry 56.3、mat-red 53.4、mat-green 63.7。**赤・緑・berry が同じ明度帯に集まっている**ため、色相差が見えない条件では区別の手がかりが残らない。一方、黄・sun・wood・sky は L* 72〜81 の明るい側にある。

参考として、CUD 暫定セットの赤 (255,51,0) と緑 (51,153,102) は通常の輝度比が 1.03 で、D型 ΔE 50.1・P型 28.3 と現行の赤緑よりずっと大きい。Okabe-Ito の朱 (#D55E00) と青緑 (#009E73)（二次情報の値）も D型 ΔE 53.1、P型 35.9。現行の mat-red を暗く、mat-green を明るくする案（例: #B83A2E と #9AD07A）では輝度比 3.17、D型 ΔE 30.9、P型 48.6 になる。ただし「みどり」と子供が認識できるかは未確認で、**色名の併記と絵・位置が必須**という現行方針（DESINGN 3.1）の方が確実。

## 6. 限界（最低基準への適合は「子供が使いやすい」の保証ではない）

1. **対象が違う**: WCAG・JIS は成人を含む一般利用者を想定した最低限の水準で、子供専用の閾値はない。Katzir 2013 のとおり、文字サイズの最適は学年で変わりうる。2〜3歳は文字を読まず、色・形・位置が手がかりになる。
2. **比は輝度差の一つの指標にすぎない**: 文字の太さ・字形・大きさ、行間、画面の反射、屋外の光、画面の品質は含まれない。薄い細線や小さな絵は比を満たしても見えにくい。
3. **24px や 44px は目安**: 子供は小さい対象を外しやすい（Anthony ら）。物理寸法（mm）での実機評価が必要（DESINGN 10・13章）。
4. **色覚シミュレーションは近似**: 2色覚の簡易法で、個人差・弱度を再現しない。画面の色再現にも依存する。最終判断は色覚多様な当事者の確認による。
5. **背景色・書体の「子供に効く」根拠は弱い**: UD体は客観差なし（主観の好みのみ）、色付きオーバーレイは根拠不十分、暖色背景は成人の短文の研究。白背景を避ける設計は予防的な判断であり、効果の主張はできない。
6. **色の学習効果は断定しない**（§2.2）。
7. 今回読めなかった資料: 東京都ガイドライン本文、MEXT デジタル教科書ガイドライン本文、慶應ポスターの原資料、Rello & Bigham 原文。
