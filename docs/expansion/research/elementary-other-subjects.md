## 3. 生活科（1・2年）

### 3.1 事実（本文・解説より）

- 教科目標: 具体的な活動や体験を通して、身近な生活に関わる見方・考え方を生かし、自立し生活を豊かにしていく資質・能力を育てる。
- 内容は9項目で、三つのまとまりに分かれる（本文 第2 内容）。

| まとまり | 項目 | 要旨 |
|---|---|---|
| 学校・家庭・地域の生活 | (1) 学校と生活 | 学校の施設、支えている人々、友達、通学路とその安全を守る人 |
| | (2) 家庭と生活 | 家族のこと、自分でできること、役割、規則正しく健康な生活 |
| | (3) 地域と生活 | 地域の場所、そこで生活・働く人々、安全な生活 |
| 身近な人々・社会・自然と関わる | (4) 公共物・公共施設の利用 | みんなで使うものと、それを支える人。大切に安全に使う |
| | (5) 季節の変化と生活 | 自然観察、季節や地域の行事、四季の変化と生活の変化 |
| | (6) 自然や物を使った遊び | 遊びや遊びに使う物を工夫してつくる |
| | (7) 動植物の飼育・栽培 | 生命をもち成長していることへの気付き。2学年間継続して扱う |
| | (8) 生活や出来事の伝え合い | 相手を想像し、伝えたいことや伝え方を選ぶ |
| 自分自身の生活や成長 | (9) 自分の成長 | できるようになったこと、支えてくれた人への感謝、これからへの願い |

- 学習活動は「見付ける、比べる、たとえる、試す、見通す、工夫する」などの多様な活動で行う。気付きを言葉、絵、動作、劇化などで表現して確かにする（内容の取扱い）。
- 校外での活動を積極的に取り入れる（指導計画の作成）。
- 情報機器について、解説は「デジタルカメラやタブレットの画像を成長の振り返りや発表に使う」例を挙げる一方、低学年は操作に戸惑う児童が多いので計画的に取り入れるとしている。
- 幼児期の終わりまでに育ってほしい姿との関連、入学当初のスタートカリキュラム（生活科を中心とした合科的・関連的な指導）が明記されている。

### 3.2 アプリでの扱い方（示唆）

- 生活科の中心は実際の町探検・飼育・栽培・遊びなので、アプリで代替しない。「やってきたことの記録と振り返り」の補助に限る。
- 学習の根拠: 気付きを表現して確かにする、成長を振り返る、という点が資料に明記されているため。

| 項目 | アプリで扱える度合い | 理由（示唆）と案 |
|---|---|---|
| (9) 自分の成長 | 高 | 振り返りが活動の本体。「できるようになったこと」記録帳、年ごとの比較。個人情報は端末内のみに保存 |

## 4. 理科（3〜6年）

### 4.1 事実: 学年ごとの問題解決の力と単元

解説より、学年で主に育てる問題解決の力は次のとおり。

| 学年 | 主に育てる力 | 中心となる考え方 |
|---|---|---|
| 3年 | 差異点や共通点を基に問題を見いだす | 比較する |
| 4年 | 既習や生活経験を基に、根拠のある予想や仮説を発想する | 関係付ける |
| 5年 | 予想や仮説を基に、解決の方法を発想する | 条件を制御する |
| 6年 | より妥当な考えをつくりだす | 多面的に考える |

問題解決の過程（解説）は、自然の事物・現象への気付き → 問題の設定 → 予想や仮説の設定 → 検証計画の立案 → 観察・実験 → 結果の処理 → 考察 → 結論の導出。これらの考え方は他の学年でも用いる（学年固定ではない）。

単元（本文 第2 内容）:

| 学年 | A 物質・エネルギー | B 生命・地球 |
|---|---|---|
| 3年 | 物と重さ / 風とゴムの力の働き / 光と音の性質 / 磁石の性質 / 電気の通り道 | 身の回りの生物 / 太陽と地面の様子 |
| 4年 | 空気と水の性質 / 金属、水、空気と温度 / 電流の働き | 人の体のつくりと運動 / 季節と生物 / 雨水の行方と地面の様子 / 天気の様子 / 月と星 |
| 5年 | 物の溶け方 / 振り子の運動 / 電流がつくる磁力 | 植物の発芽、成長、結実 / 動物の誕生 / 流れる水の働きと土地の変化 / 天気の変化 |
| 6年 | 燃焼の仕組み / 水溶液の性質 / てこの規則性 / 電気の利用 | 人の体のつくりと働き / 植物の養分と水の通り道 / 生物と環境 / 土地のつくりと変化 / 月と太陽 |

補足（指示文面との差異）: 統括指示の例にある「4年 空気と水の性質・電流の働き・人の体のつくり・季節と生物・月と星・雨水の行方」は本文と一致。3年には風とゴムの力・光と音も含まれる。5年「魚の誕生」は本文では「動物の誕生」（魚と人の発生）、6年は「月と太陽」。

主な取扱いの注意（本文）: 3年は「夏生一年生の双子葉植物」、4年は電流で直列・並列、5年は人の受精に至る過程を扱わない、6年は主な臓器として肺・胃・小腸・大腸・肝臓・腎臓・心臓。天気・川・土地では災害に関する基礎的理解にも触れる。観察・実験は事故防止に十分留意する。ものづくり（3年は3種類以上、4〜6年は2種類以上）が求められる。

### 4.2 アプリでの扱い方（示唆）

- 解説は「観察、実験は直接体験が基本」とし、コンピュータや映像は学習の充実のために適切に活用するとしている（6年の体の仕組みでは映像・模型・コンピュータシミュレーションの活用に言及）。よってアプリは実験の代替ではなく、「予想→条件→結果→考察」の思考を練習する補助にする。
- 取り入れやすい形:
  1. 観察の比較: 2つの絵・写真から「同じところ・違うところ」を選ぶ（3年の差異点・共通点）。
  2. 条件制御の問題: 「何を変え、何を同じにするか」を選ぶ。振り子の長さ・おもりの重さ・振れ幅、物の溶ける量と水の温度など（5年）。
  3. 結果の表・グラフの読み取り: 値の表、折れ線、棒グラフから「分かること」を選ぶ（4年の気温の変化、5年の発芽の条件など）。
  4. 予想・考察の文を組み立てる（「〜だから〜と思う」の型）。根拠のある予想（4年）、より妥当な考え（6年）の練習。
- シミュレーションの注意（示唆）: 簡単な動きは作れるが、現実の誤差や失敗を再現しないと「必ずうまくいく」と誤解させる。結果は「このアプリの設定ではこうなる」と明示し、可能なら実物で確かめる案内を添える。薬品・火・電気の危険な操作を促さない。安全な家庭でできる観察に限る。

| 単元 | アプリで扱える度合い | 理由（示唆） |
|---|---|---|
| 振り子（5年） | 高 | 条件制御の典型。変数が少なくシミュレーションと表・グラフで再現しやすい |
| 物の溶け方（5年） | 中 | 表の読み取り・条件の整理は得意。溶け残りなど現象の実感は実物が必要 |
| 電流がつくる磁力（5年）/ 電気の利用（6年） | 中 | 回路の組み立てや条件の比較は可能。感電・発熱の実験は誘導しない |
| 電気の通り道・磁石・光と音（3年） | 中 | 「通す・通さない」の分類は可能。実際に触れる体験が先 |
| 月と星・月と太陽・太陽と地面（3・4・6年） | 中〜高 | 位置関係や時間変化の図示に向く。夜間観察は安全と地域差に注意 |
| 天気の変化・雨水・流れる水・土地（4〜6年） | 中 | 資料（雲の画像・地層図）の読み取りは可能。災害への触れ方は慎重に（本文が自然災害に触れるとしている） |
| 動植物・人の体・発芽・動物の誕生 | 中〜低 | 観察記録は可能。人の発生では受精の過程を扱わない（本文）。表現に配慮 |
| 燃焼・水溶液・てこ（6年） | 中 | てこは「つり合い」のシミュレーションが向く。燃焼・水溶液は危険を伴う実験なので結果の読み取り中心 |
| 物と重さ・風とゴム・空気と水・温度（3〜4年） | 中 | 比較・関係付けの問題は作れるが、体感（押し返す力など）は実物 |

## 5. 社会（3〜6年）

### 5.1 事実: 学年ごとの内容（本文）

| 学年 | 内容 |

| 4年 | (1) 都道府県の様子 (2) 人々の健康や生活環境を支える事業（水・電気・ガス、ごみ・下水） (3) 自然災害から人々を守る活動 (4) 県内の伝統や文化、先人の働き (5) 県内の特色ある地域 |

資料の扱いに関する本文の要点:

- 3年: 白地図にまとめる際に方位と主な地図記号を扱う（解説の例: 学校・警察署・消防署・工場・神社・市役所・病院・田・畑・鉄道・駅・道路など。地域の実態に応じて必要なものを扱う）。年表では、昭和・平成など元号を用いた言い表しがあることを取り上げる。方位は四方位から始め、八方位は4年修了までに身に付ける（解説）。
- 4年: 47都道府県の名称と位置を理解する。47都道府県と世界の大陸・主な海洋は、学習内容と関連付けて地図帳・地球儀で確認し、小学校卒業までに身に付け活用できるようにする。
- 5年: 領土は竹島・北方領土・尖閣諸島が固有の領土であることに触れる。地図帳・地球儀・統計などの基礎的資料で調べる。位置は方位、緯度・経度で表す。産業・情報では「情報の送り手と受け手」の立場から多角的に考える。
- 6年: 憲法、三権、国会・内閣・裁判所、裁判員制度、租税、参政権・納税の義務を扱う。歴史は大まかな流れを、人物（例示あり）と文化遺産を通して扱い、年表や絵画など資料の特性に留意した読み取り方も指導する。国際では日本とつながりの深い国を数か国取り上げ、児童が1か国を選んで調べる。国旗・国歌の尊重（自国・諸外国）。
- 全体: 多様な見解のある事柄・未確定な事柄は、有益適切な教材に基づき、特定の事柄を強調し過ぎたり一面的に扱ったりしない。出典・作成経緯を吟味して資料を使う（解説）。学習は調査・見学・聞き取り、選択・判断、説明や議論を重視する（本文 内容の取扱い）。

### 5.2 アプリでの扱い方（示唆）

- 暗記クイズだけにしない。資料から読み取り、根拠を述べ、選択・判断する形にする。
  - 地図: 地図記号と方位を使って「この地図で○○はどの方角か」を読む。記号は「覚える」より「地図の中で使う」。
  - 年表: 出来事を並べ替える、元号と西暦の対応、「いつ・何が変わったか」を読む（3年は市の移り変わり、6年は歴史）。
  - グラフ・統計: 読み取りの練習に使う。最新値を固定せず、出典年を明示（下記注意点）。
  - 選択・判断: 「どれがよいか、理由は」を選ぶ形（ごみの減量、防災の備えなど。本文が「自分たちにできること」の選択・判断に触れている）。
  - 国旗・47都道府県の位置は、本文が確認を求める事項なので、地図クイズとして繰り返し遊べる形に向く。
- 注意点（示唆）:
  - 時事・統計: 人口・産業額・地図（市町村合併、地名）は更新される。アプリはオフラインなので、数値に「何年のもの」を表示し、学習の目的（グラフを読む）に使えるように、実在の最新値でなく「例示データ」と明記するのが安全。
  - 領土・歴史・政治: 5年の領土、6年の政治・歴史は本文の記述に沿った事実の範囲に留め、評価や意見が分かれる事柄には断定的な表現を使わない（解説の趣旨）。
  - 地域学習（3・4年の身近な地域・都道府県）は地域差が大きく、全国共通の正解にできない。一般的な例か、ユーザー入力型にする。
  - 日本地図・都道府県の範囲や境界は図の出典を明示する。

|---|---|---|
| 地図記号・方位・地図の読み取り（3年） | 高 | 資料読み取りが本質。ゲーム化しやすい |
| 47都道府県の名称と位置（4年） | 高 | 本文が到達を求める事項。位置の反復に向く |
| 年表・並べ替え（3・6年） | 高 | 資料読み取りが本質。 |
| 統計・グラフの読み取り（5年） | 中〜高 | 読み取り練習は作れるが、実データの鮮度に注意 |
| 産業（農業・水産業・工業）（5年） | 中 | 事例（稲作など）の選択は教科書ごとに異なる。分布の地図読み取りを中心に |
| 政治（憲法・三権）（6年） | 中 | 仕組みの図の理解は可能。判断が分かれる論点は扱わない |
| 歴史（6年） | 中 | 年表・人物・文化遺産の対応は可能。単なる人名暗記にしない |
| 地域の安全・事業・防災（3・4年） | 中 | 仕組みの理解は可能。実際の施設は地域依存 |
| 国際理解（6年） | 中〜低 | 多様性の尊重が目的。特定の国の固定的イメージを避ける |

## 6. 外国語活動（3・4年）と外国語（5・6年）

### 6.1 事実（本文・解説）

| 項目 | 外国語活動（3・4年・各35時間） | 外国語（5・6年・各70時間） |
|---|---|---|
| 位置づけ | 教科ではない。コミュニケーションを図る素地 | 教科。コミュニケーションを図る基礎 |
| 領域 | 聞く / 話す[やり取り] / 話す[発表]（3領域） | 聞く / 読む / 話す[やり取り] / 話す[発表] / 書く（5領域） |
| 聞く | ゆっくり話されたとき、自分のことや身の回りの物の語句、基本的な表現の意味、文字の読み方の発音から文字が分かる | ゆっくり話されたとき、身近な事柄の語句・表現、具体的な情報、短い話の概要 |
| 読む | 目標に含まれない | 活字体の文字を識別し発音する。音声で慣れ親しんだ語句・表現の意味が分かる |
| 話す[やり取り] | 挨拶、感謝、簡単な指示。動作を交えて、サポートを受けて質問に答える | 指示・依頼とその応答、考えや気持ちの伝え合い、その場での質問と応答 |
| 話す[発表] | 実物などを見せながら語句や基本的な表現で話す | 身近な事柄・自分のことを、内容を整理して話す |
| 書く | 目標に含まれない | 大文字・小文字を活字体で書く。語順を意識して語句・表現を書き写す。例文を参考に自分に関することを書く |
| 文字 | 文字の名称の読み方を聞いて、活字体の大文字・小文字と結び付ける程度。音声コミュニケーションの補助 | 活字体の大文字・小文字、終止符・疑問符・コンマなどの符号 |
| 語数 | 示されない（5・6年の語数に含まれる） | 3・4年の外国語活動で扱った語を含む600〜700語程度 |

- 語数の解説: 600語は小学校の外国語活動と外国語科で指導する語数の下限、700語は目安で上限ではない。受容語彙（聞く・読んで分かる）と発信語彙（話す・書く）の両方を含み、すべてを覚えて使うということではない。小学校では聞く・話すの語彙が中心になる。
- 文の例: 疑問文は be動詞・can・do 始まりと who/what/when/where/why/how、代名詞（I, you, he, she など）、動名詞・過去形の基本的なもの。文法用語・用法の指導に偏らない。
- 解説は、中学年で英語の発音と綴りの法則を教え込む指導は不適切としている。文字の指導は名称レベルに留める。
- 発音: 「現代の標準的な発音」を指導するが、特定の地域・グループの発音に偏らないことが解説に書かれている。日本語との違いに留意し、発音練習を行う。
- 言語活動の例: イラスト・写真と語句を結び付ける、日付・時刻・値段を聞き取る、自己紹介、買物・食事・道案内などの場面。
- ICT: 視聴覚教材やデジタル教材の有効活用が挙げられている。ネイティブ・スピーカー等の協力を得ることも記載。

### 6.2 アプリでの扱い方（示唆）

- 発音の自動評価は難しい（子供の声・端末のマイク・訛りの多様性を考えると、正誤判定は誤判定の害が大きい）。資料にも自動評価の言及はない。→ 判定ではなく「お手本を聞く → まねして言う → 自分の録音を聞き比べる（任意）」のセルフチェックに留める。録音を保存するなら端末内のみ、既定では保存しない。
- 向く活動: 聞いて絵を選ぶ、語句とイラストの結び付け、アルファベットの大文字・小文字の対応、文字の名称を聞いて選ぶ、文の語順の並べ替え、書き写し（指でなぞる）。
- 音声素材: 他社教材の音声・イラスト・文章を複製しない。TTSやネイティブ録音を使う場合は権利と品質（標準的な発音）を確認。
- 3・4年向けは文字を前面に出さず、音声中心。5・6年向けに読む・書くを追加する、という段階設計が資料の構成と合う。

| 活動 | アプリで扱える度合い | 理由（示唆） |
|---|---|---|
| 聞いて選ぶ（語句・短い会話） | 高 | 正誤判定が確実。音声素材の品質が鍵 |
| アルファベット（大文字・小文字） | 高 | 識別・対応・書き写しは機械判定しやすい |
| 語順の並べ替え・書き写し | 高 | 本文の「語順を意識」に対応 |
| 読む（慣れ親しんだ語句の識別） | 中〜高 | 音声で慣れ親しんだ語句が前提 |
| 話す[やり取り] | 低 | 相手との対話が本質。ロールプレイ型の疑似対話に留める |
| 話す[発表] | 低〜中 | 録音して聞き返す程度。評価はしない |
| 文化理解（日本と外国の違い） | 中 | 読み物・絵合わせ。固定的イメージを避ける |

## 7. プログラミング教育（プログラミング的思考）

### 7.1 事実（総則・各教科・手引 第三版）

- 総則に、児童がプログラミングを体験しながらコンピュータに意図した処理を行わせるために必要な論理的思考力を身に付けるための学習活動を計画的に実施する、という規定がある。教科として独立していない。
- 本文が例示する単元: 5年算数「正多角形の作図」（正確な繰り返し作業、一部を変えると他の正多角形も同様に考えられる場面）、6年理科「電気の利用」（電気の性質・働きを利用した道具。与えた条件で動作し、条件を変えると動作が変わることを考える場面）。総合的な学習の時間では、探究的な学習の過程に適切に位置付ける。
- 手引の三つのねらい: (1) プログラミング的思考を育む (2) プログラムの働きやよさ等に気付き、コンピュータを上手に活用しようとする態度を育む (3) 各教科の中で実施する場合は、教科での学びをより確実にする。プログラミング言語や技能の習得自体は目的ではない。
- プログラミング的思考の定義（手引）: 意図する活動に必要な動きの組合せを考え、動きに対応する記号をどう組み合わせるか、改善すればより意図に近づくかを論理的に考える力。
- コンピュータを動かす手順（手引）: 意図を明確にする → 動きと順序を考える → 動きを命令に置き換える → 命令を組み合わせる → 試行錯誤して改善する。命令の基本要素として、順序・条件による分岐・繰り返しが例示されている。
- 手引の学習活動の分類（教育課程内）: A 学習指導要領に例示された単元（算数5年の正多角形、理科6年の電気の利用、総合の探究3例）/ B 例示はないが教科内容を指導する中で実施（音楽3〜6年のリズムの組み合わせ、社会4年の47都道府県を特徴から見付けるプログラム、家庭6年の炊飯、総合の発表）/ C 教科とは別に実施（楽しさを味わう題材、教科学習に先立つ基礎、教科を基にした課題解決や表現）/ D クラブ活動など特定の児童（内容は未精読）。
- 手引は、小学校ではビジュアル型（ブロックを組むような）言語を想定していること、コンピュータをほとんど使わない指導だけで終わるのは望ましくないとしていること、うまくいかなかったとき当てずっぽうでなくどこが誤りかを考えて修正する大切さを述べている。

### 7.2 アプリでの活動案（アプリ独自。手引の例の流用・他社教材の複製ではない）

| 要素 | 活動案 | 対象目安 | 度合い |
|---|---|---|---|
| 順序 | 朝の支度・おつかい・料理の手順を並べ替える。順序を変えると結果が変わることを見る | 年中〜小2 | 高 |
| 条件 | 「もし雨なら傘、そうでなければ帽子」の分岐を選ぶ。信号や迷路のルール | 小1〜小3 | 高 |
| 繰り返し | 同じ動きの列から繰り返しの回数を見付けて短くする。図形のなぞり描きで検証 | 小2〜小5 | 高 |
| 分解 | 大きな動作を小さな動きに分ける（例: ロボットを迷路のゴールまで） | 小1〜小4 | 高 |
| 修正（バグ探し） | 動かない命令列の誤りを見付けて直す。結果と照らして考える | 小2〜小6 | 高 |
| 図形をかく命令 | 進む長さと曲がる角度の組合せで多角形をかく（5年算数の正多角形と連携） | 小4〜小6 | 中 |
| 電気・道具の動き | 「もし暗ければライトが点く」といった条件で動く道具の動作の条件を変えて考察（6年理科と連携） | 小5〜小6 | 中 |

- 設計上の注意（示唆）: 「楽しさ・達成感」を土台にしつつ、命令の意味や結果を考える場面を入れる。キャラクターは独自のものとし、既存のビジュアル言語の見た目・名称・ブロック構成をそのまま模倣しない。文字入力・キーボード操作を前提にしない。年少児は命令をタップして並べる形にし、読み書きを前提にしない。
- 幼児向けのアンプラグド的な遊び（体を動かす、カードを並べる）は手引でも低学年の活動に見られるとされる。アプリ内ではカード並べとして表現できる。
