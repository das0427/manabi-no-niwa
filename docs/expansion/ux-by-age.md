## 2. 画面の構成

### 2.1 幼児ホーム（2〜3歳・4歳・5歳）
- 左に絵の札の 3×3（区分ごとの遊び。位置固定）、右に「きょうの おすすめ」2〜3枚、「おえかき」、「がんばりノート」。v1 の構成を継承（v1 のレビューで寸法・はみ出しを修正済み）。
- 2歳段階は札 4 枚（2×2）＋「おえかき」だけにし、各札を大きく。「きょうの おすすめ」は出さない。起動ごとに保護者向けの短い案内（いっしょに あそぶ。1タップで閉じる）を出す（R#23）。

### 2.2 小学生ホーム（小1〜小6）
- 上段: 教科の札（こくご・さんすう・せいかつ（1・2年）／りか・しゃかい（3年〜）・えいご（3年〜）・プログラミング）。教科色＋教科の絵＋名前（1・2年はひらがな、3年以上は漢字＋ふりがな）。
- 右: きょうの おすすめ（復習を含め2〜3件。単元名と「ふくしゅう」の印）、おえかき、がんばりノート。
- 教科の札には「とりくみちゅう」の単元数を小さく（数字＋印）。点数は出さない。

### 2.3 単元の地図（教科の中）
- 領域ごとの列（例 算数: かず・けいさん／りょう・はかる／ずけい／データ）。単元は学習の順に並ぶ札。
- 状態の印（色だけにしない）: まだ＝白、とりくみちゅう＝半分塗りの丸、できた＝チェックではなく ○印、しっかりできた＝○＋星形の小さな印、ふくしゅう まち＝時計の印。
- 「ほかの がくねん」: 学年のタブ。在籍学年の±1 は表示の初期範囲で、タブで全学年へ行ける。先取り・さかのぼり（X-TG-03）。出さないのは保護者が閉じた単元だけ（R#32）。
- 復習: 「きょうの おすすめ」に出す復習は同じ教科で1日1件まで。残りは単元の地図の時計の印（ふくしゅう まち）で示す（R#14、architecture.md 3章）。

### 2.4 学習の画面（UnitRunner）
区画は全単元で同じ（X-UX-05）:
```
┌──────────────────────────────────────────────┐
│[おうち] 単元名           問題文（RichText）     [よむ/きく]│ ← 上
├──────────────────────────────────────────────┤
│                作業領域（図・操作・本文）                 │ ← 中央
├──────────────────────────────────────────────┤
│ [ヒント]   回答欄・選択肢・数字キー        [こたえあわせ][つぎへ]│ ← 下
└──────────────────────────────────────────────┘
```
- 解説は回答欄の上に開く板（閉じるまで次へ進まない／幼児は自動で閉じる）。
- 高学年は「メモ」（作業領域に書き込む小さなおえかき層。採点しない）を任意で使える。
- 数字キー: 0〜9・小数点・分数（分子／分母の切り替え）・けす・単位の選択。大きな札（主操作の寸法）。数の入力の単元では、数字キーは下の帯に入れず、**作業領域の右 1/3 の区画**（3×4＋機能の列）に置く。ヒント左下・つぎへ右下は変えない。寸法は DESINGN.md 18章（R#21）。125%・150% 表示ではみ出さないことを E2E で検査。

### 2.5 解説と誤答
- 誤答のときは誤りに応じた説明（misconception）→ もう一度。2回目の誤答でヒント2と「つぎへ」（v1 と同じ）。
- つぎへ の後は必ず解説（答えと理由）を見せる（自力でできなかったことを責めない文言）。
- 中高学年: 回の終わりに「見直し」一覧（まちがえた問題をもう一度）。

### 2.6 おえかき
- 画面: 左右どちらかに道具欄（利き手の設定）、中央に広いキャンバス（論理 16:10）。上に「おうち」「さくひん」「ほぞん状態」。
- かんたん: 道具欄に大きな札 6〜8 個（ペン、けしゴム、ぬる、はんこ、ずけい、もどす、すすむ、あたらしく）と、色・太さ（数は 1章の表）。はんこ・図形は押すと「えらぶ板」が開く（絵柄の見本と大きさの確認つき）。
  - けしゴムで はんこ・図形に触れると、そのまま消える（短い音と縮む演出。もどす で戻せる）（R#3）。
  - 重なっているときは常に最前面を選ぶ。選択中に空いた所をタップすると、そこへ移動（R#11）。
- くわしく: 色の細分（24色。スポイトなし）、太さ 5段、選択（てまえへ／おくへ／まわす／はんてん／おおきさ／矢印札での移動）、同じ所を続けてタップで奥の対象へ、虫めがね。
  - けしゴムで はんこ・図形に触れると、選択状態になり「けす」札が出る（R#3）。
- 両方: 色の札を押すと色名を短く読み上げる（効果音の設定に従う。R#27）。描いた順に重なる（後から描いた線ははんこの上に出る。「うえに かく」の切り替えは無い。R#1）。
- 状態（かく／おす／うごかす）を道具欄の上の大きな表示で示す（X-DR-06）。

## 3. 操作の規則（全区分共通）
- タップだけで主要操作が完結（X-UX-07）。hover・右クリック・ダブルクリック・細かなドラッグを必須にしない。
- 連打で二重回答・二重遷移しない。
- 2歳段階・3歳段階では、長押し・ドラッグを要する操作を出さない（研究が割れているため安全側）。
- 文字を読めない区分では、すべての指示が音声と絵で伝わる。

## 4. 年齢で意味が逆転しないこと
- 色・形の意味（○＝あってる、？＝ちがったよ、破線＝ヒント、太い輪郭＝えらんでいる）、位置（おうち左上、きく右上、ヒント左下、つぎへ右下）は全区分で同じ。
- 「おちついた」表現でも、上の記号と位置は同じ（装飾と音を減らすだけ）。
